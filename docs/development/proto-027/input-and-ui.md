# 027 贪吃蛇孵化场：操作与界面合同

版本：v0.2；日期：2026-10-10（Asia/Shanghai）。状态：操作合同，已只读核对Rules/Session与Runtime绑定，回收预告与四向提示已补源码；不是已完成测试或原生输入验收。实施范围见 [方案](implementation-plan.md)，实证见 [开发记录](2026-10-10-slice-01.md)。

## 1. 一步一输入与读图

本轮助手采用离散网格和三维斜俯生态盘。WASD/方向键直接提交单步移动，主蛇头、完整有序身体、占格、三类节身份和能力来源需同时可读。墙、通道、地面模块/货物、交付点属于Core；鼠标代理只选择切点或分身头，不按画面距离创造采集/回收或点击自动走路。Core坐标0起，界面显示1起。

规则提供MovePreview，Runtime侧栏四向显示安全/成长/碰撞提示；方向键直接提交，无额外移动确认。撞墙/未腾位身体/直接反向是耗1行动的已提交失败，原因进事件/提示并保存；其它自己的旧尾格在不成长时可进入，成长时旧尾不腾位，长度2仍不准直接反向。画面须完整显示占位与方向，不能从插值或动画长度推断占格；实际方向提示/焦点仍待验。

HUD必须区分剩余行动、交付量、实际载货/容量、有序节/能力、分身数/任务/载货；用形状和文字补充颜色。全部费用与合法性来自Core，不由按钮再扣一次。

## 2. 切尾、任务与回收

切点选择只预览，不推进任何蛇；展示主蛇保留段、新分身实际段、切后失去的能力/载量、货物转移/掉落和分身第一步。两种行为各显示短路径、下一格、方向/往返阶段与阻塞原因，不能只写“自动采集”。确认才提交单个切尾事务，达到两分身时不可再切。

新分身从后续有效动作开始推进。主蛇计划优先、分身稳定ID排序；遇墙/蛇/争物等待，不自动绕远路或造成隐藏主蛇伤害。所有新提交全局命令各花1行动，仍Active时让既有分身尝试任务；已提交碰撞失败停止后续分身，无效菜单不推进。当前无自动步进，不需要另按暂停才停住；帮助/复盘/切尾/回收确认/退出面板阻挡普通命令。

回收选择真实分身ID，主蛇头与分身头距离≤1，花1行动。Q/按钮先读取Core PreviewReclaim并打开预告：模块优先进容量2库存，满则留各原节格；货物先填主蛇余容量，剩余留分身原头格。Enter/按钮才提交，Esc取消不耗步。成功只删除该实体一次，不免费接回长身或保留已转移能力。交付只消耗合法货物，结算不能把地面/分身库存免费算成交付。

## 3. 成败、复盘与输入隔离

成功/失败以Core已确认阶段显示；明确碰撞格、资源/预算原因和最后提交动作。重试重建同配置，新局不带旧身体、模块/货物或预算；恢复只继续完整检查点，两者不得混作免费补给。

只读复盘展示近期成长、切尾能力损失、分身下一步/等待、回收、交付与位置事件；帮助/复盘互斥并阻挡玩法，关闭不执行一次隐藏动作。恢复历史不重播采集收益，不用事件回看推进分身。

输入适配须处理一帧多键、IMGUI键消费、鼠标UI覆盖、选项确认/取消、暂停与失焦，恢复/重试/新局后不得同帧再走一步并覆盖刚恢复状态。每次有效输入最多提交一条命令；方向预选及纯UI选择不自动收费。

## 4. 实际控制与安全保存

已只读核对 [SnakeRuntime.cs](../../../prototypes/proto-027-snake-hatchery/game/SnakeHatchery/Assets/SnakeHatchery/Presentation/SnakeRuntime.cs) 的实际绑定，仍未执行原生验收：

- WASD/方向键单步移动，W/↑为y+1、D/→为x+1；Space等待1全局行动，E在主蛇当前格采货，Enter在交付点交货。
- Z/X减少/增加保留节数；C巡线/V往返只打开切尾预告，Enter或按钮确认才提交，Esc取消不消耗行动。鼠标点主蛇后段选择该索引前保留的节数。
- 1/2选择当前按稳定ID升序的第1/第2分身，鼠标点分身头选择实际ID；Q打开该分身回收预告，Enter/按钮确认、Esc取消。
- G从头周围曼哈顿距离≤1的地面模块按距离、再模块ID取一件进库存；B放库存最低ID模块到主蛇头格。G不长身，Move进入地面模块才会成长。
- F6手动保存、F9恢复、R同预置重试；顶部短/长对照立即重置，同帧替换与动作共享门禁，首个合法新动作前可F9回旧档，此后自动保存更新。
- H最近十条事件，Y/面板按钮切“仅关键/含路线”；Tab帮助，两者互斥只读。M音乐、F5保存完整窗口 `Application.persistentDataPath/player-window.png`。
- Esc优先关闭切尾/回收/退出/帮助/复盘，否则打开保存退出确认；保存退出失败保留窗口。

帮助/复盘/切尾/回收确认/退出阻挡其它普通输入，关闭不消费规则；F9/R键分支return且Load/Reset与命令共用帧门禁，避免同帧再次移动/覆盖恢复状态。UI键消费/焦点/连按仍需实际测试与正常窗口验收，代码存在不等于边界已通过。系统安全权限弹窗由外部桌面条件处理，不代操作。

动作提交后保存完整状态；预览不写进度、失败不替换合法旧档。自动/手动保存失败给具体提示并保留内存状态，保存退出失败留窗口。坏主档不得覆盖唯一有效备份，恢复先领域校验，再构建主蛇/分身/地面/货物表现，不重新推进动作。
