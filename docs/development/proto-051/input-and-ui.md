版本：v0.2；日期：2026-10-10（Asia/Shanghai）。当前为首次可玩候选操作合同，已只读核对本项目Core/Runtime操作；Prepare成功、真实EditMode28/28通过，最终构建与相机证据已归档。绑定入口 [工程README](../../../prototypes/proto-051-recycling-cleaners/game/RecyclingCleaners/README.md)，分项结果见 [开发记录](2026-10-10-slice-01.md)。规则/存储/输入适配通过不等于原生已验。

## 1. 世界、选择与目标

三维斜俯视房间表现离散网格。角色移动、合法作用格、窄/广刷头覆盖和污物残量读同一个Session，不从画面距离或鼠标碰撞另算清洁/物料。角色位置、当前选格与本次覆盖分别标明，点击选择不自动走路或扣行动；移动后选格跟随角色。Core坐标0–5对应界面1–6，补给Core `(0,0)` 显示 `(1,1)`。

地图显示三类污物的形状/状态、剩余量、回收/腾桶点和边界；桶内普通/可转化料、共享已用/总容量、清洁剂、滤芯开关/额度可读。剩余清洁目标、行动/耐久和现金分开，不用一个百分数掩盖资源原因。

布局、桶容量等对照配置在新轮确定，顶栏按钮立即重新开始、滤芯初始关闭；当前无事前确认，新轮第一次合法动作前可F9回旧检查点，此后自动保存更新。不能边玩边免费扩桶或换布局。R用本轮最初布局/容量/滤芯初态重试。换刷头只在补给点，花1行动/1耐久；滤芯开关任意位置，花1行动/0耐久，不恢复额度。

## 2. 基础动作与容量反馈

移动正交一格花1行动/0耐久，目标选择本身不收费；清洁目标为角色自身或正交邻格。窄头只目标一格；广头含中心十字按距角色/格ID排除障碍，`PreviewCoverage` 为唯一预览源。吸取、基础擦洗和单目标清洁剂分别说明污物/范围/成本，刷头预览不先清掉画面；实际处理按稳定顺序与可装量。满桶时格内仍有残余，明确哪类料占用；无法处理/距离非法/没有预算等只给具体原因。

顽渍同时说明基础擦洗与有限清洁剂路线，不能让没滤芯的玩家看成无解。宽刷的额外范围与成本可查；选错空格不偷偷有效，也不无解释扣预算。移动、换头/开关、腾桶等是否消耗行动/耐久全部取Core，不由UI另扣。耐久0显示回补给点Restock路线及资金/行动成本，不误报立即失败；有残污且行动耗尽才失败，全部清完优先成功。

## 3. 出售、丢弃和转换

出售/丢弃只在补给点。出售一次清空两类材料，丢弃指定一类与数量，均花1行动/1耐久；转换任意位置但须开启滤芯，花1行动/1耐久。动作前显示选料/数量、现金/空间变化和成本；转换显示已有可转化料2→剂1、剩余三次总额度/容量2剂槽。已离开桶的材料不再成为转换来源。

自动滤芯只在合法清洁事务内消费已有材料，UI展示先腾空间再接新料的因果；本步新料不递归转化。不开/无料/无剂量槽/额度零或附加耐久不足时回普通容量吸取，不拒绝原本合法的基础动作；桶仍满才解释阻塞。清洁剂按真实用途和剩余剂量显示，失败不先喷出“成功清空”的画面。

## 4. 完成、重试与复盘

动作同步完成后再更新目标与预算；最后有效动作清完时显示成功，不先播放耗尽失败。结算列已清/剩余、材料收集/出售/丢弃/转换/使用、行动/耐久/现金和主要阻塞；不是成长商店或新人物剧情。

全部清完立即结束，末桶未售材料不自动变现、不能结束后再出售；若想出售需在最后一处污物清完前规划返回补给。结算不把库存估值加进现金，新配置/重试不带上轮资源。

重试同配置、新配置对照与读取检查点分开；明确立即重置与检查点更新时机。H复盘只读最近十条事件，Y或面板右上按钮切换“仅关键/含路线”，后者含移动事件；显示累计行动/位置、污物减少、入桶/转换/阻塞原因。切换不消费规则/预算，面板打开阻挡其它玩法命令，H/Esc关闭不提交动作。旧历史不重新清洁/派奖/播放奖励声。
