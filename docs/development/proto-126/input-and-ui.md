# 126 收割机自己铺路：操作与界面合同

版本：v0.2；日期：2026-10-10。以下绑定已只读核对实际[HarvesterRuntime.cs](../../../prototypes/proto-126-harvester-paths/game/HarvesterPaths/Assets/HarvesterPaths/Presentation/HarvesterRuntime.cs)；Prepare、规则/存储39项及最终构建已通过，原生绑定/完整HUD/动态仍未验。事实见[开发记录](2026-10-10-slice-01.md)，规则/三轮账见[实施合同](implementation-plan.md)。

## 1. 当前实际绑定

- W/上箭头：沿当前车头前进，不能直接进Crop；Q/E：左/右转，其它方向键没有自由平移绑定。
- Space：按本轮模块收割预览；C：车载2秸转油；鼠标选格后P：铺相邻Mud，用真实车秸，不能远程从warehouseStraw取料。
- I/K/J/L：目标格向y+1/y-1/x-1/x+1选一格，限图内；鼠标点场景也选格，仅预选不移车/铺路。
- Z/X：数量减/增，限1..Rules.BoxCapacity（当前10）；Enter按数量交粮，U按数量卸秸，F仓库补油。范围不保证车内有料，合法性由对应预览禁灰。
- 1–4分别预选None/滚轮/宽头/箱体，只在“新三轮·当前模块”按钮开局或合法轮界N生效，当前轮不换装。
- N：已达标且在仓库显式进入下一轮，采用预选模块；R按该局InitialModule重试整局，不采用后改的预选值。
- F6保存/F9恢复；H复盘/Y含移动，Tab帮助，M音乐，F5截图到persistentDataPath的`player-window.png`，Esc关闭帮助/复盘或开保存退出确认。

帮助/复盘互斥且阻普通命令，退出确认同样阻命令；取消/选格/数量/模块预选不扣预算。F6键盘保存后return；F9/R先Claim再return，领域Execute/轮切/新局共享帧门禁，状态替换后不接同帧驾驶保存。每成功新提交自动保存，保存失败优先显示、退出失败留窗；IMGUI焦点/Enter重复激活仍待可见窗口验收。

## 2. 入轮、达标与补救

进入第1轮基础车，先读本轮需求/剩行动、粮+秸共享容量、油及泥地。收割产物全部能装才提交，作物变Ground；不能边收边静默丢秸。车秸可以转油或铺路，真实互斥扣料，两用途都占行动。

回仓交付只能移出本轮尚需的实际粮，一次结算钱/进度；未达标可继续规划或补给，不承诺原地没油就能免费返回。达标前操作预算仍截止，最后有效交付先判目标。前两轮达标后只能用旧剩行动卸秸/补油维护，其它驾驶/收割/交粮/转油/铺路关闭；显式N才设新预算并锁定下一模块。

切模块装不下则拒绝、不删货；可旧预算卸秸或先选能装当前货的模块后在下一轮付费卸。车货/地图/油/钱/仓秸跨轮保留，warehouseStraw仅入库记录、不取回/远程利用。第三轮达标或任一轮截止失败结束；R重置整局，F9只恢复合法旧安全点。

## 3. 必需可读信息与教程

始终分开显示本轮目标/已交/余行动、油/上限、车粮/秸/总容量、库秸、现金与当前模块利益/代价。仓库不是第四地块；地图同步读Crop/Ground/Mud、铺路结果，朝向箭头和切幅与Core共锚点。颜色外用地形轮廓、字和目标范围区别。

当前收割预览说明目标格数、预计粮/秸、空间和行动/油；铺路预览标确切格/材料/费用；拒绝具体说阶段、Crop挡路、边界、容量、油、行动、材料、位置或数量。不要把缺油写成行动失败，或给隐性降目标/刷新田地。

教程顺序：W前進/QE转向→Space先收再驶入→粮秸共占箱→Z/X数量/部分交粮与卸秸→C/P互斥消费→达标旧预算维护/1–4预选与N轮切→三轮延续。Tab可复看，无强制剧情/奖励。H默认最近10条关键已提交事件、隐藏Moved/Turned，Y包含两种路线事件；行显示轮次/动作序号、Amount、行动成本/油耗和原因。复盘只读不扣预算，具体路线读图仍待动态QA。
