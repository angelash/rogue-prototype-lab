# 121 磁铁拾荒者：操作与界面合同

版本：v0.2；日期：2026-10-10。按已落盘[Runtime](../../../prototypes/proto-121-magnet-scavenger/game/MagnetScavenger/Assets/MagnetScavenger/Presentation/MagnetRuntime.cs)核对绑定；接入/真实窗口结果见[开发记录](2026-10-10-slice-01.md)，当前不预称原生QA通过。

## 1. 从进入到结束

进入Parts订单、根朝右空链；先读订单/負载/末端/首件预览。吸取后Pending必须保留或回收区出售，它计重/占格、不延伸/续吸。保留后的整链随根平移旋转，全部占格一起检验。

回收区可卖Pending、选中链尾或暂存件；X拆中段及后段先预告再确认，T只重装一件到尾。订单完成/电量截止后看结果、H复盘、R同订单重试；顶部Parts/Heavy按钮是独立新局、不继承现金。首次新合法动作前可F9回旧安全点，自动保存后更新主档。

## 2. 当前键鼠绑定

- WASD/方向键平移一格，W/上=y+1，D/右=x+1，S/下=y-1，A/左=x-1；1电。
- Q/E整链左/右转，2电；不是自由旋转某单件。
- Space吸首件，2电；K留Pending，1电。
- 1–5选稳定物件ID，鼠标点场景实际占格选ID；暂存可数字选择，已售被选中不会重新可用。
- Enter有Pending时优先卖Pending，否则卖选中ID，1电；确认窗口内Enter只确认，不并发出售。
- X开所选链段及全部后段预告，无费用；显示受影响ID、2电与新负载。Enter/按钮确认，Esc取消；非法预告只有理由、禁确认。
- T重装选中Storage ID到尾，1电；根在回收区且几何/负载合法才提交。
- F6保存、F9恢复、R同订单重试。F9/R与领域提交共用帧门禁，状态替换后不接移动；恢复不是充电/发钱。
- H最近事件，Y切“仅关键/含移动”，Tab规则；帮助/复盘互斥且阻普通命令，Esc关闭。无连续自动步进。
- M音乐开关，F5截图到persistentDataPath的`player-window.png`，Esc开保存退出确认；保存失败留窗，Esc取消。

按钮与键盘共用命令，禁灰读Core。选择/预览/取消无电量费用。代码门禁不等于IMGUI焦点、鼠标键盘同刻、连按/长按已真实验收。

## 3. 必需信息与教学

上栏显示现金/电量，左侧显示订单需求/交付、总负载/上限、根朝向、选中稳定ID/归属、链顺序、Storage/Pending。场景提示末端1起坐标/朝向、首件ID和具体拒绝原因；不能把前件不合法显示成自动抓后件。

画面应对齐真实占格/接点/末端/射线与阻断；四形状靠轮廓加文字识别。选择、Pending、Chain/暂存身份来自确认State，装饰和悬停不改规则。回收柜不扩大Rules区。

H只读最近10条已提交事件，默认隐藏Moved，Y含移动；显示动作序号、物件ID、1起X/Y、Amount和原因。Amount按事件解释，不统一当售价；拒绝原因留当前通知，不伪造成功事件。

教程顺序：先看末端/首件→Space吸/K才成工具→Pending计重不延伸/实际出售给钱→长杆改变起点/L形固定转向→拆后段不会悬空。Tab可复看，无强制剧情/教程奖励。补救提示区分无目标、墙挡、超重、重叠/越界、区外和不足电，指向合法换根/方向、卖小件、拆短/重装，不能降目标/跳首件。
