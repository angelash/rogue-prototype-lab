# 套圈改造摊：首次实现与三维改造记录

日期：2026-10-09（Asia/Shanghai）；参数版本：三维 v0.6.0。用户先授权音频准备后开始开发，随后明确要求改成真实三维、斜视场景、从玩家近处向前套圈的地摊体验。新的视觉方向是用户决定；下面的布局与调参是本轮助手的初始实现建议。

工程入口：[Unity 工程与操作](../../../prototypes/proto-013-ring-toss/game/RingTossWorkshop/README.md)。视觉合同见 [三维场景方向](3d-scene-direction.md)，全量后续任务见 [12 缺口计划](../../design/first-batch/proto-013-ring-toss/full-game/12-development-readiness-and-gaps.md)。

## 当前已实现

- 独立 Unity 工程、单场景启动、版本锁定与 Windows x64 Mono 构建入口；使用已有 Unity 2022.3.62f3c1，没有安装或升级软件，没有修改参考工程。
- 三维场地的六槽为地面两排三列，玩家从投掷线附近向前抛圈，调整左右方位、仰角和力度。相机使用透视斜视，三维网格有灯光与阴影；二维调试网格不再是当前玩法画面。
- 原创程序场景含摊布、石板路、条纹棚、灯笼、河边栏杆、远景楼房、柜台与投掷手部；首组 Blender 道具接入结果与实际画面在下方另记。
- Core 的 Flight3D 是三维投掷权威；连续穿越接受平面与圆柱/有限板接触按纯 C# 计算。Unity Collider 仅作鼠标选物代理，动画、模型厚度、帧率不领奖。
- 3D 与旧 2D 复用同一个 StageSession 经济层；普通圈、准备/投掷/待处分/再投/结束、现金与有效回款、兑现/留场互斥、调整、补救和上一投隔离回放已实现。
- 七个本项目原创短音效与中文 Noto 字体接入；原型音效来源、哈希与限制见 [音频记录](../../../sources/references/woc-audio-reuse-register.md)。BGM、环境循环、全部事件音与正式混音仍未完成。

## 参数与职责边界

[Rules3D 与黄金输入](../../../prototypes/proto-013-ring-toss/game/RingTossWorkshop/Assets/RingToss/Core/README-3D.md) 是本轮三维参数入口。X 左右、Y 向上、Z 向前；发射点 (0,0.8,0)。前排 X=-1.6/0/1.6、Z=3.4，后排同 X、Z=5.6；接受高度 0.65，XZ 接受圆盘半径 0.24，圈内半径 0.32。左右角 -30..30°、仰角 20..75°，精度 0.25°；速度 4..12m/s，精度 0.02m/s。

仍使用 1/120s 固定步与 9.8m/s² 重力。初始三台扇/三板材奖品价值共 210，目标 105、八个普通圈、两次开摊后调整。准备调整免费；转向先预选后一次确认。旧 2D 的 1.2m 接受高度和单排 X 槽位仅保留为历史测试，不作为三维布局的可达证据。

Runtime 只提交命令、推进完整规则步和消费事件。Space/Enter 的键盘入口由 Update 唯一处理，IMGUI 不重复响应同一键；一次帧内命令共用门禁。回放从发射前配置重算，关闭正式经济提交，完成后返回实际场内状态。任何首次开摊输入应保留八圈，首次发射才扣一圈。

## 实际验证

### 规则

1. 首次 2D Unity 初始化、包解析与编译通过；第一轮测试为 30/30。
2. 首次 3D 编译发现鼠标选槽所需的 Physics 内置模块缺失，加入 com.unity.modules.physics 1.0.0 后解决。截图所需 screencapture 模块也已明确加入。

4. 新增检查覆盖真实六槽各自输入、XZ 圆盘/轴边界、横向偏离、圆柱步内侧撞、有限三维板、X 切向反射、风扇不吸附 X、六件兑现共 210、满耐久留场、消耗后的回放隔离和末圈处置。六槽完整布局中分别验证每个目标，不等于验证全解锁/预装组合。
