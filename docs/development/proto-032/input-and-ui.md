# 032 回转寿司工坊：操作与界面设计

版本：v0.2；日期：2026-10-10（Asia/Shanghai）；任务开始：2026-10-09。状态：首次可玩候选的操作合同，Prepare、30项规则/存储测试与已完成构建通过；原生操作尚未验证，未完成完整纵切验收。具体绑定见 [工程README](../../../prototypes/proto-032-sushi-workshop/game/SushiWorkshop/README.md)，实际输入/构建/画面分项见 [开发记录](2026-10-10-slice-01.md)。

## 1. 屏幕与状态所有者

单个固定斜俯视三维厨房，以六槽环轨、料理/盘和工站为主。规则仍是离散环，不增加自由移动角色；相机/灯光/盘插值仅表现。当前订单、份量、离席窗口、步限、资金与库存来自同一个Session/Config，不在UI计算价格或再减等待。

当前实现顶部显示资金/传送步/改站额度，左栏显示订单名/料理/交付量/等待/价格、基础收入目标和盘库存；底部给当前反馈。环轨上用方向箭头、槽编号、工站轮廓与盘标记；选中对象有文字/形状，配色不作唯一含义。Core槽0–5对应UI编号1–6。

左侧按阶段给主动作：准备/圈边界时配置、标记、弃单及开始，运行时单步/连续/暂停；投料/清洗在未结束的合法单步间开放，连续先暂停。结束时给原因/重试/切订单。当前动作栏常驻，镜头区域预留其宽度；后续折叠局部动作栏是建议，尚不写成现成功能。必要中文与成本走文本，生成图不能烘焙规则字形。

## 2. 准备与两订单对照

订单卡给出当前高价整份或快速小份的需求、目标/等待和报价；“整份对照/小份对照”按钮立即重新建立相同基线，R立即重试当前订单。当前实现没有事前重置确认；旧检查点在新轮第一次合法操作前仍可L读取，此后自动保存更新安全点。界面应明确即时重置与检查点覆盖时机，改进确认是建议，不能伪称已实现。

选站显示槽ID、现工站、候选加工条件/输出、购置/改站或转卖净成本；确认后只发一个合法命令。选盘显示真实料理、食材量/份量、位置与交付标记；标记改变只在规则允许窗口，关闭面板不偷偷提交。

投入先显示原料费、干净盘和入口容量；清洗显示脏盘与费用。两动作可在Running的单步安全点使用，连续运行时先暂停，动作本身不推进步数/等待。资金或容量不足禁用并解释原因，不能先演示成功再报拒绝。准备界面不运行传送，菜单点击不消耗等待。

## 3. 单步与连续运行

两入口推进同一规则Step，连续只是按节奏多次调用，暂停停止未来Step；动画/掉帧不跳过或重复步骤。一个正在展示的步骤完成前不接受第二次步骤请求，或按明确队列处理；键盘与IMGUI按钮不能双发。

在圈边界停止连续运行并展示新的合法准备窗口，避免没看见窗口就自动开下一圈。订单达成或十二步离席时显示订单状态，整轮仍运行至十八步统一结算；只有整轮Finished才禁用运行按钮。订单剩余等待与整轮剩余步数分开显示。

加工事件指出输入→输出与对应站；切分失败说明缺干净盘/入口容量，保留盘经过顾客说明“保留”，错份量/料理说明拒收。事件详情折叠，核心变化在盘/站附近短提示；快动作时不靠长日志维持可读性。

## 4. 补救、结束与复盘

基础出售、弃单和转卖以Core当前合法性与价格预览，明确损失/机会成本。基础出售是准备窗口的盘标记，到顾客点先尝试主订单、未接收才按标记回收；保留盘也可显式安排基础出售。弃单花2且不自动出售；转卖仅补资金、不计基础收入目标。运行中不开放免费改站。无效操作不扣资金或改变库存；连按/重复确认只有一次成功变化。

结算显示订单成功/失败及原因、实际交付/目标、收入/支出、剩余库存和关键阻塞。重试与切另一订单都重新建立相同基线，复盘仅查看旧事件不发新收入。首版无需完整局外商店或通关剧情。

H打开关键事件面板并暂停连续传送，显示最近十条加工/切分/切分阻塞/拒收/离席/交付；每行给步骤、盘、槽和原因，无盘/无槽事件显示“—”。H或Esc关闭；关闭不自行续跑，复盘期间不提交新玩法命令。面板只读生产事件，恢复后的历史可看但不能重复发音/收款。输入隔离、行截断和长原因可读性须真实窗口核对。

## 5. 保存、恢复与错误

保存只在安全提交点；正在动画时说明保存将对应已完成步，不写半步。读取已存订单/站/盘/资金/等待/阶段，恢复后给出继续位置，不默认选新的订单或补回盘/材料。

写失败提示实际未提交并允许按存储合同重试，不能显示“已保存”；坏档/不兼容/无档分别提示，并保留已知有效备份。真实故障结果进入开发记录，UI不吞错开新轮冒充恢复。

自动保存失败的错误优先于成功命令的事件摘要；“保存并退出”只在Save成功后退出，失败保留当前窗口/内存以便返回或重试。Save先校验新领域状态；主档损坏时再保存不能把坏主档写入唯一有效备份，替换与回退都经摘要/领域校验。追加备份保护与非法新档样本已在八项存储测试中通过；错误面板和退出键鼠路径仍待实际窗口验证。

## 6. 输入与可读性验收

已只读核对 [SushiRuntime.cs](../../../prototypes/proto-032-sushi-workshop/game/SushiWorkshop/Assets/SushiWorkshop/Presentation/SushiRuntime.cs)：数字1–6/场景鼠标选槽或盘，Space单步，Enter开始/续圈，P切换连续推进，I投料、C洗一盘，S保存，L读取，R重试当前订单，H关键事件复盘，Tab帮助，M音乐开关，F5窗口截图。Esc先关闭帮助/复盘，否则显示退出确认。装料、交付/保留、基础出售、清洗、转卖/购站、弃单有鼠标按钮；搬站先选源槽、点搬站，再选目标，有效确认后才扣费。装料/清洗与受准备窗口限制的配置/标记分别提示，不能用同一个阶段判断误禁用。帮助/退出/复盘面板阻挡普通输入；同帧命令防重复与IMGUI键盘消费须真实输入复核。正常键鼠路径仍须实际验收，不声称完整手柄。

最小采用画幅核对完整六槽、盘状态/份量、标记、等待与成本。字幕/文字覆盖关键声音，高对比与低动态不改规则；相机自动图若不含UI只证明场景，完整窗口截图和真实操作需单独完成。

本轮相机图世界文字尺寸已修正，字号正常；字体位置最后调整后的图待归档。普通Player启动被Windows防火墙安全权限弹窗阻挡，工具政策不能代理操作该弹窗，已请求用户手动取消但尚未关闭。订单选择、选盘/搬站、H/暂停、保存/继续/退出及实际听感等原生路径全部待补；不把规则测试、构建或相机图称为完整UI/QA通过。
