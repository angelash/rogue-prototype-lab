## 本版结论

设计游戏时，让有限规则持续产生值得处理的新局面。开发游戏时，让每次试验持续产生可以复用的新认识。

选题既要让人愿意试，也要让试过的玩家有理由换种做法再来一次。首次吸引、继续游玩、重玩需要分别验证。

原修订版助手建议优先验证 **32 回转寿司工坊 → 13 套圈改造摊 → 51 回收保洁队**，并重点观察 **121 磁铁拾荒者、126 收割机自己铺路**；该版发布时用户尚未据此选定游戏。本轮另行将这些优先方向与用户追加的 027 整理为第一批文档，具体范围解释见新汇总。31 案仍是候选池，不能当成同时开发的承诺。

平台、商业模式和预算尚未指定。仅核对过少量相邻作品，本归档不声称所有候选均为原创。
