## 32 回转寿司工坊：第一优先

验证问题：相同站点面对不同订单时，玩家是否改变站点配置与每圈标记，形成不同做法。

| 项目 | 最小范围与规则 |
| --- | --- |
| 场地 | 二维单环、6 个站位 |
| 内容 | 6 个基础料理状态、4 个加工站、2 类互斥订单 |
| 时间 | 固定运行步数 |
| 交付选择 | 每圈标记可交付或保留 |
| 切分 | 1 份切为 2 小份，小份多占盘位；食材守恒 |
| 空盘 | 清洗消耗资源 |
| 失败补救 | 基础出售、弃单、转卖 |

对照顺序：

1. 在相同站点下测试高价整份订单与快速离席小份订单，观察玩家是否改站、改变交付或保留标记。
2. 撤掉关键站，观察玩家能否用基础出售、弃单或转卖继续处理局面。
3. 删除切分规则，对比玩家选择是否发生变化。

出现以下情况时停止扩展并重构：

- 存在固定最优排列，订单变化不能改变做法。
- 后期玩家只需点击开始。
- 玩家无法解释触发原因和结果。
- 缺少关键站只能重开。

## 13 套圈改造摊：第二优先

验证问题：玩家能否通过练习改进投掷；当前回款需求变化是否改变兑现或留场的选择。

| 项目 | 最小范围与规则 |
| --- | --- |
| 投掷 | 稳定、可练习的轨迹 |
| 内容 | 1 个基础圈、2 个机关、6 个奖品位 |
| 兑现 | 兑现后奖品移走 |
| 留场 | 留场机关占位置并消耗耐久 |
| 反馈 | 显示落点与接触来源；不用隐藏抓取概率 |

先测试基础投掷能否通过练习改善，再改变当前回款条件，观察兑现与留场是否变化。

投掷难懂、选择单一，或机关不影响投法时，停止扩展并重构。

## 51 回收保洁队：第三优先

验证问题：布局、容量与资源用途是否改变清洁路线、顺序及留料决策。

| 项目 | 最小范围与规则 |
| --- | --- |
| 场地 | 单房间 |
| 内容 | 3 种污物、2 种回收材料、2 个刷头、1 个滤芯 |
| 容量 | 吸污占桶 |
| 转换 | 材料转换为清洁剂的能力有限 |
| 操作成本 | 腾桶、换工具消耗时间与耐久 |
| 基础可行性 | 普通污物可用基础工具处理 |

先关闭升级，只改变布局与容量，观察路线。再加入滤芯，观察清洁顺序、留料和腾桶选择。

始终按最近距离清洁、资源不影响选择、滤芯仅提供数值变化，或反馈无趣时，停止扩展并重构。

## 记录与判断

记录误解、主动转型、普通组件使用、失败归因和下次尝试计划。决策依据应包括实际行为与玩家解释。根据证据选择继续、转向或停止，不用组合数量代替验证。
