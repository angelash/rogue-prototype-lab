## 最小交付范围

一张 10×10 田地、3 类地块、3 种改装模块、3 轮订单，采用离散移动。地图与订单预告，基础机器能完成基础收割与回仓，不依赖稀有割头开路。技术平台与操作设备待定。

完整循环：读订单和泥地分布 → 选一种改装方案 → 规划收割与回仓路线 → 装粮与秸秆 → 决定转燃料或铺路 → 花行动交货/补给 → 固定预算截止并复盘。

## 必须具备的需求

- **HRV-R01 地图变化**：收割前后的地块与通行变化即时可见；同地图能比较不同订单/工具，不把每个场景重做成唯一解。
- **HRV-R02 离散驾驶与收割**：位置、朝向、切割范围和转弯成本明确；收割产生真实粮食/秸秆并改变地块，不重复收取已收割作物。
- **HRV-R03 共享载货**：粮食与秸秆占有限容量；溢出时阻止操作或让玩家明确选择弃料，不能无提示超载或删除副产物。
- **HRV-R04 副产物两用**：同一秸秆用于燃料或铺路后被消耗，不能同时取得两种收益。燃料增加续航，铺路改变泥地通行条件，两者都要与当前交货目标竞争。
- **HRV-R05 固定行动截止**：移动、转向、收割、装卸、部分交货、补给和燃料转换都计入预算；加油只增加燃料，不增加本轮剩余行动数。
- **HRV-R06 模块与基础补救**：3 种模块有可见利益和代价，基础工具可处理普通场景；可以部分交货与回仓补给，相关成本和不达标结果明确。
- **HRV-R07 反馈与复盘**：记录行驶轨迹、收割地块、装载、秸秆去向、每次行动扣除和交付结果；失败显示燃料、容量或截止的具体原因。

## 验收场景

- **HRV-A01**（R01、R02）：同地块收割一次后作物消失、通行状态变化、产物只增加一次；再次执行不重复收获。
- **HRV-A02**（R03、R04）：同批秸秆分别转燃料和铺泥路，两条分支正确扣减库存，粮箱不突破容量；材料不足时不执行一半交易。
- **HRV-A03**（R05）：在剩余行动有限时补油、卸货或部分交付，预算分别扣除。重复加油不能延长订单期限。
- **HRV-A04**（R02、R03、R06）：同订单分别选择滚轮、切割头和箱体模块，界面与日志解释通行、切幅、转弯或容量差异；基础机无需特殊模块也有合法基础路线。
- **HRV-A05**（R05、R07）：最后一个行动完成交付后再判断订单；未达标显示已交数量与截止原因。三个回合的订单进度独立，不能重复交付同一粮食。

上述验收尚未执行；三轮场景需在未来实现时验证资源与基础路线可行。

## 验证问题与去留

- **HRV-H01**：同一地图因订单或模块变化产生不同路线，玩家能解释改变原因。
- **HRV-H02**：秸秆续航与铺路的互斥用途改变返回时机和载货安排。
- **HRV-H03**：宽切幅提高收获同时制造真实的转弯/容量压力，不能无代价恒优。

若玩家总按外圈逐行全清、加油使行动截止失去约束、铺路只改变视觉，或宽切头始终最佳，就暂停扩作物并重做目标、容量或地图。

## 暂不纳入与待定

不做农业机械物理、自由农场经营、复杂作物生态、天气模拟或多个机械协作。模块候选随机与局间成长后续再评估。燃料、容量、三轮订单、泥地代价和改装数值待校准，技术选型与实际开发顺序未确定。
