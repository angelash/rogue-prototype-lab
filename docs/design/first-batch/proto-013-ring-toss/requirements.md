# 013 套圈改造摊：需求文档

版本：v0.1；日期：2026-10-09（Asia/Shanghai）。状态：第一批原型文档，尚未实现或实测。

## 目标与依据

让玩家练习投圈，并在套中奖品后选择兑现现金或留场改造下一投。核心是机关确实改变可用投法，同时回款压力会改变是否保留机关。

## 最小交付范围

二维侧视或固定平面、1 种基础圈、2 种机关、6 个奖品位置。先采用固定场地与可重复的投掷规则，投掷学习成立后再测试奖励成长。平台、引擎与具体输入方式待定。

完整循环：观察场地和回款目标 → 选角度与力度 → 投圈、看轨迹 → 判定命中 → 兑现或留场 → 有限调整机关 → 继续投掷并结算。

## 必须具备的需求

- **RNG-R01 可练习投掷**：角度、力度与几何结果稳定对应；同条件同输入产生同落点。不使用隐藏抓取概率制造命中或失误。
- **RNG-R02 可读命中**：展示落点、接触对象及命中条件；快速重试保留场地。轨迹预览只给基础信息，不能代替全部操作学习。
- **RNG-R03 奖品两用**：命中奖品只能选择兑现并移走，或转为明确机关留在场内；不能同时获得全部现金和持续能力。
- **RNG-R04 有限机关**：风扇与反弹板改变轨迹；占用 6 个位置中的现有位置，受有限调整次数和耐久/能量约束。每次触发的消耗与失效原因可见。
- **RNG-R05 回款与圈数**：显示剩余圈数、现金目标和当前收益；同场地支持不同回款要求的对照。没有足够圈数或现金时显示明确结算原因。
- **RNG-R06 回放与重试**：记录初始布置、投掷输入、机关触发、命中和奖品处置；回放解释失败，重试不得无故改变物理参数。

## 验收场景

- **RNG-A01**（R01、R02）：同场景同角度力度重复投掷，命中结果一致；改变角度或力度，轨迹按规则变化，失误可从接触与落点说明。
- **RNG-A02**（R03、R05）：命中同一奖品分别兑现和留场。兑现只加现金并腾位置，留场只提供机关且占位；重放不重复领奖。
- **RNG-A03**（R04、R06）：同一输入在无机关、风扇、反弹板三种状态重放。轨迹差异可追溯到触发来源；耐久耗尽后不再生效。
- **RNG-A04**（R04、R05）：机关调整次数耗尽，仍可投掷但不能继续免费挪动。最后一个圈完成判定和处置后再检查回款，不提前结束。
- **RNG-A05**（R01、R06）：连续失手时快速重投，场地和规则保持一致，玩家可以利用上一投信息调整。

以上场景尚未执行；要求的复现精度随最终技术方案明确，首版不能把浮点误差变成隐蔽随机。

## 验证问题与去留

- **RNG-H01**：无成长奖励时，玩家愿意重试且投掷表现能通过练习改善。
- **RNG-H02**：改变当前回款要求后，玩家会在现金与后续机关之间改变选择。
- **RNG-H03**：同一机关既可能帮助远投，也可能妨碍近投，玩家会主动调整或兑现它。

投掷无法练习改善、兑现或留场长期只有一个答案、机关不改变投法，或必须依靠复杂动画掩盖单投无趣时，暂停扩内容并重构。

## 暂不纳入与待定

不纳入真实三维套环、软体模拟、无限复制圈和店铺经营。多种圈、预告风况与随机奖品留到基础验证后。命中容差、角度力度范围、回款数值和机关耐久均待校准，实际开发顺序与技术选型未确定。
