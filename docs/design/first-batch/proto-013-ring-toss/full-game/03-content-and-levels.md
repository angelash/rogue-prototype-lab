## 1. 内容规模与组织

1. 一局固定为三章，每章四摊，共十二摊。章节为「桥脚夜市」「旧货运站」「江心集」；每章第四摊是主题挑战。摊间商店和剧情停留不计入十二摊，不额外消耗投圈。
2. 制作十二个关卡模板 `LVL-01` 至 `LVL-12`，各自固定教学主题、关键奖品、公开风况类别和兑现通路条件。正式局每个模板只出现一次，模板内仅允许经过审核的候选奖品组合和公开布局变化。
3. 制作三种圈 `RING-01 普通圈`、`RING-02 重圈`、`RING-03 宽轻圈`，六种机关 `MEC-01 风扇`、`MEC-02 反弹板`、`MEC-03 挡风罩`、`MEC-04 导向滑槽`、`MEC-05 拨片`、`MEC-06 缓冲垫`。具体参数只记录在 04；关卡不能偷偷改变同名圈或机关的参数。
4. 六种机关各有两款旧物奖品皮肤，总计十二款。机关种类决定功能与基础兑现价值，同种皮肤仅改变外观和文字，不能改变判定接受区、耐久或售价。
5. 六位角色由 01 统一管理：桑禾、鲁青、阮灯、季澜、叶砧、沈泊。关卡文案可引用他们，不另增必须有头像、配音或独立支线的角色。
6. 正式局不要求玩家收齐机关，不要求看完剧情，不要求使用特殊圈。每一摊必须存在普通圈与直接兑现可达成的解法，机关组合提供不同路线和后续收益。

## 2. 固定场地与模板读法

1. 场地使用 04 的统一二维侧视标尺：宽 12 m、高 7 m，发射点为 `(0.6, 0.8)`。六槽 `S1` 至 `S6` 默认横坐标为 `2.2 / 3.8 / 5.4 / 7.0 / 8.6 / 10.2 m`，目标接受高度统一为 1.2 m。第一套十二模板不引入高低架，避免把制作成本与命中规则一起扩张。
2. 阅读顺序为「发射点 → S1 → S2 → S3 → S4 → S5 → S6」。下文 `01A` 表示奖品 `PRZ-01A`；`*` 标记该模板要保留的教学奖品，其他位置为公开候选。槽位示例是无自有机关时的布局基线，不是必须照抄的随机结果。
3. 点击「开摊」确认前可免费安装/拆下最多两个合法自有机关并设置朝向与开关，仍只占六槽。点击确认即冻结布局、目标与基础圈数；此后开关、转向、移动或交换已在场机关按 04 的两次调整预算计次，不能利用尚未首投继续免费布置。留场转化发生在原槽且不消耗调整次数；不能挪动新奖品为机关让路。
4. 准备前用固定种子确定每个槽的新奖品候选。自有机关预装只覆盖对应槽的候选，其余槽不重排；实际新奖品数为 `6 − 预装数`。反复预览、开关商店或改变预装不重抽候选；取消预装恢复该槽原候选。预览同步显示实际新奖品、兑现总值及 04 的回款目标，点击「开摊」后全部冻结。关键教学奖品被预装覆盖时，仍可在帮助或已解锁内容的训练中复习；已有同类自有机关在场可改为组合提示。关卡验收必须检查剩余实际新奖品的普通圈回款路线，不能把已被覆盖的教学奖品当成可领取收入。
5. 每一模板的回款目标、奖品兑现值、剩余圈和耐久全部由 04 的章节配置与可行性规则供给。本文件不另设章末加价或难度倍率。背景货箱、桥柱、灯串等默认没有碰撞；需要真实碰撞的对象必须登记为机关并显示作用区。

## 3. 十二摊模板

### LVL-01 桥脚报名台：读轨迹与兑现

- **学习目标**：识别圈数、回款进度、角度与力度，完成一次「命中 → 兑现」，理解失手有明确接触或落点原因。
- **基线槽位**：`S1=01A，S2=02A，S3=01A，S4=02A，S5=01A，S6=02A`。无风；没有预装教学机关。重复皮肤可存在，但用独立奖品实例编号管理。
- **教学安排**：首次游玩先提供可跳过的独立练习投，其落点、奖励与圈数不进入正式局；正式第一摊保留一次性操作提示。先突出 S1，再让玩家主动选择其他目标，不用自动修正制造命中。
- **选择与补救**：近槽兑现给玩家一个可读的成功；保留台扇或反弹板可提前试机关。失手后展示上一投输入与落点，允许重用角度或力度单独修正。
- **审核条件**：至少有两个近端奖品和一条不需机关的兑现通路；教程提示不挡瞄准区；跳过教程后规则与收益一致。

### LVL-02 渡口风扇摊：风扇的收益与占位

- **学习目标**：留场不增加当前回款，风扇改变下一投，同一机关也可能把圈吹过近目标。
- **基线槽位**：`S1=02A，S2=01A*，S3=02A，S4=01A，S5=02A，S6=01A`。无环境风，MEC-01 作用区与方向可预读。
- **选择与补救**：S2 的台扇可兑现以尽快达标，也可留场作为远投帮手。留场后近投绕开作用区、调整朝向或关闭机关，后两项各按 04 耗一次调整；不要求玩家先留扇才能够到 S5/S6。
- **审核条件**：留场之后至少一个新奖品仍有不经过风扇作用区的路线；风扇初始朝向不能在玩家不知情时直接造成必失；两次调整足以完成一次修正并保留一次试验。

### LVL-03 雨棚板材摊：反弹与接触顺序

- **学习目标**：板面法线决定反弹方向，侧撞目标不等于套中；机关耐久的消耗点可观察。
- **基线槽位**：`S1=01A，S2=02A*，S3=01A，S4=02A，S5=01A，S6=02A`。无环境风，不使用场外墙面反弹。
- **选择与补救**：板面留场形成可学习的高弧或回折路线；直接兑现仍可用普通圈逐个投掷。若板遮住原路线，可通过转向、关闭机关或选择其他目标补救；转向/开关均按 04 消耗一次调整，关闭之后的占位与碰撞也按 02/04，不能假设物体消失。
- **审核条件**：至少提供一个容易看到板面接触的合法路线；轨迹事件明确区分「反弹」「擦碰」「目标侧撞」；禁用把板隐藏在奖品后面的布局。

### LVL-04 旧闸钟台：现金与改造的第一道考题

- **学习目标**：主动决定保留风扇或反弹板的时机，考察当摊回款和带往下一摊的价值。
- **基线槽位**：`S1=02A，S2=01A*，S3=02A，S4=02A*，S5=01A，S6=02A`。无环境风；无新的机关教学。
- **考题**：玩家可以全部兑现，也可以先留一件帮助套远端奖品，再决定章末带走什么。系统不评分「是否用了正确机关」，只按公开回款规则判过关。
- **补救**：达标后明确允许主动结算或继续剩圈；继续获得的新奖品仍需兑现/留场互斥，不把剩圈换钱。最后一圈先完成处置再结算。
- **审核条件**：留两件的实验路线不能被默认认定为必通关；直接兑现路线满足 04 的最低可行性约束；章末回顾引用实际投掷和处置，不编造桑禾的表现。

### LVL-05 箱笼试摆台：公开风况与挡风罩

- **学习目标**：风况从准备到投掷保持公开且固定；挡风罩在作用区内改变环境风的影响。
- **基线槽位**：`S1=03B*，S2=01B，S3=03B，S4=02B，S5=01B，S6=03B`。采用 04 允许的轻逆风预设，准备页与瞄准页持续显示方向和等级。
- **选择与补救**：挡风罩兑现能尽快回款，留场可保护一条路线。未留罩时玩家仍可调整普通圈输入；本章开始允许选用已经引入的重圈，其供应与解锁按 04。
- **审核条件**：风况不在玩家投出后换向；普通圈能到达必要的兑现目标；护罩保护范围必须画在场地内，不能只在说明卡里提及。

### LVL-06 双窗电器台：一次入口，多次用途

- **学习目标**：区分导向滑槽的入口、出口和固定轨迹变化；理解「碰到任意位置」不等于有效进入。
- **基线槽位**：`S1=03B，S2=04B*，S3=02B，S4=01B，S5=04B，S6=03B`。无环境风；初始入口和出口朝向由已审核预设提供。
- **选择与补救**：留滑槽后，用稳定入口投法试远端目标；也可绕开滑槽直接兑现。若从背面撞击，回放突出背面与有效入口，下一投可重用同一力度改角度。
- **审核条件**：入口大小和触发方向按统一数值，不因皮肤不同改变；出口至目标不允许在背景后不可见；滑槽不能出现未登记的轨迹吸附。

### LVL-07 货架修理台：有限调整与旧机关耐久

- **学习目标**：六槽占位是真实约束，先兑现腾出空槽再移动机关；从前摊带来的机关不会恢复满耐久。
- **基线槽位**：`S1=01B，S2=03B，S3=04B*，S4=02B，S5=03B，S6=04B`。轻顺风或无风，仅从审核过的公开候选中选择。
- **选择与补救**：有自有机关时，准备页先说明剩余耐久；确认开摊后不许把新奖品换位。兑现一件腾槽再改位置是组合路线，直接兑现其他奖品也是路线。
- **审核条件**：没有自有机关的局也能玩，教学文案改为留场后调整；界面拒绝非法移动时说明原因且不扣调整次数；至少一个兑现后可用的空槽能让机关形成可观察改变。

### LVL-08 转运交接台：风路与滑路的选择

- **学习目标**：将风扇/反弹与挡风罩/滑槽组成路线，同时给现金目标留足预算。
- **基线槽位**：`S1=03B*，S2=01B，S3=04B*，S4=02B，S5=03B，S6=04B`。公开轻逆风预设，其方向与等级以 02/04 的定义呈现。
- **考题**：可保护抛物线、导向到远槽，或使用不需机关的高弧投法。提示只问「你愿意为哪条路线占一个槽」，不揭示标准角度。
- **补救**：当自有机关耐久不足时可停止依赖它、换目标或在摊间商店选择 04 允许的维修；不在挑战飞行中弹出免费修复。
- **审核条件**：无维修、无特殊圈仍有直接兑现通路；两次调整能够至少完成一种有效组合；章末剧情不要求玩家必须造出指定装置。

### LVL-09 旧戏台侧摊：看清触发时机

- **学习目标**：拨片按公开固定规则改变速度或方向，识别进入区域与触发结果；不引入依赖墙钟时间的节奏按键。
- **基线槽位**：`S1=05A*，S2=01B，S3=03A，S4=05B，S5=02B，S6=04A`。无环境风；MEC-05 初始状态在准备页可查看。
- **选择与补救**：拨片帮助制造短回折或越过原落点，直接兑现则保留空位。若前一机关将圈送到错误侧，暂停回放逐事件查看来源，再改一项布置。
- **审核条件**：暂停、慢放与正常速度结果一致；只有模拟状态变化才能影响拨片，不能因玩家等候时间改变；图示包含触发前后两个箭头。

### LVL-10 缝补灯架摊：缓冲垫与宽轻圈

- **学习目标**：缓冲垫提供可学习的减速/缓冲效果，宽轻圈的取舍由公开参数解释；圈类型不改变「从上方进入」的基本判定。
- **基线槽位**：`S1=06A*，S2=03B，S3=05A，S4=06B，S5=01A，S6=04B`。无风或轻顺风，按审核候选公开。宽轻圈在这里第一次给出功能说明，供应与解锁按 04。
- **选择与补救**：垫子留场可处理过快的路线，兑现可直达回款。普通圈仍能通过修改输入实现有效命中；宽轻圈不能被设为硬钥匙。
- **审核条件**：缓冲反馈不伪装成命中；目标接受区随圈类型的显示按 02/04，不临时改奖品几何；失手原因明确说明速度变化来源。

### LVL-11 终场试摆台：检查构筑的短板

- **学习目标**：比较近端和远端投法，主动发现一套旧机关布置会帮助什么、妨碍什么。
- **基线槽位**：`S1=06B，S2=02A，S3=01B，S4=03A，S5=05B，S6=04A`。无环境风，使失败能主要归因于输入和机关。
- **选择与补救**：玩家可保留现有构筑，也可兑现金并在摊间调整带走名单；本摊不强制收集六种机关。两种圈的替代用法只作可折叠建议。
- **审核条件**：自有机关最多两个且耐久延续；新奖品仍至少四件；直接兑现路线与至少一种机关路线都通过审核；不把「未携带机关」写成失败。

### LVL-12 共用维修台：公开条件下的综合选择

- **学习目标**：读风况、看剩余耐久、安排两次调整、在最后一圈完成奖励处置，形成对一整局的可解释复盘。
- **基线槽位**：`S1=03B，S2=06A，S3=01A，S4=04B，S5=02B，S6=05A`。从 04 允许的无风/轻顺风/轻逆风审核预设中选择一种，入摊前预告并全摊固定。
- **考题**：不锁定机关答案；普通圈全兑现、稳定导向、反弹回折都应有成立的候选布局。胜负只用同一回款规则，外观奖章不额外提供钱或能力。
- **补救**：落定后显示「本圈可兑现的现金能否达标」而不替玩家自动选；达标后仍可按公开规则继续。失败回顾定位造成差额的处置或失手，不给「运气不好」作为通用原因。
- **审核条件**：最坏公开风况仍有普通圈兑现通路；预装两个合理机关的布局也有足够现金候选；最终剧情根据完成/未完成输出对应文本，失败不自动删除练习与图鉴记录。

## 4. 奖品皮肤、编号与依赖

1. `PRZ-01A 旧台扇`、`PRZ-01B 船舱风扇`：留场对应 MEC-01。可转扇叶与固定风向箭头是功能识别点；A 为桥脚补丁主题，B 为货站回收主题。
2. `PRZ-02A 弹簧告示牌`、`PRZ-02B 货箱盖板`：留场对应 MEC-02。两款都保留清晰平直板面与法线标记，不能让不规则外轮廓暗示另一碰撞面。
3. `PRZ-03A 竹编挡雨屏`、`PRZ-03B 透明雨挡`：留场对应 MEC-03。用同一罩区轮廓显示功能；编织或透明纹理只在轮廓内变化。
4. `PRZ-04A 竹制玩具滑道`、`PRZ-04B 分拣滑槽`：留场对应 MEC-04。入口、出口和方向箭头位置相同，皮肤不改转弯半径或触发范围。
5. `PRZ-05A 钟摆玩具`、`PRZ-05B 拨片转盘`：留场对应 MEC-05。固定接触区域清晰；装饰摆动只映射真实模拟状态，不暗示墙钟计时机制。
6. `PRZ-06A 毡布针垫`、`PRZ-06B 救生软垫`：留场对应 MEC-06。软边与压缩反馈提示缓冲；不得为皮肤新增真实反弹能力。
7. 奖品实例使用 `runId + stageId + slotId + spawnIndex` 唯一标识，与皮肤编号分开；stageId 使用 04/06 的摊身份字段，不另设同义 stallId。领取、兑现、留场与回放引用实例，不能通过换皮或新局同序号摊重复领奖。
8. A/B 是美术主题，不表示稀有度。桥脚主要 A，货站主要 B，江心混搭；种类按章节开放，配色不传递未定义的掉落概率。

## 5. 解锁与奖励节奏

1. 第一章只重点引入普通圈、风扇、反弹板和兑现/留场。初局教程可跳；第二局自动折叠基础提示，仍可在暂停页重新查看。初始开放品类与工坊笔记解锁费用以 04 为准，初局可能只用普通圈与两机关完成全部主线。
2. 在相应品类已解锁时，第二章重点教学公开风况、重圈、挡风罩与导向滑槽；第三章重点教学宽轻圈、拨片与缓冲垫。未解锁时改讲风况、输入修正、占位和现金取舍等共通主题，不把某件机关或特殊圈作为推进剧情的钥匙。圈类型未解锁则不生成可选库存，按 04 保留完整基础总圈数为普通圈；关卡不临时赠送未解锁能力。
3. 章末奖励由 04 的经济事务处理；内容层提供章节对白、已见机关说明、已见模板的练习入口与投掷回顾。图鉴和练习解锁不增强数值，不扩大六槽，不增加跨摊携带上限。
4. 首次通关后开放十二模板的完整练习选择，以及使用既有内容的挑战预设。无需再做一批隐含的终局关卡；重玩来自公开布局、现金取舍、两机关组合和实际投掷改进。
5. 尚未通关的玩家可练习已到达的模板，包括导致失败的那一摊。练习没有正式局收入、维修费用或跨摊资源，不把练习结果带回正在进行的正式局。

### 未解锁奖品的确定性映射

1. 第 3 节槽位示例是相应品类全部解锁时的内容基线；生成正式局候选前，先读取并保存本摊合法准备点的解锁快照。尚未解锁机关的同类 A/B 奖品不进入可领取池，也不通过留场或商店绕过解锁。
2. 需要替换的槽按固定规则映射到初始开放品类：奇数槽 S1/S3/S5 使用 PRZ-01，偶数槽 S2/S4/S6 使用 PRZ-02；桥脚使用 A 皮肤、货站使用 B 皮肤，江心按模板已固定的 A/B 主题。替换后采用实际品类在 04 的兑现价和功能，不沿用原未解锁品类的价钱或作用。
3. 替换在六槽候选首次确认时完成并保存；预装随后只覆盖对应候选，不再次映射或抽取。解锁新内容在 04 允许的下一摊/下一局准备点生效，不改变正在飞行、待处置或已经开摊冻结的布局。
4. 模板验收至少覆盖初始两机关、部分解锁和全部解锁三种池，以及各自 0/1/2 件合法预装；用替换后的实际新奖品重新核验金额和普通圈路线。未解锁的本章教学条目可在说明中预告用途，练习只允许已解锁品类，不能把可预告当作已经获得。

## 6. 三种构筑示例与克制

1. **稳定风路：MEC-01 风扇 + MEC-03 挡风罩。** 将某一段风力变化与受保护区相接，可把一个可重复的输入延伸到不同远端槽。短板是占两槽且可能压缩近投路线；耐久不足、护罩区域放错或需要频繁转向时收益变低。补救是先兑现近奖腾空，或停止经过风扇；不承诺一定优于普通圈直接投。
2. **固定入口：MEC-04 导向滑槽 + MEC-06 缓冲垫。** 先学习进入滑槽的稳定投法，再借缓冲改变出口之后的运动，适合复用一段路线。短板是入口要求、槽位跨度和触发顺序；过早缓冲可能根本进不了槽。补救是看事件日志，调整一件机关或改瞄准目标。两个机关的参数只引用 04。
3. **回折拾远：MEC-02 反弹板 + MEC-05 拨片。** 通过固定法线与公开拨片状态建立回折路线，让同一场地出现可学习的不同轨迹。短板是接触次序、板耐久和错误侧进入；近目标可能被板遮挡。补救是转向/关闭板、改入口，或直接兑现绕开组合；开关与转向均消耗一次调整，关闭后的碰撞按 04，不把关闭视为免费拆除。重圈与宽轻圈是可替代工具，不能替组合隐藏补偿。

这些名字、用途和优劣均为助手假设；只有实测出现不同现金/圈数压力下的有效选择后，才作为正式新手建议。不得写入「这套必胜」或给出未经测量的成功率。

## 7. 生成约束与普通圈可行性

1. 随机只选择公开候选奖品、已审核布局和预告风况；投出后不重抽风向、奖品价值、机关参数或命中容差。候选和最终结果在准备页可读，随机种子与配置版本进入回放。
2. 先按固定种子与本摊解锁快照保存六槽候选，再接受最多两个合法自有机关的预装；预装仅覆盖对应槽，其余候选不重排。实际新奖品数为 `6 − 预装数`，检查 04 的配额和可行性下界；不反复重抽候选，点击「开摊」后冻结目标。旧钱包、旧机关拆解残值、商店消费和章节外奖励都不能被计入当摊新回款。审核不能只看总钱包是否够钱。
3. 在新奖品集合中建立一组「普通圈直接兑现目标」。它们的公开兑现值之和应达到当摊目标；完成这些命中所需圈数不超过该章圈数，并按 04 规定保留失手余量。所有目标均应有无需新留场机关、无需特殊圈的合法投法。
4. 上述可行性不是用数学上的单点命中应付审核。每个目标必须测量可命中的角度/力度窗口，并达到 07 的可学习性阈值；参数尚未校准前不得宣称某模板已保证通关。
5. 对自有机关布置的审核包括不预装、所有允许的一件/两件机关及槽位组合，以及零耐久非法预装拒绝。耐久 0 的携带机关必须先按 04 维修才可预装，拒绝时不占槽、不扣资源；不能拿非法的零耐久布置作为关卡现金基准。所有合法准备组合均须有剩余实际新奖品的普通圈可达证据，必要时使用两次公开调整或绕过实体；没有证据的组合不能作为正式布局交付。玩家开摊后主动把奖品留场、造成可得现金不足或挡住原路线，不提供无条件通关保证，也不偷偷降低目标。
6. 发行前审核失败时重选一个候选或回退到无风标准布局，并记录配置问题；发行后已开始准备的布局不因玩家反复预装而重抽。若发现配置无效，提示问题并保留原候选、引导恢复合法布置，不能通过临时加大接受区、加现金、补圈或自动瞄准在局内悄悄修正。
7. 初版候选数量有限：每模板保留一个标准布局与最多两个通过审核的变化，共不超过三十六套可发行布局。变体必须沿用原主题与素材，只有配置变化；没有通过审核的变体不得进入正式抽取。

## 8. 关卡编辑与审核交付

1. 每模板的场景数据至少包含：模板 ID、章节/摊序、配置版本、槽位坐标、奖品候选及权重、关键教学标签、公开风况 ID、默认机关朝向、回款配置引用、剧情触发 ID、镜头安全区和允许变体 ID。
2. 权重只用于生成候选，不能进入飞行命中。必须保存实际抽到的六槽布局；回放读取已保存结果，不能再用当前权重重抽。
3. 每个发行布局交付一份人工可读审核记录：零自有机关的普通圈解法输入样例、合理两机关时的解法输入样例、可兑现总值、失败余量、输入窗口测量、命中原因、视觉遮挡截图和调整次数检查。
4. 编辑器或数据工具应显示物理层、装饰层、接受区、机关作用区和飞行边界；分层开关用于审核。制作不允许直接拖动新奖品尺寸来调难度，改变接受区须改 04 的共用配置并重新验证。
5. 上架前检查：六槽无重叠/越界；至少四件新奖品；价格与功能卡一致；没有第七槽；所有合法作用区可见；背景不遮挡圈；最后一圈处置和达标检查正确；练习与正式局同规则；每个句子使用正确角色名。
6. 02/04 改变圈速度、风力、碰撞或接受区后，应重新审核所有受影响模板；只有背景换色、灯串位置或对白标点改变可免去轨迹复核。

## 9. 正式局、练习与挑战模式

1. **正式局**：三章十二摊，使用公开候选与固定章节顺序；每摊独立回款，跨摊钱包和最多两件自有机关按 02/04/06 延续。失败返回结算与章节回顾；新局按正常规则开始，不能把练习奖品导入。
2. **练习**：选择已到达模板、已解锁圈类型、审核过的布局/风况、零至两件已解锁机关；提供单投重置与查看上一投。重置恢复所选快照的圈数、耐久与奖品，明确标注「练习不发放收入」。允许查看详尽轨迹事件，帮助理解正式局的反馈。
3. **固定挑战**：从十二模板生成三组可重复预设：普通圈直接兑现、限制两机关、无维修完整局。预设公开种子、配置版本、目标与资源；运行规则和命中不变，只改变已声明配置。不做每日联网抽奖、排行榜或额外奖励货币。
4. 挑战记录展示完成状态、命中/失手、当摊差额、使用圈数与机关触发；不用快照作弊检测、限时竞争或联网榜单扩大制作范围。暂停和 0.5× 观察不影响合法完成。
5. 正式局复盘可把上一摊快照作为练习入口；一键重现失败投掷后，玩家修改一个变量再投。回放是解释工具，不自动揭示每个模板的必胜角度。

## 10. 内容完成定义与待验证假设

1. 内容完成需要十二模板及发行变体通过可行性、视觉与回放审核，十二奖品皮肤与六机关的映射一致，三章与六角色的触发 ID 不缺失，练习/挑战不污染正式存档。
2. **待验证 H-C01**：每章两种新机关的引入不会压过投掷学习；若玩家只记说明卡而不看轨迹，应减少同时引入而不是增加剧情解释。
3. **待验证 H-C02**：一摊两次调整足以让玩家补救一次错误并试一种变化；需要超过两次才能理解的模板应调整默认朝向和教学，不先加预算。
4. **待验证 H-C03**：十二模板足以提供一局的成长与综合考题；重玩若只剩背角度，应优先改善公开布局与取舍，不直接扩成几十种机关。
5. **待验证 H-C04**：普通圈的可行窗口对键鼠、手柄与慢速瞄准都可学习。若某设备需要隐藏吸附才能通过，应修正输入和共用容差，再回测全部模板。
