## 1. 视觉方向与读图优先级

1. **风格建议**：规则平面为二维侧视，按 09 的固定正交 2.5D 方案展示，纸片拼贴轮廓配手绘旧物纹理。架空河港旧物夜市温暖但不豪华：补丁帆布、手写价签、修理留下的铆钉、货站刷漆编号和河面反光，传达「旧物能修、机会能练」。避免把旧物统一画成污黑垃圾，奖品需要让玩家想观察和保留。
2. 画面分为三层：背景环境最低对比；六槽物体及功能标记中等对比；飞行圈、接受区与输入焦点最高对比。装饰不能盖住轨迹、合法接触面、目标接受区或机关剩余耐久。
3. 桥脚章采用暖灯黄、青灰桥影与赭红补丁；货站章采用灰蓝金属、米白标号与橘色工作灯；江心章混合两套旧物主题，以水面冷色和摊位暖灯区分远近。章色不改变功能色。
4. 场地显示二维几何关系，不用透视缩放让远端槽显得实际更小；目标接受高度和功能区依真实配置绘制。背景可以透视，六槽的判定与投掷平面保持平直。
5. 输入信息优先于情绪动画。圈命中后先确认判定，再给奖品闪动；不得先播放中奖特效再改判失败。失败不播放嘲笑、惩罚红屏或角色责备。

## 2. 颜色、形状与状态语义

1. 现金使用金色圆点与「当摊回款」文字；跨摊余额使用钱袋图标与「钱包」。二者必须分区展示，即使数值一样也不只靠颜色区分。
2. 普通圈是单线圆环，重圈是双线圆环与实心配重记号，宽轻圈是宽外轮廓与空心轻量记号。库存卡上写完整名字；飞行中的同类标记不因美术主题变化。
3. 风扇用平行箭头，反弹板用折线箭头与法线，挡风罩用拱形边界，导向滑槽用入口圆点和出口尖箭头，拨片用短转轴与拨动箭头，缓冲垫用压缩波纹。玩家通过轮廓和方向就能区分六种功能。
4. 新奖品使用「未领取」价签；已留场机关使用扳手标记及剩余耐久；自有机关另有小行李标记。当前选择加双层边框与焦点箭头，不能只有发光效果。
5. 接受区使用上方入口的开口轮廓和向下箭头；侧撞点显示短横叉，落地显示水平接地点。用「从上方进入」「侧面碰撞」「落地」「越界」四种文字反馈代替笼统的「未中」。
6. 可用机关显示连续作用轮廓，触发时高亮对应作用区，耗尽时使用斜纹加「耐久 0」。挡风罩最后一点耐久已支付的本圈保护按 04 继续，在区内显示「本圈仍受保护，下圈失效」，本圈结束后才完全切到耗尽表现；复用罩区叠层和文字，不新增一套资产。关闭机关复用待机图，加虚线作用轮廓与「关闭 / OFF」文字，不增加动画；关闭不等于移走，具体碰撞仍按 02/04。确认开摊后切换开关耗一次调整，操作前显示消耗。不能靠全灰表达全部状态，否则玩家分不清能否转向、是否有实体碰撞和为何失效。
7. 风况使用固定方向箭头、等级文字和作用范围；方向、范围与机关作用区保持不同线型。正式局基础轨迹预览按 02，不把装饰线画成完整预测命中路线。
8. 错误提示用图标与文字就近解释；红色仅作补充。非法拖动显示「这里有新奖品，不能移动或覆盖」，保留原机关位置且不扣调整次数。

## 3. 最小完整美术资产清单

以下数量限定完整建议范围，不是首轮原型必须全部制作。资产 ID 与 03、01 一致；角色/背景以二维图片为主，奖品/圈/机关按 09 制作低模 FBX。下列道具图片尺寸适用于 UI 缩略图或转精灵替代路线，模型面数、材质与导出规格以 09 为准，不为两条路线各制作一套完整内容。

1. **角色**：固定为桑禾（学徒）、鲁青（师傅）、阮灯（协调员）、季澜（转运协作）、叶砧（同期选手）、沈泊（登记员），与 01 一致。每人三种半身表情，共十八张头像，建议源文件每张至少 `768×768`；基础表情为平静、关注、舒展，具体情绪由 01 的人物性格修订。桑禾另做三种场地半身姿态：持圈瞄准、投出、收圈观察；姿态不承担命中判定。其他角色不做可行走战斗模型。
2. **奖品**：十二款 `PRZ-01A/B` 至 `PRZ-06A/B` 各一套主体、功能标记和价签挂点，若导出 UI/二维精灵则建议 `512×512`。每件单独提供物体轮廓、装饰纹理与可转部件；枢轴必须对应槽位锚点，接受区由配置绘制，不画死在贴图里。
3. **机关**：六种功能各一套待机、触发、耗尽状态，共十八个状态定义；优先复用上述十二奖品的分层主体与共用功能叠层，不另画十八套全新物体。两款皮肤共用作用区、接触面和动画挂点；功能识别标记不被皮肤遮掉。
4. **圈**：三种圈主体按 09 制作共用结构的低模；对应 UI 缩略图/二维备用精灵各一张，建议源尺寸 `256×256`。视觉旋转、模糊和残影不改变几何判定，最细轮廓在最低支持显示分辨率仍清晰可见。
5. **场地**：三章各一套背景底图，建议至少 `2560×1440`，并拆前景装饰、摊位桌面和环境层；另做三套摊位边框，每章四模板复用。前景必须留出六槽、发射区和弹道的安全区；不为十二摊分别制作十二张整屏背景。
6. **环境装饰**：十二件可复用的小件：灯笼、灯串、帆布、价签挂杆、工具盒、补丁旗、货牌、绳盘、木箱、轨道标记、渡船剪影、河面反光层。默认均无碰撞，不用动画吸引玩家忽略飞行圈。
7. **UI 图标**：二十四个基础图标：三圈、六机关、钱包、当摊回款、圈数、调整次数、耐久、风况、保存、暂停、播放、慢放、返回、设置、图鉴、帮助、挑战。源文件建议 `128×128`，交付矢量源或高分辨率原图；状态靠叠层复用。
8. **UI 组件**：八组可伸缩组件：按钮与焦点边框、信息卡、数值条、提示框、奖励双选卡、机关操作面板、对话框、结算卡。各提供正常/焦点/按下/禁用状态，不为每页独立绘制整屏图。
9. **字体与文本**：简体中文主字体一套，必要时配同风格数字字体；先核对商业使用与再分发许可。字体缺字、授权和来源记录纳入资产清单；手写装饰文字不能代替核心数值和按钮标签。
10. **交付组织**：每件资产记录 ID、用途、尺寸、枢轴、透明边界、作者/来源、许可证、修改日期、所需功能叠层与动画挂点。不得把互联网上找到的成品图片当作已获授权素材；本轮只给规格，不下载或生成未经授权资产。

## 4. 动画与视觉反馈

1. 桑禾三个姿态转换使用三段短动画，建议每段 `4–8` 个关键帧或等效补间；剧情头像直接切表情，不做全篇口型动画。投出视觉与模拟发射使用同一事件，不能让动画延迟改变输入。
2. 六机关各一个触发动画和一个耗尽动画，共十二段功能动画。风扇转动、板压缩回弹、罩区亮起、槽入口到出口流线、拨片拨动、软垫压缩都必须能关联到真实触发；待机装饰不伪造耐久消耗。
3. 交付十类 VFX：发射、风扇加力、反弹板接触、罩区作用、滑槽导向、拨片触发、软垫缓冲、有效命中、失手接触、机关耗尽。每类都要有低动态版本，可用更短静态标记代替粒子；强闪、震屏和全屏光爆不作为必要信息。
4. 飞行轨迹分「上一投回顾」与「当前投掷痕迹」两种线型；机关触发节点显示编号，展开后读到同一事件日志。只画真实模拟路径，装饰残影的透明度明显低于主圈轮廓。
5. 兑现和留场使用不同动作：价签收入当摊回款区、物体从槽位移除；或旧物原槽转换、显示机关作用区。两类动画不可同时播放，不在留场动画中飘出现金数字。
6. 选用低动态后，保留方向箭头、数值变化与文字状态，关闭镜头晃动、自动视差、飞行残影和大范围粒子。命中接受区与焦点边框仍可读，不使可访问性选项降低规则信息。

## 5. 音乐、环境声与音效

1. **音乐五首**：标题一首、桥脚夜市一首、旧货运站一首、江心集一首、局终回顾一首。章节曲建议可循环 `60–90 s`，标题/回顾可更短；轻打击、拨弦与小型风琴的音色用于河港修理氛围。章末复用章节曲的轻量层变化，不增加三首独立战斗曲。
2. **环境循环三条**：桥脚水流与远处摊声、货站空棚风声与轻金属响、江心码头水面与绳索响。声音仅包装已公开环境，不用突然风噪暗示未登记的风况变化。
3. **短音效二十六条/逻辑事件**：三圈发射声；六机关触发声；有效命中一条；侧撞、落地、越界各一条；兑现与留场各一条；合法调整与拒绝调整各一条；机关耗尽一条；UI 移动、确认、返回各一条；入摊一条；达标与失败各一条；文字推进一条；商店购买一条。音效变体可以调音色，不能使玩家把同一功能当作随机强弱。
4. 连续接触按事件去重与音量限制处理；例如同一圈同一板的重复贴面不能不断轰鸣。音效只随已确认事件播放，不在预测轨迹上提前提示命中。
5. 不纳入完整角色配音。对白默认文字，文字推进声可以关闭；关键规则不只存在于声音。若以后加配音，另行评估语料、版权、录制成本与可跳过性。
6. 主音量、音乐、环境、音效分别调节；暂停与回放降低环境音但不改变模拟。字幕或事件提示对应关键声音，静音后仍能分清命中、消耗与失手原因。

## 6. 屏幕与信息架构

1. 基准设计画布为 `1920×1080` 横屏，最低可读布局按 `1280×720` 验证；更宽比例优先扩展装饰背景，不拉伸场地标尺。不同分辨率与实际平台支持范围以 00/06 为准。
2. **标题页**：继续、开始新局、练习、固定挑战、图鉴、设置。存在正式局存档时强调「继续：第 X 章 / 第 Y 摊 / 当前阶段」；新局对当前进行中记录的处理按 06 说明，只有实际会替换记录时才显示确认。
3. **章节页**：显示章名、四摊进度、钱包和最多两件跨摊自有机关，未到达模板用标题和锁状态，不隐藏正在挑战的规则。章末剧情可跳，跳过仍执行相同已确认奖励事务。
4. **准备页**：先显示圈库存、公开风况、固定六槽奖品候选及自有机关耐久，再允许布置最多两件合法自有机关。耐久 0 的携带机关说明「维修后才能预装」，非法安装不占槽或扣资源。预装只覆盖对应槽的候选，其余槽不重排或重抽；取消预装恢复原候选，并同步预览实际新奖品、兑现总值和回款目标。点击「开摊」确认时列出已安装数量、实际新奖品数、冻结目标和可用调整次数；确认前免费布置，确认后即按调整预算计次，不以是否已经首投区分。未解锁品类按 03 的确定性映射显示实际候选，不能展示成已可选库存。
5. **主场地页**：左上为「当摊回款 / 目标」与钱包两个独立块；右上为剩余圈、调整次数、风况；左下为圈类型、角度、力度、精细调整开关；右下为本阶段主操作。六槽与中部弹道区域不被固定 UI 遮住。
6. **机关详情面板**：点击/聚焦槽位后显示功能、方向、剩余耐久、作用区、开关状态和可执行操作。「开摊」确认前允许免费安装/拆下并设置朝向与开关；确认后给 02/04 允许的移动、交换、转向与开关操作，计次以 04 为准。切换开关的按钮写「关闭/启用（消耗 1 次调整）」；其他操作同样先显示实际消耗，非法操作不扣预算。关闭不清空槽位，不重置耐久。
7. **奖品处置页**：命中后只突出当前奖品，两张同层级选卡：「兑现 +X 当摊回款，移走奖品」与「留场：机关名，+0 回款，占用此槽」。显示选择后当摊回款及差额、耐久和当前槽位，按钮不预设一个更醒目的“正确”答案。
8. **摊间页/商店**：先显示上摊结算和带走名单，再打开 04 的公开商店。钱从钱包扣，商品卡注明费用和效果；不暗示消费会倒扣已经达成的当摊回款。点击购买先显示实际变化，再确认一次，交易结果随 06 的保存事务处理。
9. **零圈清算/补救面板**：最后一圈的结果与处置先完成，再显示当摊差额、可拆卖机关的来源和合法残值，以及 04 允许且仍有资格的补救买圈。按钮写明钱包费用、能否计入本摊回款和剩余次数；无资格项说明原因，不添加免费重试。达标可结算；未达标且补救用尽、钱包不足、可得回款不足，或玩家明确拒绝继续时，按 04 确认失败。旧机关可拆卖补充钱包购买补圈，但其残值不计当摊回款。已结算摊不能通过此面板复活。
10. **摊结算页**：达标/未达标、目标与实际新回款、使用圈数、命中和失手、处置记录、最终带走选择。达标后最多带走两件按 02 确认，耐久原样展示；不把自动选择两件作为默认最优构筑。
11. **局终页**：完整十二摊或失败位置、章节回顾、关键投掷事件、练习入口、新局/标题。失败文案区分「圈用尽、合法清算与补救完成后仍差 X」「主动结束且未达标」等真实原因，不写笼统的“破产”而忽略钱包。
12. **暂停页**：继续、操作说明、设置、查看上一投、保存退出。飞行可暂停和 0.5× 观察；暂停弹窗不得接收投掷输入。保存退出使用 06 的安全边界，界面说明恢复位置；飞行中恢复继续同一投的已存输入和结果，不返还圈、不再次消耗耐久或领奖。
13. **图鉴、练习与回放**：图鉴记录已见的圈、机关、奖品皮肤和角色；练习显示所选快照与「不发放收入」。回放标注「结果回放，不能领奖」，关闭正式投掷/购买/处置入口；版本不兼容时按 06 提示，不按当前参数重算并发奖。图鉴只介绍功能与公开来源，不出现未经验证的通关率、隐藏稀有度或抽奖话术。

## 7. 开场教程与剧情呈现

1. 首次启动先进入标题，选择新局后可播放 01 的短开场；开场有「跳过」和「稍后在图鉴查看」。一屏对白建议不超过两到三行，字幕可立即显示全句；不得强制等打字机效果完成才能推进。
2. 可跳过的独立练习依次展示：选目标看接受区 → 改角度/力度 → 投出并看落点 → 兑现/留场的差别 → 查看机关作用区。练习不把额外钱、圈或机关带入正式局；跳过不惩罚玩家。
3. 正式局提示与场地事件同屏：第一次失手显示可解释的接触标记；第一次留场高亮「回款未增加」；第一次耐久归零显示「该机关已耗尽」。挡风罩本圈已付保护尚在生效时改为「本圈仍受保护，下圈失效」，不能让耗尽提示否认当前真实保护。一次性提示可关闭，也可在帮助重新打开。
4. 叙事只在入章、准备、摊间和结算阶段出现。飞行时不抢焦点、不盖圈、不新增角色对话选择；玩家正在瞄准时不会自动弹出长剧情。
5. 章节对白引用 01 的触发条件和实际结果；跳过剧情只跳展示，不跳经济事务。剧情和关卡可独立修订，禁止对白脚本直接修改奖品值、圈数或机关耐久。

## 8. 键鼠与手柄可达性

1. **键鼠默认映射建议**：鼠标点击目标/机关，滑条或拖动瞄准控件调整角度与力度；`A/D` 调角度、`W/S` 调力度，`Space` 投掷，`Tab` 循环交互焦点，`Enter` 确认，`Esc` 返回/暂停。精细调整使用可锁定的独立按钮和可改绑快捷键，不强制长按组合键。
2. **手柄默认映射建议**：左摇杆或方向键移动 UI 焦点；瞄准状态用方向键分别改角度与力度；左右肩键切圈种，右扳机投掷；南侧按钮确认、东侧按钮返回，菜单键暂停。图标按实际设备映射展示，不将某一种品牌按钮文字写死在教程。
3. 机关移动通过「选择机关 → 选择目标空槽/可交换机关 → 预览 → 确认」完成，键鼠也支持这一流程；拖拽是快捷方式，不能成为手柄无法操作的唯一入口。转向用面板控件，作用区实时预览。
4. 处置页只用水平双选且默认焦点稳定；回到主场地时沿用上一次瞄准输入。飞行中的方向键不偷偷调下一投，动画结束后也不执行残留的投掷输入。
5. 输入阶段切换时要求释放确认/投掷键再接收下一次关键操作，防止按住投掷键跳过处置或连续耗圈；此约束不增加强制等待动画。奖品领奖事务以 06 保证单次执行。
6. 所有主流程提供明确当前焦点、返回路径和本阶段主动作；手柄全程能进入设置、查看详情、改机关、购买、处置、复盘和离开。光标位置不会被鼠标静止位置抢回。
7. 支持以动作名改绑并保存，检查冲突和必要动作是否仍有入口，保留恢复默认入口；设备切换后显示相应提示，不改变当前投掷事务。手柄断连暂停观察并显示键鼠/重连入口；摇杆死区和重复输入速度可调，停止输入后角度/力度不能漂移。
8. 瞄准没有实时倒计时，不要求快速连续按键。快速试投依赖重用上一投输入与清晰反馈，不依赖弹窗自动关闭或高手反应速度。

## 9. 可访问性与低负担体验

1. **文字**：主要中文信息使用清晰字体，在最低布局中正文有效字号建议至少 18 px，标题至少 26 px；提供文字/UI 缩放并回测换行、按钮高度和图鉴滚动。关键钱数、圈数与耐久不嵌进纹理。
2. **色觉**：提供高对比模式和色觉辅助预设，但每一种圈、机关、状态与价格字段都同时有名称、图形或线型。双色皮肤不承担唯一规则信息。
3. **低动态与低闪**：关闭震屏、视差、强闪、残影与密集粒子；命中和耗尽用静态图标加文本替代。避免快速明暗频闪，用持续轮廓而非闪烁召唤注意。
4. **慢速瞄准**：降低滑条/摇杆输入变化速度、保留精细调整切换、支持数值步进和上一投输入复用；不改变圈真实速度、命中容差或经济难度。具体输入精度以共同量化规则实现。
5. **飞行观察**：提供正常速度、0.5× 观察和暂停；这些只改变观看与模拟推进速度，不改变轨迹结果、圈消耗或挑战合法性。快进必须保留关键接触反馈，不能略过最后一圈处置。
6. **声音**：分别调音量，提供关键事件文字提示和全部剧情字幕；关掉文字推进声后仍可看全句。不得用左右耳声像作为唯一风向信息。
7. **认知负担**：将即时信息维持在当摊目标、剩圈、当前机关作用和处置选择四类；钱包、详细事件和图鉴折叠展示。规则卡先给一句功能，再展开参数，不用一屏六个长术语压住场地。
8. **操作容错**：非法操作不耗资源，商店交易与关键处置先预览再确认；暂停页可以读规则。增强轨迹辅助须显式开启并显示状态，练习和显式辅助按 02 可给完整辅助轨迹，普通正式局仍使用基础粗略预览。主线辅助不扣经济奖励，本地挑战记录保存辅助配置；辅助展示与实际模拟使用同一轨迹规则，不承诺隐藏修正后的命中。
9. **可达范围**：首版要求键鼠和手柄完整可达，不把完整屏幕阅读器、全盲投掷支持或移动端触控描述为已支持。相关扩展需独立验证；本轮为已建议的可访问性建立验收用例。

## 10. 中文文案样稿

文案为助手建议，人物语气最终由 01 审核；`{}` 为真实状态值占位，不在发布版显示未替换变量。

1. 入摊标题：「桥脚夜市 · 第 {stall} 摊」。规则摘要：「本摊回款要达到 {target}。还有 {rings} 个圈，确认开摊后可调整机关 2 次。」
2. 风况：「本摊风况：{direction} · {grade}。本摊内保持不变。」作用区提示：「箭头显示风的方向；虚线显示影响范围。」
3. 瞄准提示：「先看落点，再改一项。角度影响抛出的方向，力度影响出手速度。」上一投：「复用上一投输入」，不是「复制必胜投法」。
4. 命中标题：「套中了：{prize}」。兑现卡：「兑现 +{value} 当摊回款 / 移走此奖品」。留场卡：「留场：{mechanism} / 本次回款 +0 / 占用 S{slot} / 耐久 {durability}」。
5. 处置差额：「兑现后，本摊还差 {gap}。」已经达标：「兑现后已达到本摊目标。」留场提示：「机关能帮助后续投掷；这次不增加回款。」
6. 失手反馈：「从侧面碰到目标，需要从上方进入接受区。」「圈落地了，落点在 S{slot} 前方。」「圈离开场地，本投结束。」只在对应真实事件出现。
7. 耗尽提示：「{mechanism} 耐久已用尽，不再提供作用。它仍占用此槽。」挡风罩本圈已付保护例外：「挡风罩耐久为 0，本圈在区内仍受保护，下一圈失效。」非法移动：「这里有新奖品，不能移动或覆盖。先兑现腾出空槽，或选择另一件机关交换。」
8. 达标选项：「已达标。现在结算」和「继续投剩余 {rings} 圈」。说明：「剩余圈不会自动变成现金。」
9. 失败结算：「圈已用尽。本摊回款 {receipts} / {target}，还差 {gap}。」辅助行：「钱包余额是跨摊资金，不能直接补这摊的回款。」
10. 练习标识：「练习 · 不发放收入」。重置提示：「恢复这次练习的初始布置、奖品与耐久。」固定挑战：「同一预设，同一规则。暂停和慢放可以使用。」
11. 鲁青提示样稿：「别急着换一整套。先看上一圈在哪儿拐了弯。」阮灯处置提示样稿：「兑奖还是留着修？两条路都写在牌上，你来定。」这两句只包装规则，不保证选择成功。
12. 保存提示：「正在保存……」「已保存」及失败时「保存未完成：{reason}。{safeAction}」。恢复提示：「继续第 {throw} 投，已扣除的圈不会再次扣除。」保存失败应由 06 提供保留会话、重试保存或恢复校验备份等实际可用操作，不承诺数据已经写入；已提交事务不回退重发，不让玩家通过重复确认、恢复或阅览再次领奖。

## 11. 视听与交互验收

1. 在最低分辨率和最大 UI 缩放下，六槽、圈、目标接受区、圈数、回款差额和当前操作均可见；提示不会覆盖刚发生的接触点。
2. 只看静止截图即可区分六机关、三圈、新奖品/自有机关、可用/关闭/触发/耗尽；关闭颜色和声音后仍能完成一次处置并解释失手。关闭状态复用待机资产，关开均按公开规则计次。
3. 完整键盘与完整手柄分别从标题完成一摊、非法移动、合法调整、商店购买、局终和回放，不依赖鼠标拖拽或隐藏快捷键。
4. 正常速度、慢放、暂停继续和低动态模式复现同一圈的输入、接触、命中、消耗与处置结果；视觉展示不参与经济判定。
5. 跳过所有剧情与教程后，正式局资源、圈数、奖励和回款规则一致；重新打开帮助、回放、恢复待处置或重复确认都不会重复发奖。飞行中断仅恢复同一投；关开与重映射不重抽候选或重置耐久。
6. 十二奖品皮肤与六功能、UI 卡片、音效和真实作用区一一对应；资产表、文本键与事件 ID 能追溯到版本和来源。
7. 尚待验证：基础轨迹预览是否过度替玩家瞄准；无配音的剧情阅读是否打断重玩；十八表情是否必要；十二模板的视觉是否容易混淆。若成本或测试结果要求缩减，优先合并装饰与表情，保留判定、输入和处置信息。
