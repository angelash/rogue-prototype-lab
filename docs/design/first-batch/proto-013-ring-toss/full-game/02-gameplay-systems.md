# 套圈改造摊：完整玩法系统

版本：v0.6；日期：2026-10-09（Asia/Shanghai）。既有依据为 [v0.1 设计](../design.md)。用户最新明确采用真实三维、斜视地摊、从镜头前向前抛圈；旧二维侧视方案作为历史保留。具体机制与数值仍为助手建议，经济/标量参数来源为 [04 数值经济](04-economy-and-balance.md)；当前三维几何合同见 [场景方向](../../../../development/proto-013/3d-scene-direction.md)，实际实现与验证见 [开发记录](../../../../development/proto-013/2026-10-09-p0.md)。

## 模式与一局结构

主线巡回从新局开始，依次经过 3 章×4 摊；每章前三摊考察基础规则组合，第四摊进行主题挑战。完成一摊后进入结算、可选短对白与下一摊预览。每摊开摊确认前均有可选准备商店，包括首摊；首摊钱包为零，不赠送购买资金。商店只是准备界面的页签，不构成额外摊位。

练习模式可选已解锁模板、圈型与机关，提供无限重试及完整轨迹辅助，不产生钱包、笔记或主线奖励。固定种子挑战采用冻结内容与参数版本，在本地记录结果和配置；可访问性辅助会在记录上显示使用情况，不影响主线游玩资格。

新局重置局内钱包、携带机关和耐久。已见剧情、图鉴、设置及局外解锁保留。完整剧情衔接见 [01 叙事人物](01-world-story-characters.md)，不把故事推进变成永久损失。

## 六槽与关卡准备

每摊始终有 S1–S6 六个固定槽位，槽中只允许一种占用：新奖品、玩家自有机关或空位。奖品有几何接受区；机关有独立公开作用区，不再把已变成机关的物体当作可重复领奖的奖品。

首组三维摊场建议把六槽布置在地面两排三列，使用稳定槽位身份和实际三维锚点。左右与前后都参与瞄准、距离和接触，不把旧单排六槽的横坐标映射当成新场景已经可达。精确布局按当前版本化三维配置记录；以下占槽、来源与经济次序继续适用。

跨摊收存最多 2 件机关，耐久延续。准备时可以选预装 0–2 件，其余保留在携带栏；预装占六槽中的真实位置。模板为六槽预留陈列，装入自有机关的槽不再生成对应新奖品，不存在六件新奖品之外又免费塞入两件机关。

关卡候选以固定种子和陈列规则确定。玩家调整预装时，不抽取新的随机奖品；预览同步显示实际新奖品、兑现总值、目标与可行提示。准备完成后冻结场景与现金目标，直到本摊结算都不因拆卖或换圈重算目标。

点击“开摊”确认之前布置自有机关免费；确认即生成实际新奖品、冻结目标与初始布局，进入瞄准阶段。开摊后、包括尚未投第一圈时，每摊只剩 2 次调整；仅允许机关移到空槽或两机关互换，不能挪动未赢得的新奖品。转向、开关或换槽的计次规则统一列于 04，不能通过返回菜单或撤销绕过预算。耐久为零的旧物须先修理才可预装；关闭机关仍有实体占位，不能视为免费的空槽。飞行中不修改布置。

## 一次投掷的完整状态

`准备 → 瞄准 → 确认发射 → 飞行 → 结果 → 奖品处置 → 摊内选择 → 下一投/摊结算`。

- 准备阶段选择合法装备与初始布置，显示全部费用和当前目标。
- 瞄准阶段调左右朝向、仰角、力度与当前圈型；可取消或暂停，没有操作读条倒计时。出手点位于玩家近处，圈向前飞入地摊纵深；相机固定斜视，不通过自由走动改变投掷位置。
- 发射前校验圈数、输入、配置和阶段；确认后只扣一个真实圈并生成本投唯一编号。
- 飞行按固定模拟次序执行。玩家可暂停观察或慢速播放；这只改变观看速度，不改物理步长、碰撞或实际结果。
- 首次有效奖品命中结束本圈判定；没有命中则在落地、越界或最长模拟时长结束时记失手。
- 命中奖品时必须完成“兑现/留场”选择，之后才能下一投；取消面板不会免费重掷。
- 最后一个圈也先完成命中和处置，再进行现金目标检查；不因圈数刚变零就提前剥夺领奖。

同一投的发射、机关消耗、奖励和结算都是一次性事务。读档/回放只重现结果，不重新发钱；回放界面与正式输入隔离。

## 投掷与命中合同

当前采用真实三维场景与三维规则状态。左右朝向、仰角与发射速度产生稳定空间轨迹；物件的可见作用体积、公开风况和接触改变它。奖品、接受锚点、机关、地面和边界在规则与画面使用同一配置；相机投影不参与领奖。没有隐藏命中概率、背后修正或随输赢暗改参数。

有效命中要求圈从目标的公开三维接受区上方下降，中心与圈/立柱对应容差满足当前几何合同。侧擦、从下方进入或实际实体阻挡按真实接触说明；仅被装饰/相机遮住不是额外失败条件。规则接受点与可见套入位置保持一致，不夸大远排接受范围。04 的旧 XY 接受线、单排坐标与二维接触是历史基准；新的水平/纵深接受与接触几何需记录独立版本并重新验证，不以旧二维样本证明三维正确。

机关接触/进入、奖品接受和环境终止共同进入事件序列，按发生时间再按稳定对象编号排序。找到当步首次有效事件后处理，再模拟剩余子步；有效奖品接受则立即结束，不让后来发生的机关事件倒改中奖。接触次数和最长飞行时长有上限。风扇的同投单次触发、反弹板的接触去重防止永动循环。

基础预览只展示未经过机关的粗略轨迹区间，不保证命中。落地后可看实际轨迹与事件序列；完整辅助轨迹仅练习或显式辅助设置提供，其效果不能当成基础投掷已经好学的证据。

## 圈型与六种机关

圈型为普通圈 RING-01、重圈 RING-02、宽轻圈 RING-03。普通圈是基础可行性基准；重圈与宽轻圈通过质量、受力反应及内径形成取舍，而非降低重圈重力或提高隐藏命中率。圈型解锁只提供选项，进入摊后更换的代价见 04。

- MEC-01 风扇：进入区域时施加公开方向的力/速度变化，同圈最多触发一次。
- MEC-02 反弹板：接触公开板面改变方向，消耗耐久并去重接触。
- MEC-03 挡风罩：在公开区域抵消规定的外部风作用，本身仍是有空间代价的物件。
- MEC-04 导向滑槽：捕获满足入口条件的圈，沿固定可见路线引导后按公开出口释放；不自动传送去任意奖品。
- MEC-05 拨片：圈满足正面接触条件时获得固定方向推动；首版没有周期摆动，触发依据可见接触，不加入不可见随机。
- MEC-06 缓冲垫：吸收规定接触能量并改变反弹，以可见几何形成另一种投法。

每件机关的开关、触发限制与耐久沿 04 的建议定义；三维有效面/作用体积及方向映射使用本轮版本化合同，避免把二维角度直接误当任意空间旋转。角色故事和奖品皮肤不得附加未登记能力；组合顺序由实际轨迹决定，不按菜单装备顺序制造额外连击伤害。首组仍仅普通圈、风扇与反弹板，后续四机关不是本次已实现项。

## 赢物、兑现、留场与清算

命中前新奖品归主办方，命中后进入待处置。兑现一次性增加钱包及当摊合格收入，物体移走成为空槽；留场不领取兑现现金，在原槽改成相应机关，不额外花调整次数，但占槽并开始有限消耗。

已留机关可按公开残值拆卖；这终止其能力且不会再次获得全额奖品价值。当摊新物的合法残值可计入当摊收入，自上一摊带来的旧物残值只加钱包、不计当前过关目标。每件物体带来源摊号和唯一编号，避免通过跨摊重新标成新奖品刷收据。

钱包 `wallet` 与当摊收入 `stageReceipts` 分开。旧钱包不能直接填目标，商店支出不倒扣已完成的收入。现金配额按准备结束时的实际新奖品计算并冻结；具体公式及保护条件见 04。

圈数用尽进入结算前，可按规则做一次明确清算/补救，不生成无限循环。补救买圈有价格、次数和资格限制；不能在结算后复活已结算摊。达标后可继续投剩圈，或主动结束；剩圈不变现。失败清算后结束本局，结算数据一次提交。

摊结算显示达标与否、合格收入、钱包、奖品去向、使用机关和关键失误。成功时最多收存 2 件机关；其余需明确拆卖或弃用，不自动变成局外仓库。下摊初始陈列与额度重新生成，旧耐久不自动刷新。

## 成长、随机与重玩

局内成长来自新的圈型选择、赢物、携带配置及可支付的修理/补救。局外“工坊笔记”只购买 04 列出的圈型与机关选项；模板按首次到达开放练习与本地挑战，故事图鉴按实际见闻登记，不另收笔记。没有永久命中率、免费的耐久重置或无限起始资金。

随机对象限定为可审核布局变体、公开奖品候选和已预告风况。十二个模板固定依次出现，不随机跳过教学摊。当前摊全部规则与目标公开；不能临投时才改变风或奖励。每份布局保留普通圈且无稀有机关的合法兑现路线；补救用于玩家失手或处置选择，不代替生成器拒绝无解布局。

每个模板最多使用三份已审核变体，由本局种子确定，不加入未定义的路线分岔。下一摊预览展示固定模板、候选陈列和风况，供玩家决定携带与预装；不能通过开关菜单刷新。具体出场、未解锁替换和构筑例见 [03 内容关卡](03-content-and-levels.md)。

## 边界与验证

满槽时不能覆盖对象；无调整次数不能免费转向；失效机关不得暗中继续施力；菜单重复确认不重复奖励；现金和耐久不足则整笔交易失败。长暂停后仍使用原场景版本，不按墙钟时间让预告风失效。

v0.1 的 RNG-R01 至 R06 继续作为基础规则门槛；完整版额外检验跨摊来源、现金双账、6 槽守恒、有限补救、解锁公平和存档幂等。具体场景及体验去留条件见 [07 制作验证](07-production-and-validation.md)。

此前二维 P0 的实测按原版本保留；新场景需在真实 Player 核对两排瞄准、空间接受/接触、可见锚点、遮挡及暂停/回放，实际状态只引用开发记录，不借历史通过结果标记三维通过。
