# 013 套圈改造摊：完整游戏设计

版本：v0.4；日期：2026-10-09（Asia/Shanghai）。在完整蓝图与 Unity PC/Steam 方案上补内容与能力审计、生产验证合同、缺失交互和音视频路线；工具隔离探针通过，游戏尚未实现或试玩。

## 本轮要求与版本边界

用户明确要求先对套圈改造摊补充完整游戏设计，并进一步指定 Unity、使用本机已安装版本、PC 单机、目标 Steam；参考 highschool 与 world-of-claudecraft，评估 Blender 和图像生成的资产路线并完善开发能力。本轮又明确后续开发全部由助手处理，现在检查并整理不足。已核实本机 Unity 为 2022.3.62f3c1、Windows x64 Mono 模块存在，Blender 为 5.2.2 LTS。题材、商业模式、预算、工期和具体美术仍由助手提出，未记为用户定案。

本稿提出“回湾河港旧物巡回试摊赛”：桑禾用稳定可练习的投圈赢得旧物处置权，兑现完成回收合同，或改成机关改变下一投。故事把现金与留场的两种用途接到人物关系和旧物来历，不为不同处置附加道德惩罚。

新增的世界设定、六人物、十二摊、三圈、六机关、所有价格与物理初值、局外解锁、视听规格、制作路线均为助手建议。原型 [需求 v0.1](../requirements.md) 和 [设计 v0.1](../design.md) 保留；其 1 圈、2 机关、6 槽的最小验证范围继续作为前置门槛。01–04 保留 v0.2 规则正文，08/11 等基线保留各自版本；05/09/10 和新 12/13 为 v0.4 审计补充。文档扩充不改变权威参数，也不使基础原型自动扩大到全内容。

推荐制作路线为固定正交 2.5D：Blender 制作低模圈、奖品和功能机关，图像生成制作二维人物、远景与装饰，Unity 原生 UI 显示文字和功能标记。投掷使用纯 C# 二维模拟，模型只读结果；同一 Blender 源可转精灵作为替代路线。先用少量样件验证读图与导入，再冻结管线和量产资产。

## 本版共同规则

- 一局 3 章×4 摊，共 12 摊；固定模板顺序，每模板最多 3 份审核变体，首版最多 36 份布局数据。商店与对白不增加关卡数量。
- 场地总数 6 槽；跨摊收存最多 2 件旧机关，耐久和获取价快照延续。预装占真实槽位，实际新奖品是 6 减预装数量。
- 准备阶段候选固定在六槽。点击“开摊”前免费布置，并可花钱包金币修理/购买；确认后冻结新奖品、目标及初始布局，此后共 2 次机关调整。
- 普通圈是全部关卡的可行性基准；重圈和宽轻圈是有限替代。基础圈数按章 8 / 7 / 6，没有隐藏抓取概率。
- 命中奖品全额兑现与留场互斥；留场后只能取得一次公开残值，不能再全额兑现。钱包与当摊回款分账，旧物、旧钱和商店物不能填当前回款。
- 目标按实际新奖品与基础圈数计算后冻结；最后一圈先完成奖品处置，再清算或进行有资格的一次补圈，最后才判成功/失败。
- 故事在安全边界呈现，可跳可复看；新局重置现金与实物，保留已见故事、图鉴、设置和工坊笔记解锁。
- 练习与回放不产正式奖励；暂停/慢放不改物理。读档不重掷布局、不返还已发射圈，也不重复发钱或耐久变化。
