# 013 套圈改造摊：完整游戏设计

版本：v0.6；日期：2026-10-09（Asia/Shanghai）。完整蓝图已衔接首个真实三维单摊 P0，Unity EditMode 48/48 通过（旧二维 30 项＋新三维 18 项），Windows x64 Mono 构建已完成，隔离相机图已生成并目检；精确构建、图与 Player 结果见 [本轮开发记录](../../../../development/proto-013/2026-10-09-p0.md)。相机图不含 IMGUI。旧二维窗口 QA 保留为历史；当前桌面观察到锁屏，三维正常键鼠 QA 尚未通过，规则测试和镜头渲染不代替实际操作验收。

## 本轮要求与版本边界

用户明确要求先对套圈改造摊补充完整游戏设计，并进一步指定 Unity、使用本机已安装版本、PC 单机、目标 Steam；参考 highschool 与 world-of-claudecraft，评估 Blender 和图像生成的资产路线并完善开发能力。随后明确后续开发全部由助手处理，整理不足，并要求参考 live-avatar 音频能力、筛选 WoC 音频后按计划开始开发。当前又明确要求真实三维、斜视场景、玩家近处向前抛圈，像地摊；旧二维占位和固定正交 2.5D 已替换。其他五项的实际开发顺序仍未指定。已核实本机 Unity 为 2022.3.62f3c1、Windows x64 Mono 模块存在，Blender 为 5.2.2 LTS。题材、商业模式、预算、工期、精确镜头和具体资产造型仍由助手提出，未记为用户定案。

本稿提出“回湾河港旧物巡回试摊赛”：桑禾用稳定可练习的投圈赢得旧物处置权，兑现完成回收合同，或改成机关改变下一投。故事把现金与留场的两种用途接到人物关系和旧物来历，不为不同处置附加道德惩罚。

新增的世界设定、六人物、十二摊、三圈、六机关、所有价格与物理初值、局外解锁、视听规格和实施细节均为助手建议；三维视觉方向已由用户明确选择。原型 [需求 v0.1](../requirements.md) 和 [设计 v0.1](../design.md) 保留；其一种圈、两机关、六槽的最小验证范围继续作为前置门槛。各专题保留自己的版本，v0.6 同步当前三维方向和真实工程状态；04 的经济与标量数值正文保持，旧单排 XY 几何只作历史基线，新三维参数入口与证据见开发记录，不使基础原型自动扩大到全内容。

当前实施建议为固定玩家后上方透视镜头，地面六槽两排三列，近处持圈向前抛，暖灯/条纹棚/帆布摊地与轻覆盖 UI，无自由漫游。Blender 制作真实三维圈、奖品和机关，图像生成用于可选二维对白头像、远景或纹理；主场景不转回精灵。纯 C# 三维模拟与视图共用接受/接触锚点，细节见 [三维场景合同](../../../../development/proto-013/3d-scene-direction.md)。先校准首组样件，再扩全量。

## 本版共同规则

- 一局 3 章×4 摊，共 12 摊；固定模板顺序，每模板最多 3 份审核变体，首版最多 36 份布局数据。商店与对白不增加关卡数量。
- 场地总数 6 槽；跨摊收存最多 2 件旧机关，耐久和获取价快照延续。预装占真实槽位，实际新奖品是 6 减预装数量。
- 准备阶段候选固定在六槽。点击“开摊”前免费布置，并可花钱包金币修理/购买；确认后冻结新奖品、目标及初始布局，此后共 2 次机关调整。
- 普通圈是全部关卡的可行性基准；重圈和宽轻圈是有限替代。基础圈数按章 8 / 7 / 6，没有隐藏抓取概率。
- 命中奖品全额兑现与留场互斥；留场后只能取得一次公开残值，不能再全额兑现。钱包与当摊回款分账，旧物、旧钱和商店物不能填当前回款。
- 目标按实际新奖品与基础圈数计算后冻结；最后一圈先完成奖品处置，再清算或进行有资格的一次补圈，最后才判成功/失败。
- 故事在安全边界呈现，可跳可复看；新局重置现金与实物，保留已见故事、图鉴、设置和工坊笔记解锁。
- 练习与回放不产正式奖励；暂停/慢放不改物理。读档不重掷布局、不返还已发射圈，也不重复发钱或耐久变化。
