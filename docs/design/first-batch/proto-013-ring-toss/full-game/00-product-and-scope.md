## 一句话体验与定位

在河港旧物夜市巡回挑战套圈摊：练准一投，赢下旧物，把它折现过关，或改成机关改变下一投。

建议类型为单人、二维侧视、技巧操作与有限构筑结合的轻量肉鸽。每次投掷强调稳定可学习的几何；每摊的机关布置、兑现时机和圈型选择产生策略。故事强调旧物的用途与人与人的协作，不靠大量对白代替动作。

建议主要面向喜欢短局重试、可读物理和有明确代价的构筑玩家。用户已确定 Unity PC 单机与 Steam 目标；建议首发 Windows x64 离线版，验证键鼠与手柄两套输入，采用本机已安装的 Unity 2022.3.62f3c1 与 Windows Mono 模块。触屏及其他系统另开验证。商业候选为一次性购买，价格与具体商业方式尚未确定。

美术建议使用固定正交视角的 2.5D：Blender 制作低模可动旧物，生图制作人物立绘/背景/贴纸，Unity 原生 UI 绘制文字和规则标记。游戏仍使用二维数值规则；模型深度、视觉旋转和装饰网格不改变接受区或轨迹。技术细节见 [08](08-unity-pc-technical-plan.md)，生产规格与替代路线见 [09](09-art-and-asset-production.md)。

一局目标时长建议为 25–40 分钟，单摊约 1–3 分钟；这些是制作与节奏目标，不是已测时长。瞄准和阅读没有实时倒计时，压力来自剩余圈数和当摊现金目标。

## 四个设计支柱

1. **练习有用**：同场景同输入得到同结果，失误能归因于角度、力度、障碍或公开风况。
2. **旧物改变动作**：留下一件机关后，普通圈也能走出新轨迹；组件用途因布局变化，不只是提高命中数字。
3. **兑现有机会成本**：留场失去即时现金、占槽、消耗耐久；现金目标和跨摊携带数量让保留不是恒优。
4. **一眼看懂原因**：落点、接触、触发和消耗都能回看，故事和美术帮助认识物件，不隐藏规则。

## 完整版本内容上限

- 一局 3 章，每章 4 摊，共 12 摊；每章末摊是主题规则考题。商店、叙事和准备界面不另算关卡。
- 12 个可审核关卡模板，有限参数变体；首版不宣称程序生成无穷关卡。
- 每摊始终 6 槽；6 种机关、3 种圈、12 款旧物奖品皮肤。同功能皮肤不改价格、判定或能力。
- 6 名有明确职责的故事人物，3 章主线、开场、结局、失败回流和可跳对白。首版不做复杂恋爱或多结局分支。
- 局内现金与耐久；局外“工坊笔记”解锁选择和图鉴，不提供永久命中优势。
- 主线巡回、练习和固定种子挑战。挑战仅本地记录，首版没有在线排行或反作弊工程。
- 完整的设置、教程、暂停、输入重映射、存档/续局、回放、图鉴、结算、无障碍选项与错误恢复。

内容定义见 [关卡与内容](03-content-and-levels.md)，权威初值见 [数值经济](04-economy-and-balance.md)。所有地方引用同一份参数，不各自维护价格或重力副本。

## 玩法与叙事的分工

每摊主办方给出公开旧物回收目标和试摊陈列。桑禾参加的是巡回试摊赛，套中物品后才获得处置权；现金来自回收合同，留场则是临时改装权。玩家不是向自己的摊付钱再凭空赚钱。

人物只在阶段边界出现；失败和已见对白可跳，重试不重复发奖励。剧情推进提供下一章的动机，关卡教学依赖可操作场景而非强制大段解释。

## 范围优先级与退出规则

**先验证**：基础圈、风扇、反弹板、6 槽和现金/留场取舍；通过基础动作与因果反馈后才进入纵切。

**纵切目标**：完整一章流程，包含主题挑战、准备/结算、至少一次跨摊携带、存档和最基本故事/音画。此阶段应证明完整循环能衔接，不用完成全部皮肤。

**完整版目标**：再扩至三章和上列固定内容数量，补齐教程、难度、无障碍、保存、内容审核与发布材料。

当前不纳入三维真实套环、软体、多人、店铺经营、开放夜市漫游、真实赌博和联网排行。Steam 安装/启动作为发行验收，成就、Steam Cloud 与平台 API 分期选择，主循环保持离线；详见 [11](11-steam-release-plan.md)。若基础投掷仍不好练，或兑现/留场只有一个答案，停止后续内容制作，先修规则。

## 完整设计的交付标准

每个系统须有状态、输入、输出、成本、异常处理、反馈与验收；每个关卡须有基础圈可行路线、替代选择和缺件补救；每个数值须有单位、适用版本及调参理由；每项资产须有数量、规格与触发；保存与剧情须有可恢复的阶段边界。
