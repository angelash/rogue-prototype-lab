## 目标与依据

让吸起的铁件既是可兑现货物，也是改变下一次吸取位置的工具构件。伸长能触及新目标，但负载、障碍和朝向上的首件规则可能让长结构变得不合适；玩家应有理由主动拆短。

## 最小交付范围

一个离散网格零件箱、4 种铁件形状、固定接点与朝向、单次确定吸附、公开订单和有限电量。只验证吸取、出售/保留、拆卸与重新组合。引擎、设备及地图尺寸待定。

完整循环：读回收订单 → 选落点与朝向 → 预览首件、重量和可达范围 → 吸取 → 出售或留作延长构件 → 调整结构继续拾取 → 交付并复盘。

## 必须具备的需求

- **MAG-R01 网格与形状**：清楚展示磁头、障碍、铁件占格和固定接点；保留构件会改变下一次吸取起点，不能只有长度数值加成而不改变几何结果。
- **MAG-R02 确定吸附**：每次只吸当前朝向上的首个可达铁件，不能跳过不想要的前件直接抓后件；障碍、目标和失败原因均可预览与复现。
- **MAG-R03 负载约束**：总重量与上限可见；超重不能带起，失败不删除目标、不增加库存。空磁头和基础小件可开始循环，不依赖稀有磁头。
- **MAG-R04 货物或工具**：同一物件出售后不能继续提供延长能力；保留时占重量与几何空间。拆下、重排和出售按公开操作成本结算。
- **MAG-R05 电量与补救**：有效吸取、移动/调整和拆装的电量成本可查；提供拆短、换落点或基础出售的合法应对，不把超重当成隐藏抓取概率。
- **MAG-R06 订单与复盘**：显示订单、已交货物和剩余电量；记录结构、目标、承载、操作成本与物件去向，能解释下一吸为何不同。

## 验收场景

- **MAG-A01**（R01、R02）：同落点分别使用空磁头与保留长件，下一次起点与可达目标按固定接点变化，预览和实际命中相符。
- **MAG-A02**（R02、R03）：前方重件、后方目标在同一方向时，超重失败不能跳抓后件；拆短或换落点后的可达目标重新计算。
- **MAG-A03**（R03、R04）：保留物件后总重增加；出售后该物件离开结构、产生一次收入，既不继续延伸，也不重复计入订单。
- **MAG-A04**（R04、R05）：拆下中间件时明确处理其后连接件，不留下悬空免费延长；电量不足时整个操作拒绝且库存不变。
- **MAG-A05**（R01、R06）：在窄缝场景重放吸长件、延伸吸目标、拆短的序列，结构占格、负载和最终交货一致，原因可追溯。

## 验证问题与去留

- **MAG-H01**：玩家能够根据延伸形状预测下一次吸取，而非只按高亮目标试错。
- **MAG-H02**：至少出现主动拆下长件的可解释选择，长结构不会恒优。
- **MAG-H03**：订单变化使同一铁件在出售与留作工具之间产生不同用途。

如果总是越长越好、结构对结果没有实际作用、超重只能重复碰运气、或玩法主要是在菜单整理库存，就停止扩形状并重构。

## 暂不纳入与待定

不纳入连续磁场、刚体堆叠、任意电器拼装、复杂抓斗物理或自动最优寻路。磁头商店与多轮成长在基础几何选择成立后再考虑。四形状的具体定义、重量、电量、出售成本和试玩阈值待校准。
