# 《磁铁拾荒者》夜班工单

2026-11-21 重做版。玩家操作箱顶的磁吊车，把金色菱标标出的零件卸进随车回收斗。第一单只要交一枚重芯。能碰到它的工具，就是箱里那根也可以卸走的长杆。

## 回到原案

已核对原工作簿“方案库”第 32 行 A–Q 列，对应方案 121。D、H 列提出货物可以接上磁头，改变下一次够得到的位置，同时占用承重。J 列把玩家能否预测下一吸、会不会主动拆长件列作验证问题。Q 列写了具体镜头，先吸长螺丝，借它够到箱底，再拆杆交货。F 列还设想用回收所得购买磁头。此次重做选择前一段做成五张固定工单，固定轨道、回收斗和工单顺序均是本次的设计决定。[原始工作簿](../../../../sources/chatgpt/熟悉与意外_120个游戏方案.xlsx) · [需求 v0.1](requirements.md) · [设计 v0.1](design.md)

## 旧版的三个问题

**最先教会玩家的是怎样处置货物。** 同一个“工坊零件”订单有两条已记录的解。长杆路线需九个命令，其中两次选择保留、一次拆段、两次出售。空头路线十二个命令也能交齐，两条路线的钱包都是 15，余电相差 3。第一次接触游戏的人完全可能学会独立搬回两件货就收工，错过第二吸从长杆末端出发的瞬间。旧版的两个解有对照价值，教学首单却需要把核心动作交到玩家手里。[旧版黄金输入及结算](../../../development/proto-121/implementation-plan.md)

**自由移动和返回回收区占了太多操作。** 旧版重料订单的一个可行样本长达 32 个命令，包括多次平移、整体旋转和回程。它展示了带货避障的能力，也让一次换方向和一次改变工具形状争夺注意力。新版把吊车固定在箱顶横轨，接点决定磁线的朝向。回收斗随车移动，按一次只收链尾。玩家失去了从任意方向接近同一零件、拆中段暂存再装回的自由。作为交换，一眼就能看出眼前的问题究竟要换列、延长、转弯还是卸重。[旧版操作](../../../development/proto-121/input-and-ui.md) · [现行动作与结算](../../../../prototypes/proto-121-magnet-scavenger/game/MagnetScavenger/Assets/MagnetScavenger/Core/ShiftGame.cs)

**箱面标记和结算价都在抢注意力。** 旧版初态画面给物件叠了编号、入口黄环、出口箭头与底牌，还要辨认回收区和暂存区。旧版工资在两张独立订单之间清零，买磁头的支出只存在于工作簿蓝图。新版棋盘按行列正对玩家，菱标只表示订单件，虚线画到射程内的首件或阻挡处，前方为空时标出能扫到的最远格，角框标出首件，实心吊链显示下一次起点。卸下目标件计入交货，普通件卸下能腾出位置和承重，两者都永久离开本单料箱。去掉钱包后，交货进度、电量和载重各对应一个会影响下一步决定的问题。[旧版初态实机相机图](../../../development/proto-121/evidence/scene.png) · [现行棋盘绘制](../../../../prototypes/proto-121-magnet-scavenger/game/MagnetScavenger/Assets/MagnetScavenger/Presentation/ShiftBoard.cs)

## 玩家操作

- **看单。** 找金色菱标和工单上的零件名。散件在箱内都折叠为一格，吸起长杆才展开两格。短片与弯头各重 1，长杆重 2，重芯重 3。弯头会把原来的磁线逆时针转九十度。
- **找位置。** 用 A、D 或左右方向键横移一列，整条吊链跟着移动。隔板、散件和箱沿都可能挡住吊链。磁线从末端出发，只吸射程内遇到的第一件，载重不够就吸不上来。
- **吸或卸。** 空格吸取，零件随即接成吊链。回车卸下最末一件。首单可以先吸长杆，看看磁线落在哪里，再吸重芯并卸货。要交的货可以先留在链上当工具，直到卸货才算交付。
- **回头试。** 左移、右移、吸取、卸货每次各耗一格电。被挡住的操作不扣电。Z 撤销并退回那一步的电量和物件，R 可重开本单。H 根据当前局面提示下一步。Esc 可翻工单簿，界面按钮也可用鼠标点击。[实际按键](../../../../prototypes/proto-121-magnet-scavenger/game/MagnetScavenger/Assets/MagnetScavenger/Presentation/MagnetRuntime.cs)

## 为什么安排这五单

1. **深井取芯**。空磁头只扫两格，井底的重芯从箱口够不到。玩家站在长杆正上方，第一次吸取立即把两格磁线推到井底。这里先教会“留下来的零件接下来有什么用”。提前卸杆仍可撤销。
2. **横梁底下**。目标上方封住。先用一枚短片垫深度，再挪到弯头那一列，磁线能从侧面穿进横梁下。弯头的出口在图上直接转向，玩家可以在下一吸前预测首件。
3. **过检修梁**。左井短片和右仓重芯都要交。长杆进得去左井，却带不过中间隔板。卸下短片之后还得卸杆，才能让空钩横移。提前跑去取右仓重芯又会花掉回程所需的电。
4. **地磅限载**。工单要的短片本身就是合适的延长件。限载 4，它和重芯合重恰好 4。若先交眼前的短片，再拿重 2 的长杆去够重 3 的重芯，明明瞄准也会超载。这里的难点是推迟一次已经可以兑现的交货。
5. **盲孔封仓**。工单长杆先当工具，两只弯头依次把磁线从向下转向右，再转向上，从盖板下方吸出重芯。两件目标中间夹着普通弯头，卸货顺序由实际链序决定。最后一单考的是能否在画面上沿整条链把出口追到终点。

五单电量依次为 8、10、13、11、16。对生产规则做广度优先求解，从各关开工局面到交齐的最短步数分别为 **3、5、11、6、10**。例如第三单只有两步余量，却允许随时撤回多走的路。手推路线和关键反例保存在关卡用例里，运行时提示同样搜索玩家眼前的局面。搜索若触及用时或节点上限，会提示暂时没算出路线。[关卡数据](../../../../prototypes/proto-121-magnet-scavenger/game/MagnetScavenger/Assets/MagnetScavenger/Core/ShiftLevels.cs) · [路线及反例](../../../../prototypes/proto-121-magnet-scavenger/game/MagnetScavenger/Assets/MagnetScavenger/Tests/ShiftLevelsTests.cs) · [提示求解](../../../../prototypes/proto-121-magnet-scavenger/game/MagnetScavenger/Assets/MagnetScavenger/Core/ShiftAdvice.cs)

## 重玩和待验证的问题

交齐一单后下一单开放。工单簿保留各单的当前进度和个人最少步数。重接已完成的一单可以尝试省一步，也可以撤销一次交付，专门观察货物留在链上会发生什么。五张固定布局让两个选择可以在同样条件下重试。记住路线之后确实会降低重玩价值，本轮将工单数和重复游玩的范围限定在这里。[进度与纪录](../../../../prototypes/proto-121-magnet-scavenger/game/MagnetScavenger/Assets/MagnetScavenger/Core/ShiftProgress.cs)

首次玩家测试可留三个时点。第一单吸起长杆后，先请玩家指出下一件会被吸到的货。第三单横移被挡时，记录他先检查轨道、隔板还是挂着的长杆。第四单允许先交短片，再听玩家解释第二次为什么决定把它带走。记录主动采取的动作、使用提示前后的差异和玩家自己的解释。可解路线能确认棋盘给了这些选择，玩家是否读懂、是否愿意重接工单，仍需实际试玩来回答。
