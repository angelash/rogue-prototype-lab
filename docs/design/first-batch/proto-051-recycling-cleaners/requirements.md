# 051 回收保洁队：需求文档

版本：v0.1；日期：2026-10-09（Asia/Shanghai）。状态：第一批原型文档，尚未实现或实测。

## 目标与依据

让玩家获得直接的清洁反馈，同时因桶容量、材料用途和刷头差异改变路线与顺序。清掉哪一片、何时腾桶、把材料出售还是转成清洁剂，需要对后续操作产生可见影响。

本轮用户要求整理第一批项目。051 来自既有首批推荐；范围解释见 [第一批汇总](../README.md)。[设计文档](design.md) 中具体污物命名、工具差异和结算模型属于助手草案。

## 最小交付范围

一个二维俯视房间、3 种污物、2 种回收材料、2 个刷头和1 个有限转换滤芯。首轮关闭升级，先测试不同布局与桶容量，再加入滤芯。平台、引擎和输入设备待定。

完整循环：看房间和清洁要求 → 选择区域与刷头 → 吸取或清洗 → 桶内积累材料 → 选择出售、腾桶或转换 → 用产物处理难点 → 交付、复盘、重试。

## 必须具备的需求

- **CLN-R01 房间与目标**：污物分布、清洁完成度、剩余时间/行动和补给点可见；同一房间能切换容量配置，初始资源可复现。
- **CLN-R02 基础清洁**：3 类污物有明确处理反馈；基础工具能够处理普通污物，不因缺特殊工具而无解。顽渍的基础处理和效率改善路径均可见。
- **CLN-R03 容量与材料**：吸取占桶容量，显示 2 类材料各自数量。桶满时只处理实际能存下的部分，其余留在场地，不静默删除或自动变现。
- **CLN-R04 工具与转换**：2 个刷头产生不同覆盖/效率；换工具和腾桶有时间与耐久代价。1 个滤芯只把指定材料转成有限清洁剂，显示配方、转化能力和剩余空间。
- **CLN-R05 出售或留料**：材料可在明确位置出售以腾容量，也可保留用于转换；出售后的材料不能继续合成，使用后的清洁剂不能再次卖作原料。
- **CLN-R06 因果与复盘**：同步显示刷头接触、污物减少、桶变化、工具消耗与清洁剂用途；记录路线、操作顺序、换头、腾桶、出售及转换。

## 验收场景

- **CLN-A01**（R01、R03）：同布局分别使用小桶与大桶。吸取的物料总量可核对，桶满时显示原因，满桶不继续清掉可回收碎屑。
- **CLN-A02**（R02、R04）：关闭滤芯时用基础刷头完成普通清洁；开启滤芯后，固定配方与清洁剂效率说明可查，材料扣减与产出一致。
- **CLN-A03**（R03、R05）：同一批材料分别出售和转换。出售产生现金并腾容量，转换消耗材料并产有限清洁剂，不发生双重收益。
- **CLN-A04**（R04、R06）：同一污物区域用两个刷头处理，日志能解释覆盖、时间、耐久和装桶差异；换头、腾桶的成本计入总预算。
- **CLN-A05**（R01、R06）：最后一次有效清洁先更新完成度，再检查时间耗尽；重放相同场景与操作得到相同最终库存和完成度。

当前验收尚未执行。未来试玩用真实路线和材料选择判断体验，不能用完成度上涨代替策略成立。

## 验证问题与去留

- **CLN-H01**：只改变布局和容量，玩家就会调整清洁顺序，而非总按最近距离扫完。
- **CLN-H02**：滤芯改变吸取位置、留料和出售时机，而非只提高最终数字。
- **CLN-H03**：没有升级奖励时，基础清洁操作和因果反馈仍让玩家愿意继续。

若材料从不影响选择、滤芯只有数值加成、所有房间都采用同一路线，或基础反馈无趣，就停扩内容并重构。

## 暂不纳入与待定

不纳入敌人、元素战斗、机器人、真实流体、自由燃烧或清洁电网。多房间成长和工具商店在基础验证后再评估。地图大小、污物密度、容量、转换配方、时间与耐久数值待校准，技术选型与实际开工顺序待定。
