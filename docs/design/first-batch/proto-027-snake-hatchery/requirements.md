# 027 贪吃蛇孵化场：需求文档

版本：v0.1；日期：2026-10-09（Asia/Shanghai）。状态：用户明确追加到第一批，尚未实现或实测。

## 目标与依据

让熟悉的贪吃蛇成长带来空间负担，身体节提供能力，但断尾会失去对应能力并改变采集方式。玩家可以选择保持短蛇、保留长身，或把一段身体分为小蛇处理任务；分身数量不能越多越好。

本轮用户明确要求加入“贪吃蛇孵化场”，其余项目的范围解释见 [第一批汇总](../README.md)。原工作簿将 027 列为后续候选，本轮提高的是批次归属，不改写原文件中的历史优先级。

## 最小交付范围

一个离散网格关卡、1 条主蛇、主蛇以外至多2 条分身、3 类身体节、2 类简单小蛇行为。显示分身路径预告和可见切点，普通采集也能维持循环。地图尺寸、具体数值、引擎和操作设备未确定。

完整循环：查看目标与地形 → 转向移动并采集身体模块 → 判断身体次序与通行空间 → 保持主蛇或在可见切点断尾 → 预告分身任务 → 花行动回收 → 交付并重试其他路线。

## 必须具备的需求

- **SNK-R01 基础蛇与空间**：主蛇在离散网格转向移动，身体按顺序跟随；墙、自身和其他占位可读，成长后占位同步变化，不能凭显示缩短身体逃避碰撞。
- **SNK-R02 身体提供能力**：3 类身体节各自效果可查；能力仅来自当前所属身体节，断尾后主蛇立即失去相应效果。长度与能力同时展示。
- **SNK-R03 有代价断尾**：只在公开合法切点操作；切出部分对应现有身体，不复制模块或资源；主蛇至少保留合法最小身体。分身上限达到2 条后不能继续孵化。
- **SNK-R04 简单可预告分身**：只有2 类行为，明确任务、下一步/短路径、阻塞状态和货物。分身自主撞击不得无预告地使主蛇受损；不引入复杂自主寻路。
- **SNK-R05 回收与基础保底**：回收需要行动和可达条件；超出主蛇载量的物品必须留在可见位置，不能自动复制或丢失。没有分身时仍能普通采集和交付。
- **SNK-R06 目标与复盘**：显示采集/交付目标和行动预算，记录成长、切点、能力变化、分身路径及回收。失败能归因于占位、操作或资源，而非隐藏惩罚。

## 验收场景

- **SNK-A01**（R01、R02）：吃入身体模块后，长度、跟随路径和对应能力同时变化；无新增模块时不能增长出免费能力。
- **SNK-A02**（R02、R03）：在合法切点分离带功能的尾段，主蛇长度及能力立即减少，分身只包含被切下的实际节；多实体模块总数守恒。
- **SNK-A03**（R03、R04）：已有2 条分身时尝试再分裂，原状态不变并提示上限；分身接近墙、另一条蛇或主蛇预定位置时按公开规则等待/停机，不产生隐藏主蛇伤害。
- **SNK-A04**（R04、R05）：回收前显示行动成本和货物去向，回收成功后移除分身实体；货物不足以装下时可选择保留或明确掉落，重放不重复得料。
- **SNK-A05**（R01、R06）：同一地形分别用短蛇、长蛇、1/2 分身操作，能够复现路径与碰撞；无分身场景仍有可完成的基础目标。

## 验证问题与去留

- **SNK-H01**：玩家主动保持短体或切尾，而非总追求最大长度。
- **SNK-H02**：改变通道宽度和目标分布后，玩家会改变身体次序或分身任务。
- **SNK-H03**：分身路线和回收成本可理解，玩家能解释“损失了哪段能力，换来了什么”。

如果长蛇或两分身恒优、断尾只是无损升级、玩家忙于纠正不可控小蛇、或没有分身就无法采集，就停止加模块并重构。

## 暂不纳入与待定

不做六蛇自主寻路、敌群战斗、复杂孵化科技树或真实软体。新增身体效果、切点门槛、分身行为和行动预算属于草案，不是原文既定数值。操作节奏、碰撞失败惩罚、试玩门槛与技术选型待验证。
