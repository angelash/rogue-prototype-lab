# Booster Pack Heroes 小游戏阶段开发要求补充

2026-11-18 v1.0。遵循根 [共同开发规范](../../../DEVELOPMENT_STANDARD.md)，补充本地还原项目的专属合同。此处仅记录本轮新增方向，既有静态提取/Unity 还原证据仍按原版本归属，不重新声明通过。

## 用户决策与当前授权

- 用户要求制定小程序版上线前广告接入、发行、推广等完整调研计划，归档并提交。
- 用户明确选择中国大陆微信小游戏先发，抖音随后验证。
- 用户确认已取得商业改编授权，具体覆盖后续补充；不再把“取得授权”写成未知起点，待办是范围留档和适用材料核对。
- 本轮授权范围是研究与计划、必要文档/预览制作及 Git 归档。不是执行建号、填报身份、签署、付款、联系人消息、广告投放或对外上线的指令。

## 方向变化与权威入口

本项目的下一商业目标由默认 PC/Steam 基线转为微信小游戏、随后抖音；PC 还原作为技术基线继续保留，原装内容和早期证据不覆盖、不清理。具体实施方案、内容缩放、确定奖励包、首版 IAA、横屏和性能目标属于助手建议，用户未逐项冻结。

当前计划权威为 [PLAN.md](PLAN.md) 与 [plan-data.json](plan-data.json)。前者解释决策和边界，后者定义任务、指标、预算与依赖；[HTML](index.html) 与 [任务清单](WORKBREAKDOWN.md) 为生成视图，使用 [render_plan.py](render_plan.py) 重建。

规则与商业化变更建立独立版本；开包、金币、广告奖励、存档及恢复由统一规则/事务拥有。不能因广告接入改变判定，不能以旧 Windows 构建或托管检查代替小游戏真机验收。随机虚拟币购买、授权作品适用路径和“当前及未来不虚拟支付”的声明先确认后执行。

## 当前实际完成与未执行

本轮完成现有文档读取、官方平台来源调研、58 项任务拆解、145 人日估算、阶段依赖、预算和假设收益模型、发行推广/运营/停运准备计划，以及离线可复算预览。文档验证结果见 [plan-verification](evidence/plan-verification.json)，其适用范围仅为计划产物。

当前未执行游戏开发、SDK 安装/切换、真实广告、平台账号操作、备案或提审、联系发行商、投放、签约付款和正式发行。所有生产任务为 planned，G0–G5 均为未评估；预算与模型不是已测收入或支出授权。

来源逐项记录日期与阅读等级；监管原文、抖音细则/SDK正文及账号资格缺口保持待核实。完整外部页面提取文本只供本地研究，公开归档短引、摘要、来源和正文哈希。商业授权/账号/原作受限内容不进入公开备份。
