# Booster Pack Heroes 小游戏发行计划归档

2026-11-18 v1.0。用户确认：中国大陆微信小游戏先发，抖音随后验证；商业改编授权已取得，范围后续补充。本轮交付计划与研究资料，不启动平台提交、付款、投放或游戏发行。

- **[完整计划书](PLAN.md)**：产品、移植、广告、资质、数据、收益、预算、发行合作、推广、运营、排期与风险。
- **[离线交互预览](index.html)**：完整正文、任务筛选、阶段安排、假设收益计算器、预算与来源；不依赖网络或外部库，可打印。
- [结构化执行数据](plan-data.json)：58 项任务、145 人日估算、依赖与验收、6 个检查点、24 类 QA 场景、事件字典、预算和风险。任务与数值的单一数据来源。
- [任务清单](WORKBREAKDOWN.md)：由结构化数据生成的可读清单。

- [文档验证结果](evidence/plan-verification.json)：只验证计划文档和预览，不代表游戏、广告或备案验收。

估算：12 周工作窗口依赖约 2–3 个等效角色容量，145 人日包含不同职责，不表示当前已有多名人员或启动了子代理。同一协调者串行承担时建议预留 30–36 周，外部审核和完整 D30/90 观察可能继续延长。预算三档约 2.2 / 5.72 / 11.33 万元，不含授权保底、可能适用的出版申报、薪酬与税费；不是已批准支出。

执行前先确认随机包准入、授权范围、IAA 长期声明和主体；先做可玩真机与广告闭环，随后小流量学习，真实回收成立才扩大投入。当前所有生产检查点保持未评估。
