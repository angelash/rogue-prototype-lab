# Escape from Duckov 2.3.30：逆向研究总报告

2026-10-13；输入仅为用户指定的本机 Steam 安装。此报告描述发行构建的静态实现，不把反编译结果称为作者源码，也不把内容登记当作实际游玩验证。

## 已建立的研究项目

游戏是 Windows x64、Unity **2022.3.62f2**、**Mono** 构建，主要业务位于 `TeamSoda.Duckov.Core.dll`。玩法以长期基地进度与单次出击相连接：准备装备，进入由场景与关卡配置组成的区域，搜索物资、战斗、完成条件，再通过撤离或死亡处理进入下一阶段。物品属性系统、配置对象与全局保存事件是多个玩法系统的共同连接点。

已复制并逐文件核对 **466 文件 / 3,091,569,706 字节**。全部 **201 个托管程序集**都有元数据与 IL；共 29,961 类型、249,454 方法、144,780 字段，其中包括引擎与中间件。核心业务程序集有 **1,802 类型 / 11,804 方法 / 9,995 字段**。全程序集 C# 项目转换为 200 成功、1 部分失败；该失败的完整 IL 与原 DLL 保留，详见[覆盖边界](coverage-and-limitations.md)。

全部 **131 个 Unity 容器 / 1,601,352 对象**已索引，记录对象原始偏移、大小、SHA256、结构化字段和 **4,457,141 条非零 PPtr 引用**。97,426 个 MonoBehaviour 的脚本指针经独立基础模式复核；已记录引用的目标均存在。这个结论不涵盖无法解码载荷内部的潜在引用。

已建立内容目录：**1,569 物品登记、315 任务登记、269 配方、27 建筑条目、12 商店货表、23 作物条目、156 角色预设、116 Buff、10 天赋树 / 163 节点**。其中存在模板与测试内容；Boss 标记的 61 个预设不等于 61 个独立 Boss。63 个构建场景包含启动、菜单、加载、基地、子场景和过场，不等于 63 张独立地图。

可解码媒体导出 **10,151 文件 / 1,764,905,424 字节**，另外从 FMOD 银行解码 **568 / 568 样本**，登记 **373 音频事件**。导出目录只在本机保存。模型 OBJ、PNG 预览、编译 Shader 文本等各自有格式边界，详见[资产分析](assets.md)。

4. [覆盖、限制与核验](coverage-and-limitations.md)：分母、失败对象、恢复方法、未执行范围。

本机数据入口为 `local/content-catalog.json`、`local/code-index.json`、`local/code-metadata/`、`local/assets.sqlite`。全部反编译 C# 位于 `local/decompiled/`，全部 IL 位于 `local/il/`。每种游戏脚本对象族都有索引，可继续查阅专门目录尚未展开的 UI、剧情触发、小游戏、特效、成就、天气或 Mod 系统。

## 交付物的使用方式

运行[检索启动脚本](../scripts/start-explorer.ps1)，在 [本地研究目录](http://127.0.0.1:8784) 中按名称、ID、符号或字段值搜索。物品详情链接到组件和图标；对象详情包含原始来源与双向引用；代码详情列出方法、IL 调用与字段；任务详情连接完整子任务和奖励。

完整安装输入、反编译内容和媒体属于本机 `local/` 数据，使用独立无远程 Git 快照保存。外层仓库只保存原创报告、分析工具与事实摘要；[来源记录](../sources/target-register.md)和[备份记录](../evidence/backup.json)给出实际版本与备份结果。

## 结论与适用范围

当前构建已形成可追溯的全量文件、托管 IL、Unity 对象与内容索引，并对主要游戏系统完成阅读分析。它可用于研究该游戏如何组织代码、内容生产与运行资产。发行包没有包含作者的完整 Unity 工程、原始美术制作文件、全部原始 Shader 或 FMOD Studio 工程；这些信息不能凭反编译无损补回。原生中间件只完成 PE 与符号边界登记，未人工逐行审查全游戏 249,454 方法，也未执行游戏游玩。
