# 界面与输入

## 参考布局

参考1920×1080，Canvas Scale With Screen Size、match=0.5，固定逻辑16:9，其他画幅居中留边；最低1280×720，窗口可调但不小于此。超宽不扩张五格作用区。UI参考坐标单位为像素、原点左上；配置详见 catalog.uiLayout，锚点共有一个权威。字级正文24、标题36、重要资源28、卡名20、脚注18；最低画幅可提供独立“详细卡片”全屏面板，避免小手牌承担完整规则阅读。

上方64px：章/委托/轮/难度/暂停；敌手区80–360：五岗位目标、五帮工位、五设施格、五停工位，敌手手牌只显示数量；中间380–620：来客卡、五设施格、服务图标/供电线与库存入口；己方工作区640–780；下方800–1048：手牌、AP、钱、市望、结束按钮。背景低对比，功能面板读图优先。镜像只影响装饰，敌手设施slot0仍在左。

手牌最多12张，可横向滚动，卡面显示名/岗位或类型/剩余工作点/费用/简短效果；悬浮/键盘选中显示300×420详细卡，定位避开当前目标区。最低画幅原生文字钳制到16px、交互按钮钳制到80×40px，超过卡宽则卡名省略并在详情完整显示。扩展效果全文与引用目标在详情，禁止用微小字塞整张卡。目标可选与不可选用实线/斜纹＋文字区分，岗位颜色只辅助。

## 十二个屏幕合同

catalog.screens 列完整入口文字、背景与默认焦点。Title继续按钮仅有效局档存在时可用；自由委托只在解锁后可用，锁定原因可看。章节页列7章，锁章显示上一章解锁条件；委托页显示具体五数值、来客条件、期限、难度与确认。结果页显示轮末胜负原因、达标工作、每位客人原因、市望和seed；不只播一个印章。

screen.actionKeys只列可操作按钮，标题/错误文字不接键盘焦点。检查无说和牌时焦点自动到“接受检查”；恢复无有效备份时到“开始筹备”。同代次冲突显示两份委托/轮次与A/B选择，写失败显示重试/不保存退出/取消；这些完整按钮文案均在strings。

Reaction覆盖在棋盘上、卡牌检查来源高亮、原玩家AP保持；被检查方选择说和牌或接受，其他变更按钮禁用，暂停/查看详情仍可。库存面板可预览买入/移动/改用途/变卖；底层棋盘目标格保持可见。存档恢复页对损坏、新版本、内容不符、写失败分别给清楚选择，不自动删档。

ui.card-frame与面板/按钮/数字/工作点/图标是原生绘制，插画没有功能文字、命中框或五格分割。帮助页包括轮末判定、所有标签、说和、修补分组和五类客人，数据从catalog读。排行显示本地前十，注明难度与胜/负/平；无联网等待。

## 键鼠绑定

默认动作：左键选/确认，右键取消当前选牌/目标，Esc取消或打开暂停，Enter确认焦点，Space推进文本（棋盘焦点在结束按钮时才结束），E结束回合（需确认余行动），Tab切换本方面板焦点，Shift+Tab反向，方向键面板内移动，1–9选当前可见手牌，Q查看选中详情，L日志，H帮助，F加速表现。鼠标滚轮只滚手牌/正文，无玩法命令。

允许重绑定E/Q/L/H/F与数字快捷键；Esc/Enter/方向/Tab作为菜单必需键保留。冲突弹窗选择交换/取消，不静默覆盖；重复按键和键自动重复不能重复派工。按钮按下到释放只提交一次；拖牌本版仅为选牌表现，实际仍点击确认目标，无拖放即扣费路径。

确认结束时有AP且存在合法命令才提示；可勾选本局不再提示，设置不默认跳过新局。Reaction的Space/Enter只按焦点按钮处理，不能落透到EndTurn。AI轮允许看牌/设施/日志/暂停，无变更命令。取消选目标返回原面板焦点，关闭覆盖返回打开它的按钮；焦点框宽2px常显。

## 可读性与无障碍

字体比例100/125/150%；超过正文面板则垂直滚动，关键按钮不移出屏幕。低动态关闭晃屏/漂移/弹性缩放，保留0.1秒淡入与状态框；没有每秒三次以上频闪。加速只缩短表现，不自动操作/改变计时。主音量/音乐/音效/环境均独立，静音仍显示事件文字；剧情无语音，因此无字幕遗漏。

默认失焦暂停；设置关闭该项时仍暂停人类反应与待目标输入，AI不会替玩家做决定。窗口重回后丢弃挂起鼠标按钮状态，再次点击才提交。光标不锁定，无长按Esc退出；回标题与退出均提供“保存继续/不保存退出/取消”，未提交预览会被取消。

本版承诺完整键鼠。手柄、Steam Input、屏幕阅读器等不在已采用范围；发行文案不声明完整手柄支持。菜单、教程、战斗、恢复和退出都须用实际键盘完成一次，不能只验证鼠标点击。
