# 规则与结算

## 状态与时间单位

规则版本 `ynm-rules-1`。一个筹备轮包含双方各一个行动回合。所有工作时长与负面时长以“受影响摊位自己的回合”为单位。工作剩余值是整数；物理、帧率、动画和真实时间不参与判定。轮次从 1 开始，最多 20。初始先手由 seed 最低位确定（0 为 P0，1 为 P1），每轮交换先后，保证双方在轮末获得同次数行动。

主状态：Title → ChapterStory → ContractSelect → Initialize → BeginTurn → Draw → MainAction ↔ ChooseTarget → Reaction → EndTurn → RoundCheck → BeginTurn 或 Result → StoryOutro/Title。Pause 为覆盖状态，保留完整底层状态；Load/Recover/Settings 为流程界面。动画是事件消费者，状态可以先提交，输入在需解释的动画期间暂时锁定，不能在动画回调里算胜负。

## 初始化

双方各有 95 个卡实例，实例 ID 是 `P0:C001` 至 `P1:C095`。原属牌堆身份 originOwner 永不改变，控制者可因夺牌改变。每个实例只能在一个区域：deck/hand/working/negative/pendingReaction/discard。全局始终 190 个，不能复制或遗失。初始从各自牌堆取 C001/C007/C019/C025/C037 到手中，其余 90 个排序后洗牌。两方工作已完成值均为 0，目标使用同一委托五字段。初始铜钱、设施、库存按 catalog；AP 先为 0。

第一个自己回合开始仍领取正常收入，因此初始 8 钱进入第一次行动时为 10。第一轮不额外抽牌；从第二轮开始每次抽 `max(1, refillTo-handCount)` 张，按实际牌源可用量和手牌上限处理。每轮只自然工作一次，不因先后交换漏算或多算。

## 自己回合严格顺序

1. 创建一次性 BeginTurn token（matchID/round/player）。清除上回合岗位锁，AP 设为 3；领取 2 钱至上限 20。
2. 计算有效停工岗位：所有已附着事件的目标做布尔并集；全岗位事件与指定岗位事件可重叠，不累加工作减速。
3. 按帮工位 0→4，未受阻帮工 remaining 减 1。减到 0：该岗位 done 加 1，市望加 125，帮工卡送原属弃牌区，位置清空。既有帮工即使岗位已达标仍完成工作，允许超额储备。
4. 第一轮跳过补牌；其余轮按规定补牌。没有牌与弃牌时结束补牌并提示，不报异常。
5. 进入 MainAction。修补属于花行动的玩家选择，本版取消原作回合开头自动消耗修补牌；因此本回合自然工作已受阻的进度不会追补。可再用正向推进卡补做。
6. EndTurn 只在无选目标/无检查反应时合法。按停工附着序号，对本摊停工 remaining 减 1，到 0 送原属弃牌区；推进下一摊或 RoundCheck。

手动提前结束合法。AP 为 0 不强制自动跳过，允许看牌/日志/开张条件后确认结束。AI 用完行动或无合法有价值行动时提交 EndTurn。没有 4 秒自动结束、6 秒检查倒计时和长按退出。

## 命令事务与通用资格

所有变更通过 commandID、expectedRevision、player、payload 提交。先验证结构、模式、回合/反应资格、目标、资源，失败不消耗牌/AP/钱/随机数。成功原子地改变状态，再递增 revision 并记录事件。相同 commandID 重发返回原结果；旧 revision 拒绝。卡每次成功使用市望加 50，反应牌不加市望。不能空目标刷市望。

普通卡与设施变更各耗 1 AP；卡不耗铜钱。查看、选目标、取消和预览不耗 AP。选牌后只有确认合法目标才扣费；右键/Esc 取消保持原态。目标在确认时重新验证，不使用悬浮预览缓存。

帮工：本方五个位置有空位；岗位目标尚未达标；全局没有该卡定义对应角色正在工作（双方卡实例可能同 ID）；首名成功派出的帮工锁定本回合岗位。后续帮工必须同岗位；正向 unlock_department 解除此限制到回合末，之后不重新锁。选择空位 0→4 可手动指定，默认最低空位。入场 remaining=卡 turns，不立即工作。

停工：对方负面区有空位；效果覆盖的岗位中至少有一名正在工作的帮工。若指定岗位无帮工，该牌非法。all 覆盖任意工作者即可。放入最低空负面位，duration=卡 turns，第一次减少发生在目标方这次或下一次行动回合结束；目标方下一次开始先受到完整停工影响。

## 全部效果合同

- steal_hand：敌手非空；从敌手手牌按实例 ID 排序的列表中随机不放回取最多两张到己方。先出牌再计算己方容量；溢出卡进入其原属弃牌区。
- return_workers：敌手至少一个工作者；按工作位排序随机选最多两人，移回敌手手中，remaining 工作进度丢弃。手满则送各自原属弃牌区。
- discard_hand：敌手非空；按实例 ID 排序随机不放回最多两张，送各自原属弃牌区。
- advance_all：己方至少一个未受阻帮工；按位推进 1 次，完成按自然工作结算。受到停工者跳过；不能从受阻卡中偷取进度。
- finish_all：己方至少一个未受阻帮工；按位将其 remaining 置 0，完成各 1 项；受阻者跳过。不是把整个委托直接判为完成。
- unlock_department：手中至少一张经“忽略岗位锁”检查可派出的帮工，且本回合已锁岗位、尚未解除；否则非法。
- reduce_goal：选择己方 done<goal 且 goal>1 的岗位，goal 减 1。当前有效目标不得低于 1；既有 done 不减。达标岗位不再减免。
- repair：己方至少一个事件的 cardID 在本卡 repairIDs 中。一次移除所有匹配实例，其他事件不变；只修停工，不修改设施供电状态。
- add_goal：指定岗位目标按卡 amount 增加。已达标也可加；pendingReaction 冻结被检查方与岗位。增加没有人为 5 项封顶，原有 done 保持。
- reopen_task：选择敌方 done>=goal 的岗位，检查被接受后 done 减 1，最低 0；goal 不变。超额 done 可以使扣一项后仍达标。
- cancel_inspection：只在自己收到 add_goal/reopen_task 的 Reaction 中使用，选择手中 C087/C088 任一实例；零 AP/钱、零市望，抵消整个检查，双方卡进入原属弃牌区。接受不花资源；反应无限时；检查发起方已花 AP/得 50 市望，不退款。

检查在发起时验证目标、扣费并将检查卡放入 pendingReaction，随后切换输入主体到被检查方；确认反应后回到发起方原 MainAction。AI 被检查方也走同一反应事务。Reaction 暂停自然工作、AI其他行动和轮末评定，不触发回合交换。

## 牌堆重洗与守恒

弃牌永远回原属牌堆，即使此前被偷走。controller表示当前区域所属摊：被夺手牌改为夺取方、附着对摊停工改为受影响方、进入原属deck/discard则恢复为originOwner；pendingReaction检查牌仍属发起方。规则不从controller推断原作者或退款归属。牌堆不足时先按原顺序抽尽，若仍需抽牌，把该 originOwner 弃牌区按实例 ID 排序后用自身 draw 流洗牌，再抽；弃牌里不包含工作者、停工或反应卡。满手时不抽入手，保持牌源；本次自然补牌到容量即停止。效果产生的溢出按效果处理。抽牌无法完成不补生成卡、不取消对局。

因此 20 轮里卡可以再用，必须允许目标超过初值；保存使用有界整数，运行有效值限 0–1,000,000 作为数据损坏防护，合法对局按 120 次主行动远低于该值。源值 amount=0 的即时牌采用原代码“最多两张”的行为，不把 0 误解释为无效。

## 开张与期限

仅在双方该轮 EndTurn 已完成后 RoundCheck。每方 ready = 五个岗位 done>=goal 且全部客人合格；设施和来客按最新状态一次计算。单方 ready 直接胜；双方 ready 比较 `(达标岗位数,进度分数,市望,铜钱)`，完全相同为平局。ready 时前两项相同，实际由市望/钱区分，无先手或随机裁决。

20 轮末无人 ready 则比较 `(合格客人数,达标岗位数,进度分数,市望,铜钱)`，字典序取大。进度分数定义为 `sum(min(done_i,goal_i))/sum(goal_i)`；比较用交叉乘整数，不用浮点或平均每岗位百分比。双方 ready 时同样使用此截断比例，不因超额刷工作获得额外比例。完全相同平局；平局保留成绩但不授章节获胜解锁。

正式获胜/失败/平局均记录玩家本局市望，排行榜仅玩家正式完成对局，保留前十，依次市望降序、轮数升序、resultID 字典序。显示结局类别、委托、难度与 seed，不把 AI 分数混入玩家榜。市望不用于胜负之外的消费。

## 明确变更

相对原作：加入 AP、铜钱购物、双用途设施与公开来客；固定初始岗位齐牌；独立随机流与重洗/手牌上限；修補由玩家行动；无限时说和；公平輪末評定与 20 轮期限；保存局内状态；结束只看核心状态。旧操作、文本、音画和动画驱动胜负全部替换。95 卡效果与五岗位时长结构保留，具体数量引用 catalog，不复制软件工作世界观。
