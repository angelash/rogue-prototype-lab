# 故事与教学

## 世界与角色语气

夜市在鬼门开启前准备，来客是赶路的温和妖怪。旧货不是废物，也不靠“神秘万能魔法”自动解决规则：锅能煮也能暖，帘能挡声也能挡雨，灯既能照路也能成为引符。故事把这些取舍解释成手艺。无现实品牌、原游戏公司/平台、现代办公室或侵权角色。

玩家是推祖传旧货车的新掌柜，名字由玩家填写；无性别或形象选择影响规则。狸掌柜解释规矩，锅青示范手艺，纸书记处理巡摊争执，伞老六是同场筹备的对摊。对摊竞争只采用游戏可见卡效果，不把失败写为羞辱玩家。

42 名帮工与4名关键角色的身份、衣着、工具、岗位、动机、语气、台词与资产在 catalog.characters。锅青的 NPC 半身与 C007头像是同一身份，必须基于已验收CHR.007编辑，不重新随机设计。纸书记在C088与NPC.clerk保持青印额/蓝灰衣/青布帽；C087狸掌柜保持NPC.host白眉毛与砖红背心。其他帮工没有另设无限对话树；每张牌仅一条固定手艺短句，全部已写完。

## 完整章节脚本

7章每章4委托，完整开场/收章文字在 catalog.chapters，委托特定开场/胜/败文字在 contracts。正常新局流程：首次进入已解锁章显示章 intro → 选委托 → 显示委托 openingLine → 开局；首次章内获胜显示该委托 successLine → 章 outro → 执行幂等解锁。第七章 outro 是完整结尾。

败局显示该委托 failureLine，平局显示 `ui.draw` 与“今夜的灯一起亮了。换一种摆法，再试一次。”；不解锁下一章。已完成章再玩只显示委托行，菜单可重看章 intro/outro。章节开场seen只有玩家确认或跳过后写；中途退出不吞掉未读段。每段最多两屏，由原生排版按句切页，不能改变实际内容。单击/Enter/Space继续，Esc打开暂停，跳过按钮直接到该段终点，不自动发奖励。

文字全部简体中文，用短句与生活动作解释效果。所有变量只采用 data.stringVariables，缺变量/未知键阻断内容导入；不能运行时展示`{tags}`或资源键。摊名1–12个可显示Unicode标量，拒绝控制字符、标签标记和缺字；默认“旧货夜摊”。摊名仅本地保存，无上传与聊天审核系统。

## 教学固定场景

教学作为独立模式，不从正式随机牌堆中强塞教学卡。每步的anchor、文字、requiredAction和跳过权限在 catalog.tutorial；使用与正式游戏同一规则，作者预置状态只在步骤边界加载并显示“教学演示”。每一步保存tutorialStep，恢复回同一步初始演示快照，正式局不受影响。

固定演示序列：欢迎/目标 → C001派到位0 → 尝试C007看到岗位锁 → 推进一次自己回合读工作点 → 预置C051使招徕受阻 → 雨棚修补演示改为C044+C082明确对应组 → 铁锅掌勺改暖灶 → 清空格1/2后演示F05于2、F03于1且水泵有效 → 卖F05读断电因果 → 客人卡读缺水 → 预置C089检查与手C087说和 → 结束回合 → 自由操作教学收尾。

停工与修补两步使用不同预置快照，页面明确“下一种麻烦”，不能暗示C082会修C051。需要目标的步骤预先给足AP/钱与目标，非法点击保留当前步并显示正式reason；展示注释不改规则。

教学可随时跳过到主菜单；只在完成最后一步或主动跳过时记 tutorialSeen，不记录正式胜负/排行/章节。首次点击开始筹备时若未见教学先进入教学，已见后直接章选择；帮助页随时可重开。失败不会冻结教程，不要求玩家按虚假过关步骤刷金币。
