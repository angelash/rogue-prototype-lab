# 妖怪夜市开张 开发合同

版本 v1.0，2026-10-12。继承[共同规范](../../DEVELOPMENT_STANDARD.md)和[项目模板](../../DEVELOPMENT_TEMPLATE.md)。本项目无原方案编号，不改变第一批排期。

## 1. 项目标识与执行依据

用户明确决定：采用“妖怪夜市开张”包装，建立独立目录，完整覆盖策划数据、原作包装替换、生图规范和提示词，达到可直接开工的设计准备状态。

本轮范围为完整设计及机器可校验的数据包；Unity 游戏实现、图片量产、实际试玩和发行是后续制作阶段。采用 Windows PC 单机、Unity 2022.3.62f3c1、面向 Steam 的共同基线。助手锁定二维桌面卡牌、与一个 AI 对摊竞赛、五项筹备工作及五格双用途设施；具体新增规则和数值属于本版设计选择。

权威入口：[README](README.md)、[完整设计](design/00-index.md)、[规则](design/02-rules.md)、[数据](data/catalog.json)、[美术规范](art/ART_DIRECTION.md)、[来源](sources/register.md)、[验收](design/11-validation.md)。设计数据只以 catalog.json 为权威，CSV、内容手册、提示词和替换索引由脚本派生。

目录差异：本版设计正文按用户要求自包含放在独立目录的design/，不再复制到根docs/design；根README与prototypes入口链接本目录。

待验证假设：玩家能理解设施占格与供电的取舍，首次无提示对局能完成一种合格开张布局；普通对局中位时长 12–18 分钟。实现后的真实试玩决定调参，设计覆盖检查不证明这些假设成立。

## 2. 开工准备

来源为本仓 Crunch Time 静态分析；第三方反编译源码、英语/西语全文和原媒体不复制到本项目。原有 95 卡、28 项目及全部资源对象仅作为结构和数值追踪依据，中文名称、文案、角色和资产规格重新创作。

本机 Unity 路径沿已核实基线 `D:\Program files\2022.3.62f3c1\Editor\Unity.exe`；本轮重新登记路径及 Windows Mono 模块存在性，项目自身导入/编译未执行。工程规划路径 `UnityProject/`，产品名 `YokaiNightMarket`，公司名 `RoguePrototypeLab`，保存身份独立。图片采用内置 image_gen 路线，图标/字体/数字保持原生 UI；不依赖付费 API、网络服务或第三方模型。

## 3. 制作要求

有限正式内容：95 卡、28 开张委托、12 种双用途设施、5 类客人、7 章故事；本轮冻结全部条目、关系和生产规格。玩法为确定性回合制，不采用三维投掷或实时客流模拟。键鼠为完整承诺输入，手柄和配音本版不采用。完整规则、状态、输入、保存、AI、文案、视听、性能及生产清单分别由设计目录约束。

数值权威为 `data/catalog.json`；规则版本 `ynm-rules-1`，配置版本 `ynm-content-1`，存档格式版本 1。表现不得结算胜负。所有实际生成的图片、音频和字体须记录来源、谱系、哈希、导入与目检/听检结果；第三方参考不能获得默认再分发许可。

## 4. 实施阶段与放行证据

1. 设计准备：全数据、替换、提示词、资源引用及边界用例闭合，执行 `scripts/verify_design.py`。
2. 核心原型：首章四委托、五工作类别和全设施规则，定向规则测试、恢复和 Windows 包通过。
3. 体验纵切：代表资产、教程、剧情、UI、音效接入；真实窗口操作、画面与听感实查。
4. 内容扩展：95 卡/28 委托全量导入，完整故事和提示词资产生产，内容组合验证。
5. 候选发行：Release、干净环境、迁移/故障、目标设备性能、完整许可与发行素材验收；平台账号/签署/付款及上传发布按实际条件另记。
