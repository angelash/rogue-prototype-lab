# 审视结论与确定的替换方向

## 审视依据与边界

检查两张用户截图、v2.7 实际 Player 的桌面/设置/阶段/帮工/闹场/协助/巡街牌样本、全部 52 张非插画/桌面运行纹理的联系表，以及 28 张人物和事件原图。另核对 48 个 Material 记录、hGameVars 的分类赋色、PlayCard 的标题/类别/FX、ProjectCard 的计数/改名赋色、TitleManager 的阶段字色与 TextOutline 的描边。联系表、截图与检查结果属于本机报告，独立生成的新制作源纳入 Git。

28 张插画缩略复核证明它们属于同一夜市绘画体系，不证明所有 95 张牌的实际缩小效果已重新验收。当前决定按共享插画保留；遇到生产态文字/主体裁切问题再以具体帧修订，不能因为 UI 错误整批推翻插画。

v2.7 的 748 张自动渲染证明此前尺寸、显示状态和部分边界检查通过，**不证明风格合格**。用户本轮反馈已否定那套混合外观。新设计的审美验收必须看修订后的实际桌面、折叠牌与展开牌。

## 要保留的内容

人物、事件、桌面的暖灯、旧木、蓝布、纸张和手绘笔触统一，是新 UI 的参照。游戏标题的摊棚/月亮/灯笼主题、成绩板的木框与纸签方向可保留。四种章的开张/结绳/交叉绳/折伞语义保留；后续实机若盖住关键信息，只降低装饰密度和画面墨量，不变更覆盖节点或判定。

所有原节点、相对位置、点击范围、折叠/展开、左右滑入、轮数槽数量、开关状态和原时机继续使用。原作的方形点、斜切外轮廓可以作为既定槽位；其内部应像纸签或木牌，不再像亮塑料。空的商号区域仍是信息区域，不新增并不存在的公司插画功能。

## 确定采用的整体设计

界面像摆在同一张夜市木桌上的物件：**靛蓝染纸作底、旧纸签作招牌、朱砂与矿物颜料作标记、少量旧金作边线**。不用仿金属、发光塑料、办公软件棋盘纹或大面积鲜红。装饰集中在物件边缘，每块板只有一个外框，正文区域保持安静。

主底色 #202D36，次底 #293740；纸色 #E8D6AF，浅字 #F0E4CA，深字 #362D24，旧金 #B7945E。五岗位统一低饱和矿物色：招客苔绿 #60755D、备餐石青 #536E88、备货赭金 #766239、挂灯陶赭 #9B6346、布符灰紫 #826883。类别色在顶部纸签、细分隔条和轮数带连贯使用，面积与功能沿原模板。岗位名、图标/既有形状和位置共同辨认类别，不要求只凭颜色判断。

## 各界面改成什么

| 界面/层 | 当前问题 | 明确目标 |
| --- | --- | --- |
| 帮工与事件牌顶部 | 金属渐变色帽、方硬色框，和下方旧金框不相容 | 染色纸签标题，平缓纸纹；插画周围用细旧木/旧金线，画面不再覆鲜亮塑料边。类别色统一为矿物色，标题保持浅纸字。 |
| 卡牌正文与轮数带 | 下框过多云角，底部仍是亮色斜切塑料槽 | 靛蓝账签、极淡纤维；只留一个细边，四角有极小结绳/云角，轮数带像染纸，槽内像墨色记工格。0–4 轮模板纹理一致，仅保留各自原槽数。 |
| 卡牌分隔线 | 两条粗长斜切色棒 | 沿原可见轮廓换成低饱和颜料笔划，边缘做纸面刷痕；不再贴一张完整花框，不增加横条或遮字。 |
| 左侧商号及委托 | 荧光绿标题、棋盘底、空信息区像未完成占位 | 上方旧纸招牌 + 深墨商号字；下方靛蓝账簿底，去棋盘格。五行目标区域有安静墨色底槽，说明与数字清楚。底部分隔用旧金/纸色细条，不用荧光绿。 |
| 我的摊位/轮次 | 大片荧光框、黄绿轮次 | 和商号同一纸签框；轮次用暖纸字，活动提示用蜜金。保留原空白区域、改名入口及编辑光标。 |
| 进度点和状态标记 | 荧光方块、现代红叹号/齿轮 | 原尺寸与轮廓内做染色纸筹；完成为苔绿墨勾、未完成为朱砂提醒、工作中为赭金记工印。小图标的粗轮廓不细化，保持缩小可辨。 |
| 中央阶段 | 黑蓝大矩形、硬金边、纯白黑描边，像临时调试 UI | 左右滑入的靛蓝布/染纸告示；底板只铺质地，边线层只画旧金细边。连接处无第二套框。暖纸主字、暖墨描边；胜利浅苔绿，失利陶红。原淡大字、尺寸、位置和时序保留，不能用删动画掩盖风格问题。 |
| 结束本轮/设置/继续按钮 | 平面灰蓝面 + 金属倒角 | 靛蓝木牌或账签，细纸金边；可用/悬停由原着色与 alpha 变化表达暖纸/蜜金，禁用仍可辨。仅底板有内边，不能每个状态再套整框。 |
| 四项设置与语言 | 小红绿灯像电脑开关，语言标记孤零零发光 | 原矩形灯槽内像朱砂/苔绿墨签；同一纸纹底，开启/关闭仍有清楚色差，保留开关文案。中/EN 是同尺寸纸签，字形由 Noto 排；悬停光晕为淡暖灯色，不画灯笼来占点击槽。 |
| 选中与目标反馈 | 生硬金框、厚亮边、旧现代箭头 | 同一蜜金光晕/墨金边；选中底板只提供底色，选中边线只提供边线。箭头、快进和鼠标保持轮廓方向，用旧金/暖纸笔触，不新增引导功能。 |
| 点击继续/调停底板 | 功能已修好，但仍是纯冷黑底 | 小块低对比靛蓝染纸，中心完全空白；全部提示由实时文字显示，绝不再放游戏 logo。 |
| 标题、成绩、印章 | 大体已符合夜市；成绩/章略繁 | 第一轮保留。集成代表画面后看墨量及可读性，只有真实冲突才改；不把每个面板都做成挂四只灯笼的戏台。 |

## 材质和代码内颜色必须一起处理

只改 PNG 不能关掉荧光：CARD_03_DetailsTop、Details、Mask、进度与共享粒子的最终色受到 Material / Sprite tint 乘色。完整目标记录在 palette.json。岗位的 Detail 与 Bar 使用同一矿物色，类别文字统一浅纸色；商号/委托招牌用浅纸金、文字深墨。闹场/挖角用陶红，协助用苔青，调停用灰紫，巡街用深砖红，掌柜用赭金。

TitleManager.Init 的五种硬编码色，ProjectCard 的完成计数/红色提醒，PlayCard 的硬编码灰字与协助 FX，Continue 与原 SpriteRenderer 中的荧光 tint 需在生产前列为显示值迁移。使用显式的颜色替换登记或只控制展示的主题入口，不能在每帧重写颜色从而覆盖原闪烁、暂停、淡出和完成反馈。原业务数值、调用序列、随机位置及 alpha 时序不变；若变更旧脚本中的颜色常量，必须扩大声明差异并定向核对，不能假称 30 份脚本字节未改。

TextOutline 仅将黑墨改成暖墨；先保持原 pixelSize、TextMesh 字号、缩放和动画。纹理不烘焙文字，生成器不画仿中文。材质相乘后的真实结果要在实际 Player 查看，不能凭色票就宣称对比通过。

## 推进与验收

1. 冻结本目录清单和一张成套代表样稿。样稿说明物件与材质方向，不当实机截图，不切片导入全部 UI。
2. 先独立生成“连续底材”“空白标题签”“无装饰边线”等生产稿；不同层有不同提示词。制作批次、旧图、新图、真实生成尺寸、目标尺寸、透明要求、hash 和采用状态逐项登记。
3. 技术导出只采用原 alpha、网格与槽位，不采用原金属/棋盘 RGB。必须写明每层取哪个新材质区；透明缺口不能补成任意深蓝。若原 RGB 表示轮数槽而非装饰，可提取为独立功能分区标识，不把整份灰度重新乘回去。
4. 第一批在真实 Unity 中并排看帮工/闹场/巡街、左右信息板、横幅和设置；检查折叠时标题、五行数字和进度筹仍可辨。两画幅、中英文、开关与阶段进出都通过后再推广共享模板。
5. 最后全量 95 卡/28 委托/教程/成绩复核及构建、来源封闭、尺寸/alpha/几何、源码差异、版本管理。保留失败稿与失败帧。版本化资产先提交再继续后续修订，完整工程走本地 Git 与 bundle，公开备份只推原创输入。

风格不合格的关闭条件是**实际改过且整套画面连贯**。测试图数、文件数、PNG alpha 一致或正常构建只能支持各自技术结论。
