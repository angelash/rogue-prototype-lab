# 夜市界面重整 · v2.8

日期：2026-10-13。已从审视、规格和样稿推进到正式 Unity 集成：82 张纹理中重做 38 个 UI 层，44 张保持既有夜市资产；材质、组件和运行赋色同步改成矿物色、暖纸字与旧金。实际范围、包与检查入口见[集成记录](integration-and-review.md)。v2.7 素材与测试保留为历史，概念样稿不充当实机画面。

上一轮正确修复了 UI 的功能分层，却错误地把原作的颜色、金属渐变和棋盘纹也作为应保留的外观。新约束是：保留原尺寸、Sprite 网格、节点结构、交互与动画，重新制作属于外观的 RGB、材质色与字色。技术轮廓不能代替夜市美术。

- [审视与具体设计](audit-and-design.md)：问题、保留理由、逐个界面目标及推进顺序。
- [完整替换清单](replacements.json)：覆盖全部 82 张运行纹理，逐项尺寸、决定、目标、层角色及提示词入口。
- [颜色与运行赋色](palette.json)：岗位、分类、状态、文字、材质和代码内赋色的迁移要求。
- [分层及生产规格](layer-specs.md)：哪些层可以有装饰，哪些仅提供纹理、遮罩或反馈。
- prompts/：38 个层的独立制作要求；按角色共用底材，没有把 38 个提示文件冒称为 38 次生图。
- samples/：原创设计样稿与生成记录；概念样稿不作 Player 截图或运行素材。
- [修订样稿](samples/style-proof-v2.png)：用来判断卡框、账簿、横幅与设置是否成套，不能切片导入。v1 错画的圆孔与滑动开关已修订。
- [生成谱系](generation-register.json) / materials/：两张概念样稿、四份真实生成底材、提示、输入引用与 hash；采用三份底材，早期下框稿因装饰线与原分类条相交而保留为失败历史。连续纸纹实际为 1254×1254，下框稿实际为 1452×1083；最终运行尺寸已按原规格导出。

生产先核对帮工、闹场、巡街共享模板及两侧账簿、阶段横幅和设置的同桌效果，再扩展全部变体。原生字体、数值与文案继续由 Unity 输出，生成器不画文字。技术导出只使用一个缩放因子等比覆盖、居中裁切；完整下框另设宽高比误差保护。功能 alpha、枢轴、网格、UV 和 .meta 沿原资产。一个物件只有一套外框，其余层按原分工提供底色、分类条、轮数槽和反馈。

样稿的插画、部件相对摆放及边角只说明艺术方向；正式牌面使用既有 28 张夜市插画，继续沿原模板的宽高比、槽位数量、位置与轮廓。当前 38 项为 30 个纸面/框面层、6 个技术渐变/高光、2 枚原生语言纸签；均已导入。实际渲染调查、代表画面人工查看和原生点击分别记录；完整原生与原作逐像素体验比较仍有合同缺口。
