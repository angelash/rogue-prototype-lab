# 夜市界面重整 · v2.8 制作方案

日期：2026-10-13。当前阶段：**审视、38 项变更规格、28 处材质目标和代表样稿已完成；两份连续纸纹底材已生成，尚未替换正式 Unity 资产**。本目录是新一轮包装的权威入口，v2.7 的素材与测试保留为历史。用户要求先审视、明确改动与目标，再推进修改；本轮据此先冻结方向，不能把样稿称为实机修复。

上一轮正确修复了 UI 的功能分层，却错误地把原作的颜色、金属渐变和棋盘纹也作为应保留的外观。新约束是：保留原尺寸、Sprite 网格、节点结构、交互与动画，重新制作属于外观的 RGB、材质色与字色。技术轮廓不能代替夜市美术。

- [审视与具体设计](audit-and-design.md)：问题、保留理由、逐个界面目标及推进顺序。
- [完整替换清单](replacements.json)：覆盖全部 82 张运行纹理，逐项尺寸、决定、目标、层角色及提示词入口。
- [颜色与运行赋色](palette.json)：岗位、分类、状态、文字、材质和代码内赋色的迁移要求。
- [分层及生产规格](layer-specs.md)：哪些层可以有装饰，哪些仅提供纹理、遮罩或反馈。
- prompts/：每个需要变更的纹理独立规格提示；这些是待生产任务，文件存在不表示已生图或已导入。
- samples/：原创设计样稿与生成记录；概念样稿不作 Player 截图或运行素材。
- [修订样稿](samples/style-proof-v2.png)：用来判断卡框、账簿、横幅与设置是否成套，不能切片导入。v1 错画的圆孔与滑动开关已修订。
- [生成谱系](generation-register.json) / materials/：两张样稿和两份连续纸纹底材的真实尺寸、提示、引用/hash、采用状态。纸纹输出实际为 1254×1254，最终原尺寸导出尚未执行。

改图的第一批应覆盖一张帮工牌、一张闹场牌、一张巡街牌、两侧委托/商号信息、一条阶段横幅和设置。放在同一桌面看成套效果后，再扩展共享模板的全部变体。原生字体、数值与文案继续由 Unity 输出，生成器不画文字。

样稿的插画、部件相对摆放及边角只说明艺术方向；正式牌面使用既有 28 张夜市插画，继续沿原模板的宽高比、槽位数量、位置与轮廓。38 项包含 30 项图面替换与 8 项原生/技术主题处理，不是声称已新生 38 张运行图。首次样稿由助手复核选作方向，没有冒称用户已批准新图或正式包验收通过。
