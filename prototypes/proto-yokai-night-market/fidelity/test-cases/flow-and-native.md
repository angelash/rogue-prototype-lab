# 交互与重开测试用例

用例源纳入 Git；执行结果、日志和截图位于 local/QAResults/，忽略。用例不能以文档存在判为通过。

## 自动流程：--night-flow

仅 QA 产品且 NIGHT_MARKET_VALIDATION 编译下安装 NightFlowProbe；正式包不含该驱动。快照并最终恢复 QA 身份的六项设置与十条成绩，不操作正式身份。60 FPS 为 QA 驱动配置，不加速 Time.timeScale。

1. 原生产启动至玩家回合：95 卡、28 委托、双方各五张手牌。
2. 调用原选项按钮 Click：进入状态 80 且菜单启用；修改并保存六项设置，再调用恢复按钮回到原玩家回合。
3. 使用原 CompleteTask 填满玩家委托，形成短流程胜利夹具；等待原动画、成绩保存和 PlayAgain 按钮就绪。它不作为整局 AI 对战证据。
4. 调用原重开按钮 Click：进入原 -1 淡出/重载；只重载一次，产生新 CardManager。
5. 新局回合 1、95/28 内容、双方五张牌、完成工作和分数归零；六项设置与成绩保留。

共 15 项断言，240 秒超时和脚本错误均失败。与已有 40 项规则和自动整局用例互补。

## 原生 Release 键鼠

只能在可见的正式包窗口操作；遇到系统安全提示时停止该窗口输入。每个操作先看当前画面，截图记录实际版本和结果。

- 逐牌停顿：展开新牌保持等待；Space 推进下一张。
- 选牌与出牌：鼠标停在手牌上查看展开信息，再点击当前手牌使用，检查帮工/闹场位置及分数；不满足条件时提示原因且保留手牌。
- 交班：Space 和鼠标右键分别能交班，AI 动画继续，玩家回合再次可操作。
- 暂停与恢复：点设置进入四选项；恢复原回合；语言槽切换更新可见文本，声音选项显示与岗位招客分开。
- 保留原语言对象位置：右侧红灯图标是槽 0（中文），左侧蓝狐图标是槽 1（英语）；不能按对象旧名称推测当前文案。
- 快进：Tab 切换后打开设置核对快进指示，关闭后回到原节奏。
- 改名：点击委托改名、键入名称并确认；关闭重启后名称和设置保留。
- 退出：短按 Esc 后释放取消退出；长按约三秒退出。技能 API 不支持按住时，长按保持未验。
- 两页教程、鼠标目标选择、调停反制窗口、胜负/重开、失焦与听感另行逐项记录，不能用直接调用补作原生通过。

## 包装文案画面检查

v2.4 新增 `run_local_qa.ps1 -VisualOnly -EvidenceSuffix <新修订后缀>`，仅调查两画幅，避免为了字色/文案改动重复整局 AI。再以 `-VisualOnly -EnglishSurvey` 和独立后缀执行英文调查。四组各 128 张，包含标题、两页教程、两种语言选项、95 张展开牌及 28 张委托。

自动检查宽高、内容数量、两页教程、非空渲染、逐张语言值、牌框文字宽度、教程可见文字的屏幕边界和脚本错误；通过后仍查看实际截图。人工核对题名/岗位/委托说明对比度、台词/效果换行、字符缺失、文图语境与规则限定。保留失败轮次；最终交付指向最终画面。截图中的隔离摆牌属于视觉证据，不推断原生键鼠或每张效果都已实玩。

## 右下角操作提示：v2.5

`run_local_qa.ps1 -PromptsOnly -EvidenceSuffix <新后缀>`，中文和 `-EnglishSurvey` 英文各执行两画幅。每组保存正常桌面、教程继续、逐步暂停、调停提示、隐藏后五帧，以及全部 28 份委托标题，共 33 帧。QA 驱动冻结 Loader，只调用原 Continue 的 EnableTutorial/Enable/EnableDecision/Disable 并让原动画更新，不注入正式包。

断言提示出现/隐藏、可见文字在屏幕内、主提示不超过底板、语言、33 帧数量及脚本错误；另检查 28 份委托的字幕宽度和折叠状态标题间距；逐个单独渲染题名/字幕并量黑底上的亮色墨迹，不能与名称相交。字体包围盒含空白边距，不能直接当作墨迹；夹具暂停单卡 Update 防止其动画覆盖摆放。静态检查 628×174、均匀暗色 RGB、原 alpha 逐像素相等、运行副本 hash；禁止重新把 SubTitle 归为 title。人工检查正文、关闭暂停文字和倒计时层级，再检查实际 Release 的逐牌暂停和原生键鼠推进。QA 调停夹具不等于完整原生反制验收。

## 分类色条可辨性：v2.6

继续用 -VisualOnly 和 -EnglishSurvey 串行调查两画幅；保留 128 帧/95 卡/28 委托、语言、宽度和教程边界断言。对 Type 6/7 的全部 26 张闹场/挖角牌，额外关闭其它 Renderer，在黑底上分别渲染 03 Details Top 和 03 Details Lines。每层须有至少 100 个最大 RGB 通道 >16 且通道差 >8 的像素；原纯黑 _Color 会产生 0 个，因此能区分色条仍然全黑、空图或没有实际接入的情况。每组要求 negativeCardsChecked=26、negativeBandInkChecks=52，正式包不包含这个驱动。

人工核对用户指出的第 64 牌和第 43 闹场牌、其它类型样本及轮数槽：陶红色条表示干预分类；轮数槽/进度轨道的深色凹位和字形轮廓仍保留。不能因还有合理的深色背景就把整卡背景提亮或删除功能区域。该检查证明包装可辨，不替代原生选牌或 26 种效果实玩。
