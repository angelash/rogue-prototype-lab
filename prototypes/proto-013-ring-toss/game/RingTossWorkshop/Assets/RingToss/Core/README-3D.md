# 三维 P0 规则参数 v0.6

日期：2026-10-09。用户已明确改变视觉方向：真实三维场景、斜视角、玩家在镜头前向前投向地摊。下面是本轮助手提出并冻结到 `Rules3D.ParameterVersion=0.6.0` 的初始可调参数，不是已实测难度或最终平衡。旧二维 Flight 与旧接受高度 1.2 米保留为历史测试，新运行时使用 Flight3D。

六槽索引从 0 开始。前排索引 0/1/2 为 X=-1.6/0/1.6、Z=3.4 米；后排 3/4/5 为相同 X、Z=5.6 米。接受平面 Y=0.65 米，`Rules3D.SlotPosition` 返回接受区圆心。发射位置为 (0,0.8,0)，地面 Y=0；规则边界为 X -6..6、Z 0..12、Y 0..7 米，镜头角度不改变这些坐标。

`ThrowInput3D(azimuthDegrees,elevationDegrees,speed)` 的横向角为 -30..30°、仰角为 20..75°，各量化到 0.25°；速度 4..12 米/秒，量化到 0.02 米/秒。初速为 `(v*cos(el)*sin(az), v*sin(el), v*cos(el)*cos(az))`。仅 Y 方向施加重力 9.8，固定步 1/120 秒，步内按解析恒加速度分段推进；6 秒飞行时限、16 米/秒效果速度上限与逐机关/整圈触发预算沿用 04。

圈中心为三维判定质点。下降穿越 Y=0.65 且竖直速度不高于 -0.15 时，XZ 与奖品圆心的距离不大于 0.24 米才接受。该区为圆盘，不能分别检查 X/Z 半宽当成方框。奖品侧柱为半径 0.08、Y 0..0.65 的圆柱；求连续首次接触，接受顶边与柱体同刻相交时接受优先。圈内半径与模型外径不扩大机关的接触体。

风扇作用盒横向 X 宽 1.2、纵向 Z 深 2.4 米，中心 X/Z 为槽位，Y 范围 0.8..2.4 米。支架判定为半径 0.1 的球，圆心为 (槽X,0.9,槽Z)。默认朝向 0°；旧朝向角映射到 YZ 方向，普通圈冲量引起 `(0,2*sin(angle),2*cos(angle))` 的速度变化。风扇不修改 X 速度、不吸附到奖品中心；达到速度上限时对完整向量等比例缩放。每投同件最多一次，耐久上限 4。

板材是有限薄矩形：中心为槽位接受圆心，横向 X 宽 1.0 米，YZ 倾斜跨度 1.0 米。朝向角 15..165°、每 5°一档，默认 45°；其 YZ 切线为 `(0,sin(angle),cos(angle))`，法线为 `(0,cos(angle),-sin(angle))`。两侧接触均分解完整三维速度并施加 `0.95*切向速度 - 0.8*法向速度`；X 属于板面切向，摩擦只保留原方向的 95%，不朝中心修正。离有限板面 0.02 米才能重新触发，同板每投最多两次，耐久上限 6。有限板宽之外穿过所在平面不碰撞。

三维事件 `PhysicsEvent3D` 的 Position、VelocityBefore、VelocityAfter 均为 Double3；按事件时刻及稳定物件 ID 排序。SlotObject 仍持有身份、类别、耐久、方向和获取价快照；旧 X 属性仅供二维 Flight，新三维表现应读 Rules3D.SlotPosition，不能把旧一排 X 布置继续当作三维位置。

经济没有新增第二份实现。StageSession.CreatePrototype3D 创建相同三风扇/三板材奖品、210 新奖品价值、105 目标、8 普通圈和2次开摊后调整；Launch3D/Step 使用共同处置和结算逻辑。CreateReplayLastThrow3D 从该投发射前槽快照重算，不改正式圈数、账目或耐久。完整版跨摊、保存和其他圈/机关仍为后续范围。

独立闭式核算以 45°仰角、`R=sqrt(x²+z²)`、`v²=9.8*R²/(R+0.15)` 得到六槽量化输入：前排 (-25.25,45,5.96)、(0,45,5.64)、(25.25,45,5.96)；后排 (-16,45,7.46)、(0,45,7.32)、(16,45,7.46)。数学重算的穿越圆心误差为约 0.0056..0.0137 米，均小于公开接受半径；这个计算尚不代替 Unity NUnit、实际场景与输入设备核验，实际结果由协调者统一登记。
