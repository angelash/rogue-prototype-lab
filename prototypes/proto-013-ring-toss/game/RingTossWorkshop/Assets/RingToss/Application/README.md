# 首摊规则接口与范围

版本：三维接入 v0.6，2026-10-09。历史二维数值来源为 `docs/design/first-batch/proto-013-ring-toss/full-game/04-economy-and-balance.md`；用户本轮明确改变为三维斜视角地摊，新增三维参数及独立数学证据见 [三维规则 v0.6](../Core/README-3D.md)，均为助手初始建议。

当前实现普通圈、六槽、风扇和反弹板，以及一摊的投掷、互斥兑现/留场、拆卸、调整、补圈和主动结算。首摊固定交替三件风扇奖品和三件反弹板奖品，实际新奖品总价 210，目标 105。普通圈无环境风、无阻力；风扇留场默认朝右 0°是本次原型作者布置。完整版的其他圈型、四种机关、十二摊内容、解锁、商店修理、跨摊携带和磁盘存档尚未由这些类实现。

当前三维主路径为 `CreatePrototype3D`、`Launch3D`、`ActiveFlight3D`、`LastFlight3D`、`LastInput3D` 和 `CreateReplayLastThrow3D`；三维风扇 0°指向前方 +Z。历史二维 CreatePrototype/Launch/Flight 保留以继续核验旧规则。两条路径使用同一个 StageSession 经济状态机，Step 接口不变；不能给三维会话发送二维发射命令，反之亦然。

`StageSession` 持有正式状态，表现层只读公开属性并发送带唯一事务编号的命令。`OpenStage` 是免费准备与收费调整的边界；准备阶段合法移动、交换、转向、开关不扣次数，开摊后各扣一次。移动与交换的重载允许同一动作设置目的朝向。非法操作和朝向未变化不扣次数。奖品不能移动，初始六槽配置最多覆盖两件有耐久旧物；本次界面是否提供旧物配置由宿主决定。

每次正式发射使用所属模式的 Launch 或 Launch3D，之后宿主每个模拟刻调用 `StageSession.Step`。普通圈输入先量化，两种 Flight 使用固定 1/120 秒、double 位置和速度，按解析恒加速度分段推进。历史二维步内求平面、矩形和圆体接触；三维求平面、有限板面、盒、圆柱和球接触。根收敛/同刻比较使用约 1e-11 秒的数值容差，不增加公开 0.24 米接受范围。圈中心为判定质点，柱体与机关几何固定，模型网格不参与规则。

物理事件按时刻、稳定物件 ID 排序，同一奖品顶边同时触达柱体时接受事件优先。每件风扇每投最多触发一次，每块反弹板每投最多两次且须先离板 0.02 米；整投最多六次改变轨迹的效果，效果后速度限制为 16 米/秒。关闭、耗尽或超限的机关保留实体碰撞。Flight 克隆数组，SlotObject 不可变；更新耐久以新实例替换。

`AwaitingDisposition` 必须先执行 `Cash` 或 `Retain`。最后一个圈命中后仍保持该状态，不会提前判失败。处置或空投结束后进入 `BetweenThrows`，此时允许拆卸、一次补圈、继续投掷或 `EndStage`；补圈条件与钱包检查在最终结算前执行。`Wallet` 与 `StageReceipts` 分开，旧钱包及旧物拆卸不自动满足本摊目标，目标不因开摊后卖空槽重算。

成功命令按事务 ID 去重。重复命令返回 `Success=true`、`AlreadyApplied=true`、`Event=null`，表现层不能再次播放奖励或结算效果。失败命令不登记，可修正条件后重试。不可用不同事务 ID 对同一奖品再次兑现或留场。

`CreateReplayLastThrow` 从最近一次已结束投掷的输入和发射前六槽快照创建独立 Flight；回放步进不消耗正式圈数、不更新正式机关耐久、不改账目、阶段和事务记录。它不承担存档恢复或正式投掷奖励。

`Tests/EditMode` 的 NUnit 用例核验解析基准、六槽量化可达、接受边界、步内侧撞、双面反弹、耐久、事件顺序、重放与账目。文件存在不代表已执行；实际 Unity 测试和 Player 核验由协调者统一运行并记录。
