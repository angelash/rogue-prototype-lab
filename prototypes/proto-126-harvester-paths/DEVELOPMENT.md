## 2. 开工准备

1. 核对需求/设计、共同标准和工作区，建立独立任务包、工程/参数版本、定向测试及构建入口。
2. 固定10×10田地、三类地块、仓库功能标记、三种模块和三轮订单；登记基础机能力、切幅、转弯、燃料、共享载货、粮/秸秆产出和各行动成本。
3. 明确三轮延续的地图/库存字段、新轮订单重置字段、泥地/铺路状态、容量不足处理与部分交货；基础路线无需稀有模块即可完成。
4. 首批样件为车头朝向/切幅、作物/收后地面/泥地、粮/秸秆、仓库、燃料/容量/行动三账和铺路反馈；不先做真实农机物理。

## 3. 玩法与技术重点

- 一个固定地图、离散移动、三模块、三订单先验证路线取舍。仓库是地块功能标记，不额外扩第四地块；无农业生态、天气、自由农场或多车协作。
- 同一地块收割只产一次真实粮/秸秆并改通路。两类货共享空间，首版全产物装下才收割；容量不足不执行半次收割或静默删副产物。
- 秸秆转燃料或铺路互斥消耗；燃料和剩余行动分别记账。移动/转向/收割/转燃料/铺路/卸货/补给有公开成本，加油绝不增加本轮行动截止。
- 先验证全部预算/材料/容量 → 完整执行并扣费 → 更新交付 → 判断目标/截止。最后行动交付有效，失败动作保留原状态，交付粮不仍留车上。
- 每轮只选一改装，具体利益和代价可查；宽切头不免费切回窄模式。预览、执行和复盘共用地块、动作费用、资源与订单规则。

## 4. 美术、音频与交付

朝向、切幅、收后通路、铺路变化和共享货箱必须实际可见。燃料/容量/剩余行动分开显示，失败说明具体限制；铺路不能只换贴图而通行未变。

二维格图或Blender低模按本项目镜头决定，保留源/导出、单位/轴/枢轴或透明边界，逐项清理许可与哈希；装饰网格不扩大收割范围。移动、收割、满仓、铺路、转燃料、交货和截止音对应实际事件，静音仍有状态变化/文本。首轮不强加人物配音或复杂引擎声模拟。

## 5. 首次纵切与阶段顺序

顺序建议：基础移动/收割/回仓 → 共享容量与固定截止 → 秸秆两用 → 单选模块对照 → 三轮持续地图/订单 → 完整复盘/失败重试 → 正式样件与Windows真实输入 → 路线取舍成立后扩内容。

首次纵切执行 [HRV-A01–A05](../../docs/design/first-batch/proto-126-harvester-paths/requirements.md)。保留重复收割拒绝、同秸秆两用途、补油不加行动、容量不足整笔拒绝、三模块/基础路线、末行动交货和跨三轮资源核账的输入/事件证据；同粮不得重复交付。

按共同标准，首次纵切还要定义动作结束及订单轮切换的安全保存/恢复，核对地图、车/模块、粮/秸秆、燃料/行动和本轮交付；恢复不重收割、不返还行动或重复交粮。当前尚无存档实现或故障报告。

真实 Player 核对移动/朝向、收割预览、转燃料/铺路、回仓/部分交货、模块与复盘，记录版本、真实输入、画面和结果。再用HRV-H01–H03比较同图不同订单/模块，观察返回时机、货物安排和宽切幅代价；固定外圈全清、加油破坏截止或宽切头恒优时先修约束，不扩作物。
