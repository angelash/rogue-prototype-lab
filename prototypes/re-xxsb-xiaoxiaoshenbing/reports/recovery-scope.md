# 恢复层次与当前边界

日期：2026-10-14。用户已确认本地代码反编译与资产提取授权；本项目按指定 APK 的实际字节形成静态研究成果。

## 已覆盖

- 原件、副本及全部 1,488 ZIP 条目已校验；完整解包 370,964,058 字节与登记 hash 一致。
- 35 个标准 DEX 全部独立解析与 Android SDK 指令反汇编，覆盖 17,317 个类定义（14,935 个唯一类名）、113,830 个方法体及 3,157,749 个 16-bit 指令单元。独立计数一致；重复定义和空 DEX 原样保留。
- 嵌入包装另恢复 1 个完整 DEX，共计 36 DEX、17,417 类定义（15,014 唯一类名）、114,259 方法体及 3,169,066 指令单元；旧包装未覆盖，校验与 SDK 独立计数通过。
- 21 个原始托管 PE 镜像全部提取/索引，实际 IL 的 53,427 个方法体无解码失败。10 业务 DLL 的 50,738 个 IL 方法体与 11 AOT 补充镜像的 2,689 个 IL 方法体分开登记。生成 7,319 个 C# 阅读文件，其中业务 4,239 个；反编译文本不是原作者源码。
- IL2CPP metadata v31 与 ARM64 libil2cpp.so 配对，生成 67 个声明程序集和 133,186 条 native 方法名称/地址；全部这些地址在 ARM64 可执行区反汇编中得到标注。
- 全部 40 ELF 已登记节、符号和依赖；ARM64 的 20 个库、43 个可执行节全量线性反汇编，共 53,005,796 字节。3,772 字节被工具标为数据/不可解指令，不冒称正常指令。ARMv7 原字节、ELF 元数据及同样 67 声明镜像/133,186 方法地址均已恢复，两 ABI 的方法名称多重集合一致、地址均落在可执行节；未宣称其高级源码已还原。
- 484 清单包与额外启动包全部解压；1,438 逻辑资产全部关联到对象，清单 MD5/CRC/大小闭合。59,312 对象中 59,311 个当前类型树通过；235,902 个已解析引用全部在库存中解析到目标。
- 150 个合并配置项全部保留并解释，其中 146 行表、2 KV 表、2 空表头占位。10,495 行记录、130 KV 项、8,257 次对象池引用、2,399 语言行与 1,022 中文关联均有索引。
- 所有 92 TextAsset 原字节保存；21 PE、24 JSON、24 SDF 块、12 A* 分块、5 A* 包装/索引、3 FMOD RIFF、3 其他二进制分别登记。原生空间数据的字节布局与物理/路径语义分开。
- 媒体对象 3,388 项已处理，无失败：1,501 纹理、1,004 精灵、230 静态网格、215 音频、190 动画、114 Avatar、122 Shader、6 ComputeShader、3 Font；另 3 张空运行时纹理没有伪造图像。

2. **嵌入载体历史限制已关闭**：`assets/39285EFA.dex` 的 71,500 字节包装已恢复为 DEX 035，SHA1/Adler32/大小全部通过。新增 100 类、429 方法体和 11,317 指令单元，常规/逐 DEX fallback/SDK 三层解析通过；原包装与派生摘要分别保存。
3. **Java 结构化诊断**：常规 JADX 有 10 个节点错误（工具日志另有重复错误行）和未知类引用提示。逐 DEX fallback 与完整 SDK 指令保留、计数通过；没有用常规 Java 文件数证明所有高级 Java 都可编译。
4. **AOT 高级算法**：DummyDll 只有声明/占位方法，补充镜像只提供一部分 IL；原生机器码已反汇编，不等于全 C++/原 C# 的控制流和语义均已重建。
5. **原作者 Unity 工程**：没有原 `.cs`、`.unity/.prefab` 编辑器文件谱系、原 `.blend/.fbx`/分层图稿、声音制作源、原项目设置/包锁或签名私钥。导出的 OBJ 丢失蒙皮/材质/场景层次，PNG 是解码图，动画/Avatar/font 保存的是序列化字节，不宣称已得到作者源文件。
6. **原生地图语义**：SDF、A* 和混合渲染 payload 的已验证结构与完整算法解释区分。战斗一致性清单是客户端自述原制作输入 hash，其中原作者文件不全在 APK，未独立复算作者全部源目录。
7. **包外与服务端**：在线协议 schema 可读，但服务器源码、规则校验、运营开关、远程热更新和账号/付费状态不在本包分析结论中。注册表中出现而未保留的模块单列，不自行下载缺失内容。
8. **运行与移植**：未运行 APK、联网、修改/重签名、重建可运行工程；没有真实输入、画面、听感、性能或功能对照验收。静态源/数值理解与实机行为分别记录。
