## 2. 开工准备

1. 核对需求/设计、共同标准及工作区，建立本项目任务包、独立工程/配置版本、测试与构建入口。
2. 固定一零件箱及两简单物件基准，再列四形状的占格、入口/出口、锁定朝向、重量、价值、基础射程、电量与订单。
3. 明确根移动/整体旋转、障碍/同距首件裁决、接入重叠、待处置位置、出售区域和拆中间件后的后段去向；预览和执行共用查询。
4. 首批样件覆盖磁头、四形状、接点/唯一末端、首件射线、承重/电量、暂存与订单提示，不先建通用拼装库。

## 3. 玩法与技术重点

- 最小范围是离散网格、四形状、固定接点/朝向、确定单次吸附、订单和有限电量；不加连续磁场、刚体堆叠、树状任意电器或复杂抓斗。
- 整条结构随根移动/旋转，构件朝向由接点锁定；末端决定下一吸取起点。占格、连接、射程与承重共同决定结果，不能把长度仅做数值加成。
- 从唯一末端查朝向上的首个可达铁件，障碍和首件阻断后方。首件超重时失败，不能跳到后件；同距按稳定编号裁决。
- 校验电量、首件、总重和接入占格后才转移物件。待处置不能继续吸，实际交付前不发钱/订单进度，待处置件不免费延伸。
- 物件唯一属于箱内、待处置、链、暂存或已售。拆中间件连同后段公开暂存；出售物不再提供工具或重复交付。失败重排/吸取不损原状态或执行半笔交易。

## 4. 美术、音频与交付

完整链占格、固定接点、出口朝向、首件和阻断理由必须可读；同时显示总重/上限与电量，不把过重包装成概率。吸附动画从提交结果生成，不能让看见碰到就算抓到。

采用二维图或Blender低模前先确定本项目镜头和格点锚点；源、导出、轴/枢轴或透明边界和商业使用许可逐项登记。网格占格不由任意模型Collider推导。吸取、阻塞、超重、保留、拆卸和交付音只响应实际事件，均有静音说明；不默认配音或照搬套圈音色/身份。

## 5. 首次纵切与阶段顺序

顺序建议：两简单件的固定吸取/唯一归属 → 连接/末端与四形状 → 负载/电量 → 待处置/出售/拆装 → 一箱订单完整循环/复盘 → 正式样件与Windows真实操作 → 几何取舍成立后扩布局。

首次纵切执行 [MAG-A01–A05](../../docs/design/first-batch/proto-121-magnet-scavenger/requirements.md)。保留空头/长件同落点、前重后目标、出售移除、拆中段、电量不足及窄缝拆短序列；检查预览/执行一致、物件守恒和失败事务不改状态。

按共同标准，首次纵切还要定义动作结束的安全保存/恢复，核对根与链、箱内/待处置/暂存/已售归属、电量和订单；恢复不重复吸取或交付，同一件始终只有一个位置。当前尚无存档实现或故障报告。

真实 Player 验证根/朝向选择、预览、吸取、处置、拆装、复盘与重试，记录版本、输入/事件和窗口画面。再用MAG-H01–H03观察预测下一吸、主动拆短及同物因订单改变用途；长结构恒优、超重只能碰运气或主要整理菜单时先修规则，不加形状掩盖问题。
