# 121 单链规则权威

版本 `0.2.0`，快照格式 `1`，2026-10-10。全部数值是首次纵切的助手可验证初值，尚非平衡/趣味实测结论。原需求/设计v0.1保留；真实Unity、构建和窗口证据由项目开发记录登记。本目录为几何、物件归属、电量、订单和事件的唯一实现权威。

## 有限箱体与数值

- `Rules`：12×8，内部坐标0基，`CellId=y*12+x`；界面及面向玩家的坐标文字加1。Up增加Y、Right增加X，方向枚举Up0/Right1/Down2/Left3。根起始 `(1,1)`、朝Right；固定墙 `(5,2)/(5,4)`；回收区为根在 `x0..2/y0..3`，不是远程售货按钮。
- 单链、4固定形状、5唯一铁件，不随机生成、不用连续磁场或刚体。初电60、射程4、承重6、钱包0。成本：根移动1，整体旋转2，吸取2，保留1，出售1，拆后段2，重装1；电量不足或非法操作整笔拒绝，状态、归属与电量均不变。
- ShortPlate短片：局部占格 `(0,0)`，出口 `(0,0)` 朝Right，重1、基础价3。
- LongRod长杆：局部占格 `(0,0)/(1,0)/(2,0)`，出口 `(2,0)` 朝Right，重2、基础价6。
- Elbow L形件：局部占格 `(0,0)/(1,0)/(1,1)`，出口 `(1,1)` 朝Up，重2、基础价5。
- HeavyBlock重块：局部占格 `(0,0)/(1,0)/(0,1)/(1,1)`，出口 `(1,0)` 朝Right，重5、基础价9。
- 全部入口是局部 `(0,0)`，入口面朝局部Left；`Facing`表示局部+X的全球方向。吸附时将入口放在上一出口沿出口方向前一格，整件按入口锁朝向，不能单独自由转某段。出口坐标是该件实际占格上的接点，下一件仍从出口向前一格接入。
- 原箱体ID与姿态：ID1短片 `(2,1)`、ID2长杆 `(4,3)`、ID3 L形件 `(8,3)`、ID4重块 `(6,5)`、ID5短片 `(9,5)`；全部原始Facing=Right。每件始终只属于Crate/Pending/Chain/Storage/Sold之一。

## 完整几何和首件吸取

`Move(Direction)`移动根的一个正交格，保持根朝向；`Rotate(±1)`绕根整体转90度。每次先计算根、整条链和待处置件的最终全部占格，校验出界、固定墙、结构自身重叠及箱内未拾铁件占格。合法后才同步位置、锁定接点和扣电。离散规则校验最终格姿态；表现旋转动画不额外产生物理碰撞真值。

链的唯一末端是最后一个正式保留构件出口，无链时是根。`PreviewAttract()`从末端沿其出口四向扫描距离1..4；每个格先处理边界/墙/当前已装占格，再取箱内相交铁件。首件按最靠近相交格确定，同距按稳定ID升序。首件超重、接入重叠或电量不足时拒绝，不能跳到后件；预览保留首件ID和实际原因。正式 `Attract()` 没有可选目标ID参数。

吸取校验全部成本、首件、总重和固定接入完整几何后，将同一物件从箱内移到Pending。抓取后的实际位置为规则接入姿态，不由动画碰到的位置决定。`AttractPreview.CandidateCells` 是新件完整占格，`RayCells` 是到首件/阻断/射程的实际扫描格；已有构件和待处置件使用 `ItemState.Cells`。

Pending计入总重、占格且随根移动/整体旋转，但不改变唯一末端，不给钱或订单进度，不能续吸。期间可付电移动、旋转、保留该件，或回收区出售该件；不能绕过当前处置去拆装或卖别件。保留付1电才成为Chain并改变末端，L形件会使之后连接/射线转向。若出售地点不合法，Pending保持原归属和完整负载，没有半笔交易。

## 回收区、暂存和订单

- `Sell(id)`只在回收区出售Pending、Storage或链尾。已售/箱内件不能卖；链中段不能直接卖，需先拆下。出售移除实际ID，给基础价；若该件真实贡献当前未完成订单，还加2收入并将对应需求加1。钱、进度、物件移除在同次命令中完成。
- `Detach(chainIndex)`只在回收区且无Pending时进行。索引0为第一构件，选中件及其全部后段一笔转Storage；整次费用2，不逐件重复收费。不留下悬空出口、重量或射程。预览 `AffectedItemIds` 给出真实后段顺序。
- Storage是回收区托盘上的逻辑暂存，保留唯一ID与最后合法姿态记录，供表现定位；不占田箱格、不提供重量/工具。`Attach(id)`在回收区把单个实际暂存ID加到链尾，重新校验入口、完整占格及负载，付1电。不合法重排完整拒绝，不删除暂存件。已售物永不再提供工具。
- 单轮一个公开订单，使用相同地图/物件/初始资源独立对照：Parts需长杆、L形件各1；Heavy需长杆、重块各1。不跨订单带钱或货物。非订单短片仍能基础卖3，是明确补救。
- 每次有效操作先完成归属/资源/订单，再检查目标，最后检查电量。最后1电实际出售完成目标时Completed；电量0未完成则Failed，保留真实已售/部分交付/收入，不能继续操作。目标提前完成就结束本轮。非法动作不为“尝试”扣电，也不自动发失败奖励。
- `Retry()`返回同订单的全新独立初始轮，恢复初电60/钱0及5件原箱内状态；不返还给旧轮。换订单同样从相同初态开始。根空头就能开始普通吸取；完整保底路线见下文。

## 公共API与保存

命名空间 `MagnetScavenger`、程序集 `MagnetScavenger.Core` 无Unity引用。`Session.CreatePrototype(OrderKind.Parts/Heavy)`；`State/LastEvents/ExportSnapshot()`深拷贝，公开DTO为Serializable字段，Unity输入只产生命令。

命令为 `Move(Direction)/Rotate(int quarterTurns)/Attract()/Retain()/Sell(int id)/Detach(int index)/Attach(int id)`，均可传可选 `commandId`。`PreviewMove/PreviewRotate/PreviewRetain/PreviewSell/PreviewDetach/PreviewAttach`返回 `ActionPreview`；`PreviewAttract`返回 `AttractPreview`。预览、取消和事件复盘不执行命令、扣电或发钱。

`RoundSnapshot`保存规则/格式/订单版本、根与朝向、phase/outcome、电量/钱、链序列/暂存/已售/待处置ID、所有物件完整姿态及唯一归属、唯一末端/占格/总重、订单需求和交付、成功命令及事件。`ActionIndex`为已提交命令数，独立于所花电量；事件有稳定Sequence、ActionIndex、ItemId和原因，能复盘每笔变更。

`ValidateSnapshot/TryRestore`先做有限范围/唯一归属检查，再从相同订单初态执行记录的生产命令，比较全部序列化字段。未知版本、假电量/钱/订单进度、重复归属、改接点/占格/末端、错误phase都拒绝。合法Pending、暂存、失败和完成检查点都能恢复；恢复不追加命令/事件、不再吸取或卖货，LastEvents清空。相同已提交命令ID再次执行返回 `AlreadyApplied=true`，不改状态、不发事件。该检查拒绝不自洽本地检查点，不声称是防作弊签名；磁盘提交/备份由独立 `CheckpointStore`处理。

## 独立黄金输入与边界

这里的坐标均为内部0基，`U/R/D/L`为根绝对方向移动，并不自动转磁头。`Rotate(-1)`从Right转Up，`Rotate(+1)`为枚举四向的顺时针下一向。`Attract2/3/4`只描述预期首件ID，正式吸取API仍无参数。

Parts链与拆卸路线：`U,U,Attract2,Retain,Attract3,Retain,Detach(0),Sell3,Sell2`。9命令，移动2电、吸取4、保留2、拆卸2、出售2，共12，余48，收入L形7+长杆8=15。根 `(1,3)`；已售ID2/3，链/暂存/Pending均空，ID1/4/5原箱内。空头同根原射程到x5，保留杆后末端x4、射程能到x8的L形件；实际几何经过 `(5,3)` 窄口，L在 `(6,4)`转出。

Parts空磁头保底路线：`U,U,Attract2,Sell2,R×3,Attract3,Rotate(-1),L×2,Sell3`。12命令，共15电、余45、收入15；根 `(2,3)`，始终没有正式保留链。两个订单部件均可不用稀有磁头处理。

Heavy空磁头保底路线：`Attract1,Sell1,U×2,Attract2,Sell2,R×5,U,R×2,U×2,Rotate(-1)×2,Attract4,L×5,Rotate(-1),D×4,Rotate(+1),L,Sell4`。去重块前有12次移动、返回10次，总22移动；整体旋转4次计8电，吸取3次计6电，出售3次计3电。因此32命令共39电、余21，收入短片3+长杆8+重块11=22。已售ID1/2/4，ID3/5原箱内，根 `(2,2)`、朝Left、无持货或链。先出售短片清除回仓末段的真实占格，不能把这一步删掉仍声称同路线合法。

其它有区分边界：带长杆在根 `(2,5)`朝Right，末端 `(5,5)`前首件为重块ID4，合重7>6；ID5短片在其后仍不能跳抓。带长杆/L链从根 `(2,3)`向Up移动会让构件进入墙 `(5,4)`，根本身空地也不能通过；先Depot拆0及全部后段后才可移动。Parts链余1电时拆卸2电完整拒绝；最后卖L仍会耗尽并因缺杆而Failed；先卖L、保留最后1电卖杆则Completed。
