# 121 磁铁拾荒者：首轮场景资产源登记

版本：v0.2；制作日期：2026-10-10（Asia/Shanghai）。原需求/设计v0.1保留2026-10-09日期。本轮三维废料盒、形体、配色和镜头为助手实施建议；Core仍使用离散十二乘八格及固定接点。

## 来源与制作方式

原创场景源为 [MagnetSceneView.cs](../../../prototypes/proto-121-magnet-scavenger/game/MagnetScavenger/Assets/MagnetScavenger/Presentation/MagnetSceneView.cs)，制作配方、尺寸、状态映射与源码SHA256见 [asset-register.json](asset-register.json)。

本轮未调用Blender、ImageGen、外部模型包或付费服务，没有本项目FBX、`.blend`或栅格美术成品。圆角棱柱、环带、箭头与射线由C#生成；圆柱使用Unity内置网格，材质使用Built-in Standard。基础网格/TextMesh配方沿用本仓原创032代码（提交`afee539`），未复制寿司场景或玩法。

代码与参数为本仓原创，不将Unity引擎、项目整体或独立字体/音频声明为CC0。原始制作源在Unity源码内，网格仅在运行内存生成。后续若采用Blender，需保存真实源、导出、预览与哈希，保留已有Unity `.meta`。

字体及九个运行音频资源由协调者接入，逐项来源见 [runtime-resource-register.json](runtime-resource-register.json)；本登记不把文件存在或哈希检查写成Player听感已通过。

## 权威与空间锚点

1. Core `Rules/Session` v0.2.0是规则权威；视图只读`Session.State`与`Session.PreviewAttract()`，不执行吸取、移动、旋转、保留、拆卸、重装或出售。
2. 十二乘八格，`id=y×12+x`，Core X0–11/Y0–7对应UI列1–12/行1–8；X左→右、Y前→后。视觉格距0.66m，格中心`((x-5.5)×0.66,0.045,(y-3.5)×0.66)`。
3. 地砖0.636×0.045×0.636m，顶部y=0.045m，缝隙0.024m。Root、ItemState.Cells、入口/出口、末端、射线、首件交格、阻断和代理共用此锚点。
4. 固定选择代理0.62×0.28×0.62m，中心为格底面上方0.12m；装饰无有效碰撞器。`TryPick`先检查实际Camera.pixelRect，只返回格坐标，Runtime再按真实归属选择；模型外轮廓不能决定占格或可达。
5. Depot只读`Rules.IsDepot`，当前X0–2/Y0–3，用浅金地砖和区域外缘线说明。左侧回收台在网格外，仅包装出售/拆装；不是新增位置。墙格只读`Rules.IsBlocked`，当前Core(5,2)/(5,4)。
6. 四形状的完整占格直接来自ItemState.Cells，入口/出口来自EntryX/Y、ExitX/Y及ExitDirection；视图不复制LocalCells/ItemExit计算，不从任意Collider推导几何。
7. 正式唯一末端使用RoundSnapshot.EndX/Y/EndDirection；Pending虽计重占格，仍不延伸末端。Storage/Sold不画在板上；暂存托盘仅按StorageIds显示实际物件图标/编号，不制造新板上占格。

## 有限资产清单与读图

1. 废料工作台：暖灰台面、深蓝低废料盒、奶油格、背沿牌、右侧行1–8/前沿列1–12；外围装饰与柜台避开选择区，保留全板可见。
2. 磁头：黄色三段U形体、红/米白双极面，按RootX/Y及Facing表现。空链时简短深色标签“磁·末”，有链时“磁头”与独立深色“末端”标记分开，避免把Pending当延伸工具。
3. 短片：单格低钢片和双铆钉；长杆：三格钢轨及顶缝；L形件：按实际三格折线连接的青灰件；重块：四格低重钢块及浅顶带。形状、材质和“短/杆/弯/重#ID”共同区别物件，不由大小猜重量。编号有独立米白小底牌，放在真实入口格前方，避免铁件中央文字压在深金属或与墙字同列。
4. 入口：实际Entry格上的黄色环；出口：实际Exit格上的青蓝箭，方向取ExitDirection。黄环与蓝箭兼有形状差异，前沿图例写明；入口圈相对格中心偏后左、出口箭向真实出口方向偏0.18m，均是同一接点格内的读图偏移。
5. 归属：Chain每占格青蓝完整框；Pending每占格橙色角括号，物件编号后加“待”；当前选择每占格绿色环。Crate物件保持独立钢件形体。入链/待处置/选中用不同轮廓，不能只靠颜色。
6. 射线：直接读取AttractPreview.RayCells，白色低点和连线；首件相交格用白完整框，保持首件ID语义，不能点击改成任意目标。CandidateCells用细金色/红色角括号表达接入预览，不生成第二份物件。
7. 阻断：真实BlockX/Y在板内时显示红叉；板外阻断不夹回边缘制造假格。超重、电量、无目标、待处置和接入重叠等完整拒因由Runtime显示，红色角括号不解释成随机抓取。
8. Depot：浅金地砖、外围边线、网格外木柜/奶油台面/蓝收料盆，“回收区”和“出售·拆装”文字；不以柜台碰撞开放交易。
9. 暂存：右侧木浅托盘，按实际StorageIds逐件显示类型小图标、稳定ID及“暂存N”。小图标不表示暂存件仍在箱内占格；Sold不显示在托盘或继续提供工具能力。
10. 障碍：深灰矮挡块、浅顶带与“墙”字，位置由Rules.IsBlocked决定；高形体限制在低层，不遮住后方格。

## 生成设置与接口

- 圆角棱柱16点轮廓、4高度层、128三角面/实例，最大倒角0.018m并受高度/最薄轴限制；环带64段、512三角面/实例；箭头一三角面、射线段一四边形。
- 状态完整框为四条棱柱、角括号为八条棱柱；框线不提供碰撞。24种共享Standard材质，默认Metallic0/Glossiness0.27，金属件局部Metallic0.33–0.38，强调材质弱自发光为色值×0.10。
- WorldText使用64px字体图集，`characterSize=请求字高×10/64`。物件标签0.19m、行列0.21m、主磁头0.20m；行号放右侧x=4.39m，与左右柜台分离，暂存/回收标题抬离容器。
- 物件底牌0.74×0.24×0.024m，深墨文字，位置为实际Entry格中心加`(0,0.47,-0.47)`m；底牌朝向相机，不改变物件接点/占格。回收台两行功能文字分别位于y=1.30m/1.02m。
- 正交相机位置`(0.30,10.2,-10.2)`，看向`(0,0.25,0.10)`，大小`max(3.70,5.95/max(0.6,最终pixelRect宽高比))`。保留Runtime的Camera.rect（当前`(.225,.14,.775,.66)`）。
- `Build(Camera)`建立一次独立根`MagnetSalvage_OriginalArt`；`Render(Session,selectedItemId)`只读快照，物件姿态/归属、射线或库存签名改变时才重建对应局部，不每帧重造全场景。
- `TryPick`只返回代理格坐标；`CellPosition/CellScreenPoint`供输入共用锚点；`Dispose/OnDestroy`释放自有材质/网格/场景，不销毁字体、引擎网格或Resources。
- 当前直接显示已提交格位置，未添加推测性吸附或售出粒子。正式吸取反馈须消费Core确认事件；总面数、绘制次数与帧时间待真实Player量测。
