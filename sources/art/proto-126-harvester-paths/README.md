# 126 收割机自己铺路：首轮场景资产源登记

版本：v0.2；制作日期：2026-10-10（Asia/Shanghai）。原需求/设计v0.1保留2026-10-09日期。本轮斜俯三维田地、形体、配色和镜头为助手实施建议；Core仍采用离散十乘十格、三轮持续地图和单选模块。

## 来源与制作方式

原创场景源为 [HarvesterSceneView.cs](../../../prototypes/proto-126-harvester-paths/game/HarvesterPaths/Assets/HarvesterPaths/Presentation/HarvesterSceneView.cs)，尺寸、配方、状态映射与源码SHA256见 [asset-register.json](asset-register.json)。源码使用UTF8无BOM、LF，登记原始字节哈希，避免Git归档换行导致偏差。

本轮未调用Blender、ImageGen、外部模型包或付费服务，没有本项目FBX、`.blend`或栅格美术成品。圆角棱柱、低模球、环带与箭头由C#生成，圆柱使用Unity内置网格，材质使用Built-in Standard。基础网格/TextMesh配方沿用本仓原创032代码（提交`afee539`），未复制寿司场景/玩法。

代码与参数为本仓原创，不将Unity引擎、项目整体或独立字体/音频声明为CC0。制作源在Unity源码内，网格仅在运行内存生成；后续若用Blender，须新增真实源/导出/预览/哈希并保留Unity `.meta`。

字体与九个运行音频资源由协调者接入，来源见 [runtime-resource-register.json](runtime-resource-register.json)。本登记不把媒体存在或哈希检查等同Player听感验证。

## 权威与空间锚点

1. Core `Rules/Session` v0.2.0为权威。视图只读`Session.State`及`Session.PreviewHarvest()`，不执行移动、收割、铺路、转燃料、交货或轮切换。
2. 十乘十格，`id=y×10+x`，Core X/Y0–9对应UI列/行1–10；X左→右、Y前→后。视觉格距0.72m，格中心`((x-4.5)×0.72,0.045,(y-4.5)×0.72)`。
3. 地砖0.696×0.045×0.696m、顶部y=0.045m，格缝0.024m；车位、地块、切幅/实际目标、选点和代理共用CellPosition。
4. 固定选择代理0.68×0.28×0.68m，中心为格底面上方0.12m；装饰无有效碰撞器。TryPick先检查Camera.pixelRect，只返回格坐标，模型/割台不能扩大选择或收割规则。
5. 仓库功能点使用Rules.DepotX/Y（当前Core(1,1)），以蓝垫、白圈、角落“仓”牌表示；左侧小粮仓在网格外，是功能包装，不新增第四种地块或交易位置。
6. 地块只读TileState.Kind/Harvested/Paved：Crop才有麦束，Mud才有湿斑；实际Harvested才有土垄/残茬，实际Paved才有秸秆路，三轮延续状态不由视图重新生成。
7. 窄/宽完整切幅直接读取HarvestPreview.CoverageCells，实际作物目标读取TargetCells；边界外点仅不绘制，查询及拒因仍属于Core。
8. 货箱容量读取Vehicle.Capacity，共享用量读取CargoUsed，粮/秸数量分别读取Grain/Straw。燃料条读取Fuel/Rules.MaxFuel，不在视图另设初燃料或行动预算。

## 有限资产与读图

1. 田地台景：暖木低基座、十乘十双色草土格、前列号/右行号，背沿三个改装小样，网格外左粮仓。完整地图保持可见，装饰不遮格。
2. 作物：每个真实Crop格五株低麦秆、金色麦头和绿叶；模型株数只用于轮廓，不代表收获产量。产物数量与装载资格只读Core。
3. 收割后通路：实际Crop消失，格色变浅土，四条土垄与三处短残茬可辨；没有收割的原始Ground保持双色普通地面，不假装产生粮。
4. 泥地：灰棕地砖、双叶深湿斑、两条浅轮辙，“泥”字配浅底牌；铺路后湿斑移除，七条横向秸秆条与“路”牌代替。形状/文字/材质共同区别，不只换颜色。
5. 收割车：青蓝低车体、奶油驾驶室、深窗、四轮/轮毂、车顶方向箭、货箱与燃料条。Facing只表现Core四向，轮子不会推进规则或计算泥地费用。
6. 窄/宽割头：可见0.55m/1.86m割台、奶油横卷筒及5/11齿；实际收割仍由Core蓝框切幅和金色角框目标决定。模型尺寸不是判定面积，也不在宽头下免费切回窄模式。
7. 滚轮模块：两侧长履带壳和六条履带凸条替换轮形；大箱体：共享货箱宽/高增加，仍是一个装载空间。车顶浅底牌显示Rules.ModuleName。
8. 双货共享箱：粮以金色小圆粒、秸以三根短条束表示；每单位占一个真实容量位置，粮先放、秸后放，数量变化才更新。容量牌“箱已用/容量”显示实际CargoUsed/Capacity，不以模型外观代替精确HUD库存；牌位于车的世界前侧，与上方模块名牌分离。
9. 仓库：低奶油墙、蓝门、斜屋顶、粮仓牌及实际“库存秸N”牌；仓库格有独立蓝垫/白圈，与车区分。库存变化来自StoredStraw，房子不能发放免费货物。
10. 三模块样件：滚轮/宽切头/大箱体小模型及浅底名称牌位于后沿，说明本轮可选类型，不是车上同时生效的三个模块。样件不处理点击或安装命令。
11. 预览：蓝完整框表示完整切幅，金色角括号表示本次实际Crop，白环表示Runtime所选铺路点；白环不承诺PreviewPave合法。材料/容量/燃料/行动的实际拒因归Runtime。

## 生成设置与接口

- 圆角棱柱16点轮廓、4高度层、128三角面/实例，最大倒角0.018m并受高度/最薄轴约束；低模球12×8、168有效三角面/实例；环带64段、512三角面/实例；方向箭一三角面。
- 25种共享Standard纯色材质，默认Metallic0/Glossiness0.24，齿金属Metallic0.30，强调材质弱自发光为色值×0.10。无外部纹理或透明流体。
- WorldText64px，characterSize=请求字高×10/64；行列0.22m、车模块名0.18m、容量牌0.17m、泥/路0.16m。功能字、数字和模块名均优先深字浅底，避免直接压深材质；外缘坐标/图例用米白对暖木。
- 车模块名牌位于车格上方1.04m，底牌宽0.74m；容量牌相对实际车格采用世界偏移`(0,0.25,-0.80)`m、底牌宽0.68m，不随车朝向跑到模块名旁。两牌仅表现，不增加占格或判定范围。
- 正交相机`(0.30,11.0,-11.4)`看向`(0,0.25,0.35)`，大小`max(3.95,5.65/max(0.6,最终pixelRect宽高比))`，保留Runtime Camera.rect（当前`(.225,.14,.775,.66)`）。
- Build(Camera)只建一次独立根HarvesterFarm_OriginalArt；Render(Session,selectedX,selectedY)只读状态，地块、模块、货物与预览各自按签名更新，不每帧重造全图。
- 更换模块时局部重建车体，旧货箱与容量牌一起销毁，防止累积旧计数。共享箱按实际Capacity布局两排单位，当前最多十位置由Core所有。
- CellPosition/CellScreenPoint为输入共用锚点；TryPick仅返回代理格；Dispose/OnDestroy释放自有材质/网格/场景，不销毁引擎网格、字体或Resources。
- 当前车直接显示已提交格位置，无推测性收割/铺路粒子；正式事件反馈须由确认事件驱动。总面数、绘制次数与帧时间待实际Player量测。
