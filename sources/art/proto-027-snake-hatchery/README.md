# 027 贪吃蛇孵化场：首轮场景资产源登记

版本：v0.2；制作日期：2026-10-10（Asia/Shanghai）。原二维需求/设计 v0.1 保留2026-10-09日期。本轮桌面生态孵化盘、斜俯三维形体、配色与镜头为助手实施建议；规则仍是离散八乘六格。

## 来源与制作方式

原创参数化场景源为 [SnakeSceneView.cs](../../../prototypes/proto-027-snake-hatchery/game/SnakeHatchery/Assets/SnakeHatchery/Presentation/SnakeSceneView.cs)。尺寸、生成配方、规则映射、源码SHA256及验收状态见 [asset-register.json](asset-register.json)。

本轮没有调用Blender、ImageGen、外部模型包或付费服务，不存在本项目FBX、`.blend`或栅格美术成品。圆角棱柱、低模球、椭圆环带与路线网格由C#生成；圆柱使用Unity内置网格，材质使用Built-in Standard。基础网格/TextMesh配方沿用本仓原创032代码（提交`afee539`），没有复制寿司场景或玩法。

代码和参数为本仓原创；不将项目整体、Unity引擎或独立字体/音频声明成CC0。制作源保留在Unity源码内，网格仅在运行内存生成。后续若改用Blender，需增加真实源、导出、预览和哈希，保留Unity `.meta`。

字体、音频与音乐由协调者接入，来源另见 [runtime-resource-register.json](runtime-resource-register.json)。本登记只负责原创场景，不以媒体文件检查替代Player听感验证。

## 权威与空间锚点

1. 规则权威为Core `Rules/Session` v0.2.0。视图只读`Session.State`，不执行移动、采集、断尾、交付、回收或奖励命令。
2. 八乘六格，`id=y×8+x`。Core坐标X0–7/Y0–5对应UI列1–8/行1–6，X左→右、Y前→后。视觉格距0.84m，底面中心`((x-3.5)×0.84,0.17,(y-2.5)×0.84)`。
3. 每格苔垫0.806×0.05×0.806m、顶部y=0.17m，格缝0.034m。身体、货物、模块、路线和代理共同引用`CellPosition`。
4. 固定选择代理0.78×0.28×0.78m，中心为格底面上方0.12m。装饰没有有效碰撞器；`TryPick`先检查实际Camera.pixelRect，只返回代理坐标，不能由蛇形、果实或叶子决定占格/点击规则。
5. 交付点使用`Rules.DockX/DockY`（当前Core(1,1)），用米白圈及“交”字标识。网格外左台和右模块盒均与其Z对齐，是功能包装；尤其回收仍须Core的主蛇头与分身头邻接条件，不由台柜位置开放新权限。
6. 模块唯一ID来自Core的七个ModuleState。已在主蛇/分身的模块按真实Segments顺序显示，不依据视觉距离接长、合并或产生新模块。
7. 地面模块可与身体或其他地面模块共存，视图按Location及坐标扫描并按ID排序；最多显示三个小形体，文字显示完整数量。货物最多显示四个果实，文字显示实际Cargo；不能从可见模型件数反推规则余量。

## 有限资产清单与读图

1. 生态桌面：暖木工作台、奶油底盘、淡绿低围沿、八乘六苔格、背沿孵化场牌和两盆小叶植。高装饰在网格外，不新增可走空间或墙格。
2. 基础节：绿色软椭球与双叶帽，“基+当前身体序号”字样；采集节：蓝色软椭球与三叉采集顶，“采+序号”；仓库节：暖橙椭球与带浅色锁扣的木箱盖，“仓+序号”。颜色、形状和文字共同区别三类。
3. 头部：只为每条蛇的实际Segments[0]显示鼻口、双眼及身份圈。主蛇徽章为“主”；分身徽章为“分+稳定实体ID”，与分身蓝/紫身份圈共同区别。颜色不承担唯一身份识别。
4. 身体连接：顺序相邻的真实Segments之间显示短圆柱。模块缓存按ModuleId复用，归属/位置以本帧快照为准，不为了连贯动画提前移动规则。
5. 货物：桃色果实、绿梗与低木果床；地面余量用“货×N”，模块余量用“模×N”，明确数量与身体模块ID的区别；共存时分两行，避免一行跨格。实际清空后移除形体和文字。
6. 障碍：浅灰低岩块与小苔叶，“墙”字显示Blocked真值；不能用植物或装饰投影推断阻挡。
7. 模块库存：右侧暖木浅盒显示InventoryModuleIds所指的实际类型，以及“盒 N”计数；没有库存时只保留空盒。
8. 交付包装：左侧木台、奶油台面、三只青绿容器及“货物交付”文字；交付格单独有“交”圈。回收按钮、邻接条件、转移货物及落地模块由Root/Core处理，场景不执行台柜交易；柜台文案不再混写“回收”，避免暗示必须回仓回收。
9. 候选切点：红色剪叉和“切”字在真实第N与第N+1节之间，N是保留节数、头计入。只在数组边界有效时展示候选，不代表Core.PreviewSplit已同意；路线、两分身上限等拒因由Runtime显示。
10. 实际路径：读取分身Route，以蓝/紫实线和节点在格角低处显示；选中分身线更粗。RouteIndex只画其公开索引圈，不冒称下一步或可达路径。
11. 确认草案：读取Root传入的GridPoint[]，金色虚线与节点和实际路径的实线区分。C/V准备、Enter确认、Esc取消的命令权威归Runtime；视图不寻路、不提交、不消耗行动。

## 生成设置与接口

- 圆角棱柱：16点轮廓、4高度层、128三角面/实例；最大倒角0.018m并受高度/最薄轴约束。
- 低模球：12经向×8纬向、168有效三角面/实例；环带64段、512三角面/实例。路线条每段实线一个四边形，草案每段四个短四边形，均沿底面朝上。
- 21种共享Standard材质，默认Metallic0/Glossiness0.22；选中圈/草案材质弱自发光为色值×0.10。不含外部纹理、透明流体或后期滤镜。
- WorldText使用64px字体图集，`characterSize=请求字高×10/64`。类型/序号0.22m、地面余量0.20m、外缘坐标0.23m，深绿背景用米白，浅苔地用深墨；单一地面类别一行，货物与模块共存时最多两行。
- 正交相机位置`(0.30,8.8,-9.0)`，看向`(0,0.25,0.20)`；大小`max(3.35,5.15/max(0.6,最终pixelRect宽高比))`。保留Runtime指定Camera.rect（当前`(.225,.14,.775,.66)`）。
- `Build(Camera)`只建立一次独立根`SnakeHatchery_OriginalArt`。`Render(Session,selectedCut,selectedClone)`只读快照，模块/身体连接/货物/库存/路径仅在对应内容签名改变时更新，未每帧重造全场景。
- `SetDraftRoute(GridPoint[])`复制预告点，null清除；`TryPick`只返回格坐标；`CellPosition/CellScreenPoint`提供共同锚点；`Dispose/OnDestroy`释放本视图自有材质与网格，不销毁引擎网格/字体/Resources。
- 当前身体直接落在已确认格中心，不引入插值遮蔽真实占格；无推测性的拾取粒子、断尾奖励或采集动画。总面数/绘制次数/帧时间须在实际Player量测。
