# 051 回收保洁队：首轮场景资产源登记

版本：v0.2；制作日期：2026-10-10（Asia/Shanghai）。原二维俯视需求/设计 v0.1 保留2026-10-09日期。本轮斜俯三维房间、形体、配色和镜头为助手实施建议；规则仍为离散六乘六网格。

## 来源与制作方式

原创参数化 C# 场景源为 [CleanerSceneView.cs](../../../prototypes/proto-051-recycling-cleaners/game/RecyclingCleaners/Assets/RecyclingCleaners/Presentation/CleanerSceneView.cs)，生产配方、尺寸、权威映射与源码 SHA256 见 [asset-register.json](asset-register.json)。

本轮没有调用 Blender、ImageGen、外部模型或付费服务，不存在本项目FBX、`.blend`或栅格美术成品。圆角棱柱、低模球、环带、框线与清洁勾形由代码生成；圆柱使用Unity内置网格，材质使用Built-in Standard。部分基础网格/TextMesh构造配方来自本仓原创032代码（提交`afee539`），未复制寿司场景或玩法。

建模代码与参数为本仓原创；不将Unity引擎、项目整体或独立字体/声音声明成CC0。原始制作源在Unity源码内，网格仅在运行内存生成，无另一份外部原稿或导出模型。若后续采用Blender，须新增真实源、导出、预览与哈希，保留Unity `.meta`。

字体/声音/音乐由协调者接入，来源单独登记在 [runtime-resource-register.json](runtime-resource-register.json)，不冒称本场景原创媒体。

## 权威与空间锚点

1. 规则权威为Core `Rules/Session` v0.2.0。视图只读 `RoundSnapshot` 和 `Session.PreviewCoverage`，不发清洁、移动、转换、出售或奖励命令。
2. 六乘六格，`id=y×6+x`，Core坐标0–5对应UI1–6；X左→右、Y前→后。视觉格距0.90m，底面中心 `((x-2.5)×0.90,0.035,(y-2.5)×0.90)`。
3. 每格陶瓷地砖0.872×0.048×0.872m，顶部y=0.035m，缝隙0.028m。地砖、污物、目标/覆盖轮廓及选择代理共用格中心。
4. 固定选择代理0.84×0.28×0.84m，中心为格底面上方0.12m；装饰无有效碰撞器。`TryPick`只读代理坐标并先检查Camera.pixelRect，视图不由污物或刷头网格扩大规则范围。
5. 补给点为Core(0,0)，有蓝白地垫和邻近回收台包装。台柜在网格外x=-3.48m，其Z直接取Rules.SupplyX/Y对应格中心（当前z=-2.25m），与服务行对齐；模型不是额外补给位置。行号位于x=-2.82m的柜与网格之间；两障碍的位置/资格只读各格Blocked。
6. 原始二维规则来源保留。展示单位为米，物理距离、车体朝向、轮子、刷头造型和动画不能决定网格移动、清洁量、接触覆盖或物料去向。

## 有限资产清单与读图

1. 房间：暖木地基/边沿、奶油背墙、双格窗框与浅蓝窗面、回收队店牌、材料形状图例、一盆矮绿植。网格前方和侧边保持开放，不设遮挡格子的高墙/自由镜头。
2. 网格：两色浅奶油陶瓷砖、脏态灰化砖、外围行列1–6标号。只有实际Remaining变为0才恢复干净材质；曾有污物的清空格显示“净”与勾形。
3. 普通碎屑：浅灰方片，固定散布角度；可转化碎屑：浅灰圆环。两材料用形状和“片/环”字样共同区分，未新增第三种材料。
4. 水渍：不规则浅蓝双叶斑与短白反光线；顽渍：暖棕双叶斑与深色结壳刮痕。斑面积随实际剩余比例缩小，并保留“水/渍+余量”的单行标识。
5. 余量标签：每格最多一行，`片4/环4/水2/渍3`中的类别与数值来自该格快照；不是根据可见碎片数反推。障碍格为“障碍”；起初干净的普通格不堆文字。
6. 蓝白工具车：低矮轮车、白色肩沿、开口收料桶、把手、滤芯管/状态灯、清洁剂量条。车体只表现PlayerX/Y；状态量条按Rules.DetergentCapacity归一化。
7. 两刷头：窄头宽0.32m、广域头宽0.68m，各有白壳、蓝面与3/7组深色刷毛，直接随state.Brush切换。模型宽度是包装，不换算覆盖数。
8. 目标/覆盖：蓝色完整方框标目标，金色四角括号标Core预览覆盖。实线与角括号保持形状差异；非法/远距目标无覆盖括号，不能由工具车模型猜覆盖。
9. 回收/滤芯台：蓝柜、奶油台面、方/圆接料孔、滤芯和清洁剂瓶；与网格外标签共同说明用途，不开独立商店或免费补给行为。
10. 障碍：低矮储物木箱、顶板条和前横带，仅表现Blocked格。桶内少量方片/圆环作类型提示（每类最多四件）；精确库存、容量/滤芯余次由Runtime HUD展示，不能把模型件数当库存数。

## 生成设置与接口

- 圆角棱柱：16点轮廓、4高度层，128三角面/实例；倒角受高度和最薄轴限制，薄板/污痕不反折。
- 低模球：12经向×8纬向，168有效三角面/实例，极点不生成零面积面；椭圆/圆环带64段、512三角面/实例。
- 连续目标方框8三角面、覆盖角括号16三角面、清洁勾4三角面。圆柱为引擎内置网格，总面数/绘制次数和帧时间待Player量测。
- 21种共享Standard纯色材质；浅底用深墨文字、蓝底用米白文字。无外部纹理、透明流体或强后期效果。
- WorldText使用64px字体图集，`characterSize=请求字高×10/64`。每格余量字高约0.21m，外缘坐标0.23m；类别/余量放在格前缘，避免占满污物中心。
- 正交相机位置`(0.35,9.0,-8.8)`，看向`(0,0.60,0.40)`；最小orthographicSize3.65，按最终pixelRect宽高比适配。保留Runtime设定的Camera.rect；当前协调者范围为`(.225,.14,.775,.66)`。
- `Build(Camera)`建立一次独立场景根；`Render(Session,targetX,targetY)`只读快照，剩量/类别变化才替换对应局部污物，库存变化才替换桶内类型提示。
- `CellPosition/CellScreenPoint`给输入/HUD共用锚点；`TryPick`只返回格坐标。目标/覆盖标识是动作预览，不播放已清洁特效。
- 工具车移动用0.20秒视觉插值，不推进规则、扣行动或提前清掉污物。无随机粒子，不生成推测性的吸取/喷洒事件。
- `Dispose/OnDestroy`释放自己的材质、运行网格和独立场景，不销毁引擎网格、字体或外部Resources。
