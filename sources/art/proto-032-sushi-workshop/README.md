# 032 回转寿司工坊：首轮场景资产源登记

版本：v0.2；制作日期：2026-10-10（Asia/Shanghai）。原需求/设计 v0.1 的日期仍保留 2026-10-09。本轮已授权首次实现，以下镜头、形体与材质是助手实施建议。

## 来源与制作方式

本轮使用原创参数化 C# 网格，不调用 Blender、ImageGen 或付费服务。完整建模源为 [SushiSceneView.cs](../../../prototypes/proto-032-sushi-workshop/game/SushiWorkshop/Assets/SushiWorkshop/Presentation/SushiSceneView.cs)；清单 [asset-register.json](asset-register.json) 保存生成规则、尺寸、材质与当前源码 SHA256。

场景没有外部图片、贴图、模型包、FBX 或 `.blend`。圆角棱柱、椭圆环带、低模球和方向箭头由源码生成；圆柱使用 Unity 内置 PrimitiveType.Cylinder，材质走本项目 Built-in Standard。建模代码与参数为本仓原创，不擅自把引擎或项目整体许可改为 CC0。字体、声音和音乐由运行时负责人独立接入并登记，不归本清单冒称原创。

程序生成源位于 Unity 工程，实际网格只在运行内存中生成，不维护另一份导出模型或 Unity 外部原稿。以后若改用 Blender，必须补真实 `.blend`、FBX、预览与源/成品哈希，保留已有 `.meta`；本轮不得把 C# 网格称为 Blender/FBX 成品。

## 功能与场景锚点

1. 唯一椭圆环盘轨：X 半径 2.45m、Z 半径 1.55m，环带中心 y=1.02m、轨顶 y=1.0575m、带宽 0.68m、厚 0.075m，金色双边沿。
2. 六逻辑槽：Core 0–5 对应 UI 1–6。角度 `-90°-slot×60°`，盘原点 y=1.095m；0 前→1 左前→2 左后→3 后→4 右后→5 右前，顺时针。数字标签沿同角度移至 X/Z 半径2.95/2.05m、y=1.17m并朝向镜头，避免被内圈工具遮住；选择代理位置保持盘锚点。
3. 入口 0、顾客 5。站模型位于同槽的内圈扇区：X 半径 1.32m、Z 半径 0.71m；其顺序/类型从 Session.State.Stations 读取，不在视图自行加工。
4. 暂存区为前左独立托盘；新切盘只随规则的 Staged/Ring 状态显示，动画不能抢先入环。
5. 六个固定选择代理为 0.82×0.50×0.82m 的 BoxCollider，中心为各槽锚点上方 0.18m；模型碰撞器禁用/移除，代理只返回 slot。
6. 展示单位为米；Core 实际规则仍是六槽离散步序，空间距离和碰撞不决定加工、份量、交付、资金或时间。

## 形体清单与读图

1. 厨房：圆角暖木岛台、墨绿单环轨、黄铜沿与24条传送缝、6个顺时针箭头；后墙、木栏、墨绿暖帘、中文店招、两吊灯、两盆栽和地板接缝。
2. 四工站：加料为碗/绿色料与珊瑚色鱼条托盘；卷制为竹帘与卷轴/海苔片；加热为珊瑚色小烤炉、深色窗口与炉光/格栅；切分为木刀板、金属刀与切样。名称取 Core Rules 同一术语。
3. 盘：米白陶瓷圆盘、墨绿细沿；交付绿牌“交”、保留金牌“留”，可交付/保留使用文字与颜色共同表示。选中槽有独立薄绿环。
4. 米基底：白色压米基底与米粒；卷料：海苔片/压米与外露鱼条、绿料；成卷：海苔圆柱、两端米/鱼/绿料截面。
5. 熟卷：褐色烤卷、金色炙纹和短白蒸气形体；小份卷/小份熟卷：缩短为半卷，明确半份文字与金色半份标记，热态仍保留炙纹/蒸气。
6. 净盘与待洗：六层盘栈、独立中文数量；待洗有污渍，旁有金属水槽。盘栈仅表达库存，不产生免费盘或清洗。
7. 顾客：独立青色衣身、肤色头、黑发/眼与珊瑚颊、木脚凳，配当前订单样件与数量/等待文字。轻微摇头仅表现，不更新离席。

模型使用统一墨绿、暖木、米白、珊瑚鱼色、金色与少量金属材质。食物身份、份量、标记及作用区优先于厨房装饰；不沿用013地摊镜头或机关外形。

## 生成设置与接口

- 自定义圆角棱柱：4角×4点，4高度层，含顶底与边缘斜角；128三角面/实例。边缘斜角受高度与最薄轴限制，避免薄刀/板反折。
- 椭圆环带：64段，顶/底/内/外四面，512三角面/实例；宽度沿椭圆法向偏移。
- 低模球：12经向×8纬向，168有效三角面/实例，极点不生成零面积面；方向箭头1三角面。
- 圆柱采用引擎内置网格，实际总网格/材质/绘制次数和帧时间待 Unity/Player 量测，不以静态配方宣称已达到性能目标。
- 材质18种共用纯色 Standard：无外部纹理，低金属/光泽；选择与灯光少量 emission，不使用强 bloom、景深或雾遮住轨/盘。
- 镜头：正交斜俯视，位置 `(0.3,8.3,-9.3)` 看向 `(0,0.65,0.45)`；最小正交尺寸3.7，按最终 pixelRect 适配窄画幅。Runtime 设置的 Camera.rect 保留。
- 世界文字：64px 字体图集，`characterSize=请求字高×10/64`，分离图集精度和世界比例。店招字高约0.28m、库存/工站0.18m、槽号0.21m、料理0.145m、交留牌0.12m；按702px高视口估算主要标签约14–20px，最终以实际画面复核。前排工站标签位于本工具前下方 `(0,0.12,-0.34)`，后排位于本工具后上方 `(0,0.47,0.25)`；坐标均相对工站锚点，避免前排标签投影到后排工具。
- Build(Camera) 只建立一次独立场景根；Render(Session,int) 只读深拷贝快照，更新盘/站/订单/库存。静态厨房不每帧重造；类型变化才更换局部模型并释放生成网格。
- 盘按稳定 plateId 重用，槽移动显示0.28秒平滑动画；已提交状态始终为真值，动画完成不触发加工/交付。RaycastSlot(Vector2) 只返回固定槽代理编号。
- SlotPosition/SlotScreenPoint 可供 Runtime HUD定位；Dispose 释放自己生成的网格/材质/场景，不销毁引擎网格或字体。
